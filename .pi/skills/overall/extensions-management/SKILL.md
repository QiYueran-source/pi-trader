# 扩展管理

## 定位

扩展是 Pi 启动时加载的代码，可以注册命令、事件或其他运行时行为。本技能负责识别扩展、检查入口和依赖、解释加载问题，并按用户确认执行明确变更。

## 两类扩展

### 本地扩展

通常位于：

```text
.pi/extensions/<extension-name>/
```

检查入口文件是否存在、默认导出是否符合 Pi 扩展接口，以及启动时是否加载成功。

### npm 扩展

依赖通常记录在：

```text
.pi/npm/package.json
.pi/npm/package-lock.json
```

检查依赖是否声明、lock 文件是否同步、包是否实际安装，以及升级后是否需要重启 Pi。

## 使用范围

适用于：

- 列出本地扩展和 npm 扩展。
- 检查入口文件、依赖和加载错误。
- 排查扩展不生效或启动失败。
- 按确认安装、升级、降级、禁用或删除扩展。

基本检查顺序：

```text
确认来源
→ 检查入口
→ 检查依赖和版本
→ 检查加载错误
→ 修改后重启或重新加载
→ 验证扩展行为
```

## 人工确认边界

以下操作必须先说明影响并获得用户确认：

- 安装、升级、降级或删除扩展。
- 修改 npm 依赖或 lock 文件。
- 修改扩展入口、配置或加载方式。
- 禁用可能注册命令、事件或外部副作用的扩展。

默认不自动安装、升级、删除或替换扩展。权限和密钥管理不属于本技能范围。

## 失败汇报

只需汇报：扩展名称、操作、失败阶段、原因，以及文件或运行时状态是否已经改变。
