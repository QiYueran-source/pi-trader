# MCP 管理

## 定位

MCP（Model Context Protocol，模型上下文协议）服务通过配置接入外部工具。本技能负责识别配置、检查问题、说明影响和执行用户明确确认的变更，不负责自动运维。

当前项目的 MCP 配置位于：

```text
.pi/mcp.json
```

## 使用范围

适用于：

- 查看当前 MCP 服务及其工具。
- 检查 stdio 或 HTTP 配置。
- 排查服务无法启动、连接失败或工具未发现。
- 新增、修改、停用或删除 MCP 服务。

## 检查顺序

```text
读取配置
→ 检查 command / url
→ 检查脚本路径和参数
→ 检查环境变量名称
→ 确认服务能否启动和连接
→ 确认工具是否被发现
→ 必要时验证工具调用
```

服务配置存在不等于服务连接成功；工具被发现也不等于工具调用正常。报告问题时说明具体失败阶段和原因。

## 人工确认边界

以下操作必须先说明影响并获得用户确认：

- 新增、替换或删除服务。
- 修改 command、args、url、headers 或环境变量。
- 修改具有交易、数据库写入或外部副作用的服务。
- 安装、升级或降级 MCP 依赖。

默认不自动安装、升级、删除或替换 MCP 服务。发现明文密钥时提醒用户，但本技能不负责权限和密钥管理。

## 修改后

配置变更后，根据 Pi 的加载机制重启或重新加载 MCP 客户端，再检查服务连接和工具发现结果。不要只修改文件后就假设运行时已经生效。

## 失败汇报

只需汇报：服务名称、操作、失败阶段、原因，以及配置或运行时状态是否已经改变。
