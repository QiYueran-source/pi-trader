# 板块/概念成分股查询（无 ths_index 权限时的可靠路径）

## 问题（都踩过）

- `ths_index` / `ths_member`（同花顺概念板块）：报错「抱歉，您没有接口(ths_index)访问权限」
- 东财 `push2.eastmoney.com` 板块接口、同花顺 `q.10jqka.com.cn`：服务器环境常被拒连/封禁（`Remote end closed connection` / `nginx forbidden`），不可依赖
- `index_member(index_code='801222.SI')`：**只返回历史进出记录**（`out_date` 全非空），当前成分股取不到——别用这个接口取当前成分

## 可靠方案：index_member_all 全市场快照 + offset 分页 + l3_name 过滤

`index_member_all` 返回**全市场 SW 分类快照**，即使传了 `index_code` 也忽略该参数（按全市场返回），每页最多 3000 行，用 offset 分页拉全：

```python
import tushare as ts, time, pandas as pd
pro = ts.pro_api()
all_rows = []
for offset in range(0, 12000, 3000):
    df = pro.index_member_all(offset=offset, limit=3000)
    if df is None or len(df) == 0:
        break
    all_rows.append(df)
    time.sleep(0.3)
full = pd.concat(all_rows, ignore_index=True)
```

字段：`l1_code/l1_name/l2_code/l2_name/l3_code/l3_name/ts_code/name/in_date/out_date/is_new`

过滤成分股（申万三级行业名）：

```python
sel = full[full['l3_name'].isin(['垂直应用软件', '横向通用软件', 'IT服务Ⅲ'])]
```

## 关键事实

- 全市场快照约 5,939 只，3 页拉完（每页 3000）
- **没有官方板块叫「AI应用」**；申万三级「计算机」下最贴近的是三块：
  - 垂直应用软件（106 只）— 行业专用软件（金融/政务/医疗/建筑）
  - 横向通用软件（36 只）— 通用平台（办公/安全/协同）
  - IT服务Ⅲ（145 只）— 系统集成/IT服务/数字化
- 查询概念股归属时用 SW 分类替代同花顺/东财概念口径，稳定且字段规范
- 2026-08-03 实测：达实智能(002421)→IT服务Ⅲ、用友网络(600588)/泛微网络(603039)→横向通用软件、普联软件(300996)→垂直应用软件、网宿科技(300017)→IT服务Ⅲ
