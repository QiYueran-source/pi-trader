# 买入信号检测：MA5 突破 + 放量确认

## 场景

在候选股池（已筛选出涨停回调站稳的股票）基础上，检测每个候选股的最新交易日是否满足开仓条件。

## 信号条件

- **价格条件**：收盘价 > MA5（放量突破 5 日线）
- **量能条件**：成交量 > 放量倍数 × MA(成交量, N)（默认 N=20，倍数 1.2）
- 两个条件必须同时满足

## 推荐数据流

```
candidates/latest.json           → 候选股池（经过涨停筛选 + 均线回调检查后）
daily(ts_code=XXX, ...)          → 逐只拉日线（需要 MA5 + 均量窗口的历史数据）
  → time.sleep(0.15)             → 控制频率
  → 计算 MA5、均量 MA             → 信号判定
  → 输出 signals 列表             → 量比（vol/ma_vol）排序
```

## 完整流水线目录结构

推荐按处理阶段分层输出：

```
output/
├── for_market_candidate/        # stock_picker.py —— 全市场涨停回调候选
├── hottest_industry_candidate/  # AI 分析后 —— 筛选为热门板块候选
└── buy_signal/                  # buy_signal.py —— 买入信号
```

## 买入信号输出规范

```json
{
  "date": "20260615",
  "data_date": "20260615",
  "params": {
    "volume_multiplier": 1.2,
    "volume_ma_window": 20,
    "ma5_period": 5
  },
  "stats": {
    "total_candidates": 516,
    "checked": 516,
    "signals": 1
  },
  "signals": [
    {
      "code": "301312.SZ",
      "name": "智立方",
      "industry": "专用机械",
      "board_count": 2,
      "signal_date": "20260615",
      "close": 91.38,
      "ma5": 84.952,
      "ma5_above_pct": 7.57,
      "volume": 91560,
      "ma_volume": 66076,
      "volume_ratio": 1.39,
      "pullback_pct": -32.31,
      "board_dates": ["20260602", "20260615"]
    }
  ]
}
```

- `ma5_above_pct`: 收盘价高于 MA5 的百分比（正数 = 突破幅度）
- `volume_ratio`: 当日成交量 / 均量（>1 = 放量）
- `signals` 按量比降序排列（量比大的优先关注）
- 落盘文件：`buy_signal/signals_{日期}.json`，覆盖写入

## 常见注意事项

### 速率限制

`daily(ts_code=XXX)` 逐股查询时，基础用户建议 `time.sleep(0.15)` ~ `time.sleep(0.6)` 之间。500 只候选全量扫描约需 1.5~5 分钟。

### 数据不足兜底

如果某只股票的历史数据少于 MA5 或均量窗口，应跳过并日志记录（名称 + 原因），不应静默处理。

### 最新收盘日判断

检查时以 `target_date` 为截止，用数据中 `trade_date <= target_date` 的最后一条作为最新收盘日。如果当天市场未收盘、数据不完整，自动回退到前一个交易日。

### 参数外部化

买入检测参数（放量倍数、均量窗口、MA5周期）放在独立参数文件中，与脚本分离：

```
params/
├── pick.json    # 选股参数
├── buy.json     # 买入信号参数
└── sell.json    # 卖出信号参数
```
