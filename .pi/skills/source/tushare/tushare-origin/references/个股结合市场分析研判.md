# 个股结合市场分析研判

## 适用场景

用户问"XX股票怎么操作/能不能买/怎么样"时，需要结合**近期盘前分析/市场分析**给出研判，而不仅仅是拉数据。

## 标准流程

### 第1步：查个股基本面+行情

用 Tushare 获取：

```python
# 基本信息
stock_basic(ts_code='001309.SZ')  # 行业、上市日
stock_company(ts_code='001309.SZ')  # 主营业务

# 近期行情（默认近1个月）
daily(ts_code='001309.SZ', start_date='20260601', end_date='20260710')
```

输出要点：
- 股票全称、代码
- **所属行业/板块**（判断与当前市场热点的关联性）
- 主营业务描述（是否属于当前主线方向）
- **近期走势特征**：涨跌幅、波动率、高低点、趋势形态

### 第2步：读近期盘前分析/市场分析

搜索 `笔记/财经分析/` 下最近2-3个工作日的分析文件：

```python
# 找最近3个工作日的盘前分析
search_files(target='files', pattern='盘前分析', path='...'/'笔记/财经分析/')
# 按修改时间排序取最新的
```

重点提取：
- **大盘环境判断**：是否提示风险（M头/见顶）/ 机会（企稳/冰点）
- **板块观点**：个股所在行业是否被提及、看好还是规避
- **风险提示**：不开新仓/不抄底/高开高抛等
- **时间节点**：后续催化/风险事件

### 第3步：交叉研判

将个股与市场分析对接：

| 研判维度 | 检查项 |
|----------|--------|
| **行业匹配** | 个股所属行业是否在近期分析中被列为"看好方向" |
| **催化匹配** | 是否有近期事件催化（如长鑫存储上市利好存储板块） |
| **风险匹配** | 大盘是否在M头/回调窗口内 |
| **位置判断** | 个股是高位震荡还是低位企稳 |
| **操作纪律** | 近期盘前分析是否有"不开新仓""不抄底"等纪律性提示 |

### 第4步：输出研判结论

按以下结构输出：

```
## 个股基本情况
（行业、主营业务、代码）

## 近期走势
（区间涨跌、波动特征、关键价位）

## 与市场分析对照
（个股方向 vs 市场主线：匹配度）
（当前大盘风险信号 vs 个股位置）
（近期操作纪律）

## 操作建议
[已持有] 具体建议
[未持仓] 是否建议开仓
风险提示（关键时间节点、止损参考等）
```

## 重要原则

1. **先查数据再下结论**——不要凭记忆说话
2. **市场分析优先级**：最近1天的分析文件 > 前1天的 > 更早的
3. **盘前分析中的操作纪律优先级高于个股逻辑**——如果分析说"不开新仓"，即使个股看起来不错也应提示风险
4. **区分已持有 vs 未持仓**：两个场景操作建议不同，必须分别说明
5. **给出关键时间节点**：用户需要知道什么时候该关注、什么时候该回避

## 常见错误

| 错误 | 正确做法 |
|------|---------|
| 只看个股数据，忽略市场环境 | 必须交叉对照近期市场分析 |
| 用户问"怎么操作"只给基本面 | 操作建议需要结合判断 |
| 未持仓的开仓建议过于积极 | 市场环境差时优先建议等待 |
| 忽略M头/见顶等风险信号 | 风险信号是操作建议的重要依据 |
