# 季度调仓日期对齐

A股季度调仓回测时，调仓日通常定在 3/6/9/12 月的最后一天。
但这些日期可能是假期/周末，需要对齐到最近的交易日。

## 坏做法

```python
def get_rebalance_dates(start, end):
    """硬编码 3/31, 6/30, ..., 再手动查日历对齐"""
    dates = []
    for y in range(start_y, end_y + 1):
        for m, d in [(3,31), (6,30), (9,30), (12,31)]:
            dt = f"{y}{m:02d}{d:02d}"
            if start <= dt <= end:
                dates.append(dt)
    return dates  # 可能含非交易日，需额外对齐
```

问题：3/31 可能是假期、周末，必须另写逻辑往前推。
还要额外查 `trade_cal` 判断哪些是交易日，代码分两层，容易出 bug。

## 好做法

一步到位：用 `trade_cal` 查每个季度末月最后一个交易日。

```python
def get_rebalance_dates(start: str, end: str) -> list:
    """直接用交易日历查 3/6/9/12 月最后一个交易日"""
    import pickle
    import tushare as ts
    
    # 加载交易日历（优先本地缓存）
    cache_path = "cache/trade_cal.pkl"
    if os.path.exists(cache_path):
        with open(cache_path, "rb") as f:
            cal = pickle.load(f)
    else:
        ts.set_token(os.environ["TUSHARE_TOKEN"])
        pro = ts.pro_api()
        cal = pro.trade_cal(start_date="20000101", end_date="20261231")
        os.makedirs(os.path.dirname(cache_path), exist_ok=True)
        with open(cache_path, "wb") as f:
            pickle.dump(cal, f)
    
    # 筛选范围 + 只用 A 股日历
    cal = cal[(cal["cal_date"] >= start) & (cal["cal_date"] <= end)]
    cal = cal[cal["exchange"] == "SSE"]
    
    dates = []
    for y in range(int(start[:4]), int(end[:4]) + 1):
        for m in [3, 6, 9, 12]:
            month_key = f"{y}{m:02d}"
            trading = cal[
                (cal["cal_date"] >= month_key + "01") &
                (cal["cal_date"] <= month_key + "31") &
                (cal["is_open"] == 1)
            ]
            if not trading.empty:
                dates.append(str(trading.iloc[0]["cal_date"]))
    return dates
```

## 关键细节

| 注意点 | 说明 |
|--------|------|
| `trade_cal` 排序 | **降序**（最新在前），所以 `iloc[0]`=最后交易日，`iloc[-1]`=第一天 |
| `exchange` 过滤 | 沪深用 `SSE`（同一个日历），期货用 `CFE` |
| 缓存策略 | `trade_cal` 基本不变，一次性拉取 + pickle 缓存即可 |
| 返回格式 | `YYYYMMDD` 字符串，可直接传给 `daily_basic(trade_date=...)` |

## 与月线方案的对比

| 方案 | API 调用数 | 优缺点 |
|------|-----------|--------|
| `pro.monthly(trade_date=月份)` 全市场 | **0 条数据** | ❌ `monthly` 必须传 `ts_code`，不支持按月全市场拉取 |
| `pro.monthly(ts_code=单只, start, end)` | 1 次/只股票 | ❌ 300 只股票 = 300 次调用，比 daily_basic 多 |
| `trade_cal` + `daily_basic(trade_date)` | 1次(trade_cal) + N次(daily_basic) | ✅ **推荐**：trade_cal 只需拉一次缓存，daily_basic 按交易日拉全市场 |

核心原则：**能用 `daily_basic` 全市场快照解决的问题，就别走逐股票拉取的路径。** `daily_basic(trade_date=X)` 不加 `ts_code` 时返回当日全市场所有股票的一行快照（含 close + total_mv），性价比远高于逐股票拉月线。
