# ETF 流动性对比与"每板块选一只最优 ETF"方法

> 2026-07-31 实战沉淀。用于为行业主线/轮动体系挑选候选池：每个板块选一只 ETF，按**流动性 + 费率**综合最优。

## 核心方法

### 1. 拉日线，用 `fund_daily`（不是 `daily`）

```python
import os, tushare as ts
pro = ts.pro_api(os.environ['TUSHARE_TOKEN'])

d = pro.fund_daily(ts_code='588200.SH', start_date='20260430', end_date='20260730')
# amount 单位是千元！vol 单位是手！
avg_amt_yi = d['amount'].mean() / 100000          # ✅ 亿元（1亿 = 100,000千元）
avg_vol_yi = d['vol'].mean() * 100 * d['close'].mean() / 1e8   # 交叉验证口径
```

**单位验证法：** `amount/1000`（元）≈ `vol×100×close`（元），两个口径应近似相等。
若 `amount` 与 `vol×close` 比值恒为 ~10，说明把千元当成元了。

### 3. 费率核实

行业 ETF 管理费普遍 0.15%/年 + 托管 0.05%/年（合计 0.20%）。
例外：创新药 159992（0.50%+0.05%）、消费 159928（0.50%+0.05%）。
用 `pro.fund_basic(market='E')` 的 `m_fee` / `c_fee` 字段核实（字段名是 `m_fee`/`c_fee`，不是 mgt_fee）。

### 4. 选池原则

- **每板块只留一只**，流动性最大者优先（全仓进出无压力）
- 日均成交 ≥ 5亿 为核心池，1~5亿 为补充池（注意滑点），< 1亿 不推荐
- 费率差异只在流动性接近时作为第二比较维度
- 现金停泊统一用 511990 华宝添益（日均 110亿+，T+0）

## 应用场景

- 行业主线趋势跟踪体系候选池（12+1：11只行业ETF + 货币ETF）
- 跨资产轮动体系扩池评估
- 任何需要"同板块选最优 ETF"的需求

## 相关坑位

- `fund_daily` 的 `amount` 是**千元**、`vol` 是**手**，见 tushare SKILL.md 的 fund_daily 小节
- 拉近 3 个月（~62 个交易日）求均值比只看单日可靠；单日极端行情会扭曲结果
