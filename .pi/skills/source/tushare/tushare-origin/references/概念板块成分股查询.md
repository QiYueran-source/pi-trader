# 概念板块/行业成分股查询 — 可用路径与坑（2026-08 实测）

用户问"XX概念有哪些股票""AI应用板块成分股有哪些"时，按此路径取数。

## 结论先行

| 数据源 | 接口 | 状态 | 说明 |
|:---|:---|:---|:---|
| 同花顺概念 | `ths_index` / `ths_member` | ❌ 基础账户无权限 | 报"没有接口(ths_index)访问权限" |
| 申万行业成分 | `index_member(index_code=...)` | ⚠️ 只返回历史记录 | out_date 全非空、is_new 全 N，无法直接过滤当前成分 |
| **申万行业成分（推荐）** | **`index_member_all(offset=, limit=)`** | ✅ 可用 | 全市场快照分页拉取，含 l1/l2/l3 三级行业字段，按行业名过滤 |
| 东财概念板块 | push2.eastmoney.com clist 接口 | ⚠️ 服务器 IP 常被拒 | Remote end closed connection，不稳定 |
| 同花顺网页 | q.10jqka.com.cn / dq.10jqka.com.cn | ⚠️ 服务器 IP 被拒 | Nginx forbidden / 404 |

**结论：** A股没有官方"XX概念"板块成分接口（基础 Tushare 权限下），用**申万三级行业**替代最稳。用户说"AI应用板块"时，申万对应 `垂直应用软件` / `横向通用软件` / `IT服务Ⅲ`（软件/IT服务三兄弟）。

## index_member_all 用法（推荐）

```python
import tushare as ts, time
import pandas as pd

ts.set_token(os.environ.get('TUSHARE_TOKEN', ''))
pro = ts.pro_api()

# 全市场快照分页拉取（约 5900+ 只，每页 3000，循环 offset）
all_rows = []
for offset in range(0, 12000, 3000):
    df = pro.index_member_all(offset=offset, limit=3000)
    if df is None or len(df) == 0:
        break
    all_rows.append(df)
    time.sleep(0.3)  # 限速
full = pd.concat(all_rows, ignore_index=True)

# 按三级行业名过滤（也可用 l1_name/l2_name）
target = ['垂直应用软件', '横向通用软件', 'IT服务Ⅲ']
sel = full[full['l3_name'].isin(target)]
```

**返回字段：** `l1_code/l1_name`（申万一级）、`l2_code/l2_name`（二级）、`l3_code/l3_name`（三级）、`ts_code`、`name`、`in_date/out_date/is_new`。

**注意：** 该接口的 `index_code` 参数实际按全市场快照返回（分页），不是按指定指数过滤——要按行业筛选必须自己 filter 字段。成分中会混入退市股（name 含"退"、ST），向用户展示前剔除。

## 腾讯盘中实时行情接口（tushare daily 当日数据未更新时用）

Tushare `daily` 盘中无当日数据（收盘后才有）。需要盘中实时行情时用腾讯免费接口：

```python
import urllib.request

# 多代码逗号分隔，沪市 sh 前缀、深市 sz 前缀
url = 'https://qt.gtimg.cn/q=sh600588,sz002896'
req = urllib.request.Request(url, headers={'User-Agent': 'Mozilla/5.0'})
resp = urllib.request.urlopen(req, timeout=10).read().decode('gbk')  # GBK 编码！

# 每条格式: v_sh600588="1~用友网络~600588~11.53~11.08~11.39~1840000~...~20260803120503~..."
# 按 ~ 分割后字段索引：
#   data[1]=名称  data[2]=代码  data[3]=现价  data[4]=昨收  data[5]=今开
#   data[6]=成交量(手)  data[30]=时间(YYYYMMDDHHMMSS)  data[31]=涨跌额
#   data[32]=涨跌幅%  data[33]=最高  data[34]=最低
data = line.split('"')[1].split('~')
price = float(data[3]); pre_close = float(data[4]); open_p = float(data[5])
pct = float(data[32]); high = data[33]; low = data[34]; vol = float(data[6])/1e4  # 万手
```

**注意：** 响应是 GBK 编码（不是 UTF-8），`decode('gbk')` 否则乱码。午间 11:30-13:00 返回上午收盘快照，时间字段可判断数据时点。
