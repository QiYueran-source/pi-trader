# 开源证券投顾来源规则

## 来源定义

- 来源主体：开源证券投顾。
- 当前状态：允许新增、跟踪和复盘。
- 当前主要文件：`开源证券-盘前分析.md`。
- 默认 `source_type`：`盘前分析`。

## 整理

1. 读取 `交易/财经分析/<日期>/` 下同日已有的开源证券文件。
2. 同一来源、同一内容类型、同一日期只保留一份；补充或覆盖前先读取并判断差异。
3. 盘前分析保存明确的市场环境、板块方向、个股观察、风险判断和操作策略。
4. 只把专业来源明确表达的未来判断提取为判断记录；客观行情事实不作为判断录入。
5. 午评或收评中的客观市场数据按知识库规则进入事实文档；其中明确的未来判断仍需确认是否属于开源证券来源后再处理。

## 录入

- 个股判断使用 `type=stock`，必须核对代码和名称。
- 板块、指数和题材判断使用 `type=sector`，代码可为空。
- 根据原文修饰词计算跟踪窗口：短线、近日、博弈、谨慎或风险通常为 3 天；无明确修饰通常为 5 天；趋势向好、主升、中期或延续通常为 10 天；长期、业绩驱动、政策或进口替代通常为 44 天。
- `mention_date` 使用分析发布日期，不使用整理日期或验证日期。
- 每条判断的 `context` 必须能对应原文中的一句话或连续片段。
- 写入前使用逻辑路径校验，并向用户展示待入库清单。

## 复盘

- 按开源证券的 `source_file` 单独查询和统计，不与和信历史记录混算。
- 当前盘前分析在发布日期当天开始验证。
- 覆盖有效窗口内仍未结束的历史开源判断。
- 复盘至少包含市场背景、开源判断、实际表现、出入分析、来源命中率、未验证项和总结。
- 复盘文件建议写入：`交易/财经分析/<日期>/开源证券-盘前分析复盘.md`。
- 复盘完成后写入对应简报。
