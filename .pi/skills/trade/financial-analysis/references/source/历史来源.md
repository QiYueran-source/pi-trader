# 历史专业财经来源规则

## 来源范围

本文件管理已经停止新增、但仍需要查询、复盘和统计的专业财经来源，当前包括：

- 和信证券或和信荐股；
- 历史调仓信息；
- 其他已停止的专业机构来源。

## 和信荐股

- 历史 `source_type` 可以继续读取，包括 `盘前荐股`、`盘后荐股` 和历史 `调仓信息`。
- 历史来源文件和数据库记录可以用于复盘、统计和历史查询。
- 当前不新增和信荐股判断，不覆盖历史和信记录，不把新内容伪装成其他来源写入。
- 发现新的和信材料时，只能标记为历史来源输入并向用户说明不录入；如需保存原始材料，应按知识库规则作为历史资料保存，不进入当前判断数据库。

## 其他停止来源

- 只按已有 `source_file`、`source_type` 和历史日期查询。
- 不补录、不迁移、不删除历史判断。
- 历史物理路径按兼容规则读取，新的来源字段仍遵守逻辑路径协议。

## 历史复盘

- 复盘时明确标注来源已停止，不把历史命中率解释为当前来源表现。
- 可以按来源文件分别查询历史判断和表现。
- 历史统计不得与当前开源证券投顾统计合并为单一来源命中率。
- 历史数据缺失、来源文件缺失或行情不可验证时，标记为缺失或未验证，不补造结果。

## 非专业内容边界

用户口述、主观交易观点和体系内部判断不属于历史专业财经来源，也不由本文件处理。
