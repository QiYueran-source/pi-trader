# 财经分析

## 触发

以下内容必须使用本技能：

- 专业证券公司、投顾机构或其他明确专业来源的财经分析；
- 专业来源的个股、板块、指数、市场情绪和风险判断整理；
- 专业来源判断的数据库录入、行情跟踪和复盘；
- 专业来源历史判断的查询、验证和统计。

用户口述、主观交易观点、交易意图和体系内部判断不属于本技能，不得录入专业财经判断数据库，也不得参与专业来源命中率统计。

## 来源路由

先识别分析来源主体，再加载对应来源规则：

- 开源证券投顾：`references/source/开源证券投顾.md`
- 和信荐股及其他已停止来源：`references/source/历史来源.md`

来源主体决定整理、录入、跟踪和复盘规则；来源内部的盘前分析、盘前荐股、盘后荐股等内容类型由来源规则映射到 `source_type`。

## 通用流程

1. 识别来源主体、内容日期和内容类型。
2. 加载对应的来源规则和 [`references/common.md`](references/common.md)。
3. 按来源规则读取本地输入、整理专业判断并写入动态知识文档。
4. 按来源规则提取判断，使用公共规则完成名称、代码、窗口和逻辑路径校验。
5. 先向用户展示待入库清单，获得确认后再调用财经分析 MCP 写入。
6. 写入后核对新增、跳过、替换数量，并重新查询复核。
7. 复盘时只读取对应来源的有效判断，使用行情 MCP 验证并形成来源独立复盘。
8. 完成后按 `summary` 技能写入简报。

## 边界

- 财经分析 MCP 负责数据库访问和工具参数校验；工具列表见 [`references/mcp-tools.md`](references/mcp-tools.md)。
- 公共字段、窗口、路径和写入安全规则见 [`references/common.md`](references/common.md)。
- 不执行 SQL，不调用旧 CLI，不把用户观点当作专业来源。
- 不负责交易下单、交易账本、交易体系计划或组合复盘。
