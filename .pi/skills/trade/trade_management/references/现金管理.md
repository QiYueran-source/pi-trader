# 现金管理

现金管理用于记录每个交易体系在每个账户下的现金流入流出，为体系级资金追踪和复盘提供数据支持。

## 作用

现金管理的核心作用包括：

1. **记录现金变动**：每一笔现金流入流出都作为独立记录保存
2. **实时计算余额**：通过 SUM(amount) 实时计算某体系在某账户下的现金余额
3. **支撑交易自动联动**：创建交易记录时自动生成对应的现金变动
4. **支撑体系间调拨**：提供原子性的资金划转操作
5. **支撑资金复盘**：可回看每一笔资金变动的时间、金额和原因

## 设计原则

- 现金变动采用“事件流”模型，不直接维护余额字段
- 余额由 SUM(amount) 实时计算，避免冗余存储导致不一致
- 每条现金变动通过 (account_id, system_id) 归属到具体账户和体系
- 交易自动联动时，手续费一并计入现金变动

## 表结构

- 表名：`cash_flow`
- 字段定义：
    - `id`：现金变动主键，自增整数
    - `account_id`：账户 ID，对应 `account.id`
    - `system_id`：交易体系 ID
    - `amount`：现金变动金额（正=流入，负=流出）
    - `occurred_at`：变动时间
    - `reason`：变动原因
    - `updated_at`：最后更新时间

## 最小建表 SQL

```sql
CREATE TABLE IF NOT EXISTS cash_flow (
    id INTEGER PRIMARY KEY,
    account_id TEXT NOT NULL,
    system_id TEXT NOT NULL,
    amount REAL NOT NULL,
    occurred_at TEXT NOT NULL,
    reason TEXT,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (account_id) REFERENCES account(id)
);
```

## 索引

```sql
CREATE INDEX IF NOT EXISTS idx_cash_flow_account_id ON cash_flow(account_id);
CREATE INDEX IF NOT EXISTS idx_cash_flow_system_id ON cash_flow(system_id);
CREATE INDEX IF NOT EXISTS idx_cash_flow_account_system ON cash_flow(account_id, system_id);
CREATE INDEX IF NOT EXISTS idx_cash_flow_occurred_at ON cash_flow(occurred_at);
```

## CLI 使用说明

`cash_cli.py` 提供现金管理和资金调拨功能。

### 查看余额

```bash
./cash_cli.py balance --account-id <账户ID> --system-id <体系ID>
```

输出：账户、体系、现金余额（实时 SUM 计算）。

### 添加现金变动

```bash
./cash_cli.py add \
  --account-id <账户ID> \
  --system-id <体系ID> \
  --amount <金额> \
  --occurred-at <时间> \
  --reason <原因>
```

- `--amount`：正数表示流入，负数表示流出
- `--reason`：变动原因，如“初始入金”“分红到账”

### 查看流水

```bash
./cash_cli.py list --account-id <账户ID> --system-id <体系ID> [--limit 20]
```

按时间倒序显示现金流水，默认最近 20 条。

### 修改记录

```bash
./cash_cli.py update <ID> [--amount] [--reason] [--occurred-at]
```

只需传入需要更新的字段，未传入的字段保持不变。

### 删除记录

```bash
./cash_cli.py delete <ID>
```

删除前会要求确认。

### 体系间调拨

```bash
./cash_cli.py transfer \
  --account-id <账户ID> \
  --from-system <源体系ID> \
  --to-system <目标体系ID> \
  --amount <金额> \
  --occurred-at <时间> \
  --reason <原因>
```

- `--amount`：必须为正数
- 原子操作：同时生成两条记录（源体系扣减、目标体系增加）
- reason 会自动拼接调拨方向信息

## 交易自动联动

当通过 `trade_cli.py create` 创建交易记录时，系统会自动往 `cash_flow` 表插入一条对应的现金变动记录：

- **买入**：`amount = -(quantity * price + 手续费)`，reason 为 `买入 <代码> <数量>股@<价格> (trade#<ID>)`
- **卖出**：`amount = quantity * price - 手续费`，reason 为 `卖出 <代码> <数量>股@<价格> (trade#<ID>)`

手续费根据账户的 `fee_rules` 动态计算，与 `pnl` 命令保持一致。

如果账户没有配置费率规则，手续费按 0 计算。

## 余额说明

- 余额允许为负，不校验
- 余额 = `SUM(amount) WHERE account_id = ? AND system_id = ?`
- 余额为负表示该体系在该账户下处于资金占用状态

## 典型使用场景

### 场景一：体系启动时入金

```bash
./cash_cli.py add --account-id my_account --system-id dividend_etf_grid --amount 50000 --occurred-at "2026-06-13 09:00:00" --reason "初始入金"
```

### 场景二：买入后自动扣减

```bash
./trade_cli.py create --account-id my_account --system-id dividend_etf_grid --code 510300.SH --name 沪深300ETF --side buy --quantity 1000 --price 3.5 --occurred-at "2026-06-13 10:00:00"
```

执行后自动生成一条 cash_flow 记录，amount 为 -(3500 + 手续费)。

### 场景三：体系间调拨

```bash
./cash_cli.py transfer --account-id my_account --from-system dividend_etf_grid --to-system agent_etf_rotation --amount 10000 --occurred-at "2026-06-13 14:00:00" --reason "调拨至轮动体系"
```

### 场景四：分红到账

```bash
./cash_cli.py add --account-id my_account --system-id dividend_etf_grid --amount 500 --occurred-at "2026-06-15 09:00:00" --reason "510300.SH 分红到账"
```
