# 历史交易数据恢复

从 markdown 复盘文档中提取历史交易记录写入 hermes-trade SQLite 数据库。

## 数据来源

历史交易记录存储在 markdown 复盘文档中：

```
/hermes-trader/knowledge/交易/交易复盘/{日期}/{体系名}.md
```

### 复盘文档的 frontmatter

复盘文档 frontmatter 包含体系归属信息，可用于确定系统 ID 和账户：

```yaml
---
systems:
  - agent_etf_rotation_system      # 或 hot_sector_pullback_system
trade_type: 模拟交易
date: 2026-07-06
account_id: MNZH                    # 或 YHZQ
---
```

### 交易数据格式

**ETF轮动体系** 的复盘文档通常包含交易表格：

```
| 时间 | 方向 | 标的 | 数量 | 价格 | 金额 |
|------|------|------|------|------|------|
| 14:00 | 卖出 | 588000 科创50ETF | 544,900份 | 2.04 | 1,111,596元 |
```

**回调低吸体系** 的复盘文档在"体系完整交易记录"段包含全周期买卖汇总表。

## 恢复步骤

### 1. 确定账户和初始入金

| 体系 | system_id | 账户 | 初始本金 |
|:---|:---:|:---:|:---:|
| 红利ETF网格 | `div_etf_grid_trade` | YHZQ | 8,000 |
| ETF轮动 | `agent_etf_rotation_system` | MNZH | 1,000,000 |
| 回调低吸 | `hot_sector_pullback_system` | MNZH | 1,000,000 |

### 2. 数量推算

当复盘文档只给总盈亏和买卖价时，用以下公式推算数量：

```
数量 = 总盈亏 / (卖出价 - 买入价)
```

示例：士兰微 +¥47,658 / (47.98 - 37.84) = 4,700 股

### 3. 卖出日期推算

从"持有天数"列反推卖出日期：
- 买入日 + 持有天数 = 卖出日（仅算自然日）
- 持有 1 天 = 次日卖出

### 4. 直接操作 SQLite

批量恢复时通过 Python 直接写 SQLite 比调 CLI 更高效。注意 trade 表**没有 amount 列**，只存储 `quantity` + `price`。

```python
# 写交易
c.execute("""INSERT INTO trade (account_id, system_id, code, name, side, quantity, price, occurred_at, note)
    VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)""",
    (account_id, system_id, code, name, side, quantity, price, occurred_at, note))

# 同时记现金流水
c.execute("""INSERT INTO cash_flow (account_id, system_id, amount, occurred_at, reason)
    VALUES (?, ?, ?, ?, ?)""", (account_id, system_id, cash_amount, occurred_at, reason))
```

### 5. SQLite 重建注意事项

- 先 `DELETE FROM trade` + `DELETE FROM cash_flow WHERE reason != '例外'` + `DELETE FROM account` 清空旧数据
- `CREATE TABLE IF NOT EXISTS` 确保表存在
- 此时 `account_cli.py list` 返回"暂无账户"是正常的，`account` 表刚清空
