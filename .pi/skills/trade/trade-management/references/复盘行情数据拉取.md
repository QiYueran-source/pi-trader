# 复盘行情数据拉取（工具与口径）

复盘与信号复核需要指数、ETF 与个股行情。取数一律通过 `tushare-data` MCP；不写临时脚本、不用 `python -c` 内联长代码、不直连 SDK、不读旧环境的 token 文件（token 由 MCP 服务自行读取 `.pi/mcp-servers/tushare/.env`）。

## 工具与代码口径

| 数据 | MCP 工具 | 口径 |
|:--|:--|:--|
| 指数（如科创50） | `get_index_daily` | 科创50 为 `000688.SH`（上交所指数 `.SH`、深交所指数 `.SZ`，**不套用股票代码段规则**；`000688.SZ` 是国城矿业，勿混） |
| ETF／基金（511990、588000、515180 等） | `get_fund_daily` | 必须用基金工具，用股票日线工具会静默返回空 |
| 个股日线 | `get_stock_daily` | 带 `.SH`／`.SZ`／`.BJ` 后缀，裸代码返回空 |
| 分钟线（开盘段） | `get_stock_minutes`／`get_fund_minutes` | 开盘段用 09:30–10:00；窗口实测含两端共 7 根 5min bar |
| 全市场日线 | `get_market_daily` | 按 `trade_date` 一次取全市场，用于市场宽度与涨停统计 |
| 基础资料 | `get_stock_basic`／`get_fund_basic` | 名称、行业、上市日期、费率等 |

调用后检查 `ok`、`row_count`、`source`、`warnings`；空结果要区分非交易日、权限不足、参数错误与真实无数据。按交易日排序后再看，输出常用列 `trade_date/open/high/low/close/pct_chg/vol/amount`。

## 单位口径

`daily` 系接口（`daily`／`fund_daily`／`index_daily`）：`vol` 单位是「手」、`amount` 单位是「千元」，都不是「万手／亿元」。换算万手 ÷10000、亿元 ÷100000。8/14 科创50 实测 `vol=8685139` 手 = 868.51 万手；把 `vol` 直接标成「万手」会让量能环比错一个数量级。其它工具按各自字段说明换算。

## 限频

官方 `stk_mins` 限频严格（**实测 1 次/小时**，同小时重复调用必拒），而 19:00／19:10／19:25 三个体系任务同处一小时。纪律：单个任务一次把所需 bar 取全再计算；降级链（`official` → `promax`，promax 需校验 `trade_time` 日期）与 `unavailable` 处理见 `交易/交易体系/热门板块回调低吸体系/风控.md`「开盘段取数降级链」。

## 体系判断口径（本文件不定义，只给指针）

- **涨停／跌停与市场宽度统计**：口径见 `交易/交易体系/热门板块回调低吸体系/选股.md`，产物由 `hot-sector-pullback-system.calculate(operation="sector_heat"|"select_candidates")` 生成（含 `limit_up_clean` 与 `sector_environment.json`）。旧的「按代码段 9.8%／19.5%／29.5% 阈值 + 全市场日线」替代法已废弃，不再使用。
- **开盘半小时审慎标签**：由 `hot-sector-pullback-system.calculate(operation="risk_signal")` 统一计算（3 个交易日有效；有效期内 MA5 跌破当日直接减半），口径见该体系 `风控.md`，不由复盘任务手工补算。
- **ETF 轮动的环境与信号判据**（「缩量止跌」「低波防御」「双日确认」等）：见 `交易/交易体系/基于Agent的ETF轮动体系/规则库/评估框架.md` 与 `调仓逻辑.md`。历史实例：8/14 科创50 量 −17.89% 达标但低点 1690.68 破 8/13 低点 1715.34 → 候选证伪；8/10 国债单日放量创新高后 8/11 即缩量回调，单日放量不构成趋势确认。

## 历史沿革

2026-08-10 的实测记录原以「临时脚本 + 直连 SDK + token fallback」方式写成；2026-10-17 起取数统一走 `tushare-data` MCP，脚本与旧环境路径口径作废。上述实测数据与结论保留为证据。
