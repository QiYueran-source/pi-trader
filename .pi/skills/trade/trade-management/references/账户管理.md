# 账户管理

账户管理用于维护交易账户的基础信息和费用规则，为交易记录、收益计算和费用核算提供账户维度配置。

## 当前访问边界

账户数据由 `trade-management` MCP 管理。查询、创建和更新账户必须使用 MCP 工具，不直接读取或修改 SQLite，不调用旧的 `account_cli.py`、`trade_cli.py` 或其他 CLI。数据库位置由 MCP 配置注入，不在本参考文档中固化机器绝对路径或旧数据库文件名。

## 作用

1. 管理账户 ID、名称和说明。
2. 按品种和方向配置佣金、印花税、过户费和其他费率。
3. 为交易收益、费用和现金流水计算提供账户维度配置。
4. 支持多个券商账户使用不同费率规则。

## 账户字段

- `id`：账户 ID，唯一标识账户。
- `name`：账户名称。
- `fee`：费用规则，JSON 格式。
- `note`：账户说明。
- `created_at`、`updated_at`：由 MCP 管理的时间字段。

## 费用规则格式

`fee` 字段按品种和方向组织，示例：

```json
{
  "version": 1,
  "currency": "CNY",
  "defaults": {
    "commission_rate": 0.0002,
    "commission_min_fee": 5.0,
    "transfer_fee_rate": 0.0,
    "stamp_duty_rate": 0.0,
    "other_fee_rate": 0.0
  },
  "rules": {
    "stock": {
      "buy": {"commission_rate": 0.0002, "commission_min_fee": 5.0},
      "sell": {"commission_rate": 0.0002, "commission_min_fee": 5.0, "stamp_duty_rate": 0.0005}
    },
    "etf": {
      "buy": {"commission_rate": 0.0002, "commission_min_fee": 5.0},
      "sell": {"commission_rate": 0.0002, "commission_min_fee": 5.0}
    }
  }
}
```

具体字段校验、账户查询和账户写入以 `trade-management` 技能及 MCP 工具定义为准。账户 ID 创建后通常作为主键，不应直接修改；删除或重建账户必须经过明确确认。
