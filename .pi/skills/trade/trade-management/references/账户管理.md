# 账户管理

账户管理用于维护交易账户的基础信息和费用规则，为后续的交易记录、收益计算、费用核算提供账户维度的配置支持。

## 作用

账户管理的核心作用包括：

1. **账户信息维护**：管理账户 ID、名称、说明等基础信息
2. **费用规则配置**：按品种和方向配置佣金、印花税、过户费等费率规则
3. **收益计算支持**：为交易收益统计提供费用计算依据
4. **多账户管理**：支持管理多个券商账户，每个账户可配置不同的费率规则

## 表结构

- 表名：`account`
- 字段定义：
    - `id`：账户 ID，唯一标识一个账户，如 `zxzq`
    - `name`：账户名称，如 "中信证券"
    - `fee`：费用规则，JSON 格式，详见下方说明
    - `note`：账户说明，如 "中信证券，手续费为万2，主要用于T交易"
    - `created_at`：创建时间
    - `updated_at`：更新时间

## 费用规则格式

`fee` 字段为 JSON 格式，按品种和方向分层组织费率规则：

```json
{
  "version": 1,
  "currency": "CNY",
  "defaults": {
    "commission_rate": 0.0002,
    "commission_min_fee": 5.0,
    "transfer_fee_rate": 0.0,
    "stamp_duty_rate": 0.0,
    "other_fee_rate": 0.0
  },
  "rules": {
    "stock": {
      "buy": {
        "commission_rate": 0.0002,
        "commission_min_fee": 5.0,
        "transfer_fee_rate": 0.00001,
        "stamp_duty_rate": 0.0,
        "other_fee_rate": 0.0
      },
      "sell": {
        "commission_rate": 0.0002,
        "commission_min_fee": 5.0,
        "transfer_fee_rate": 0.00001,
        "stamp_duty_rate": 0.0005,
        "other_fee_rate": 0.0
      }
    },
    "etf": {
      "buy": {
        "commission_rate": 0.0002,
        "commission_min_fee": 5.0,
        "transfer_fee_rate": 0.0,
        "stamp_duty_rate": 0.0,
        "other_fee_rate": 0.0
      },
      "sell": {
        "commission_rate": 0.0002,
        "commission_min_fee": 5.0,
        "transfer_fee_rate": 0.0,
        "stamp_duty_rate": 0.0,
        "other_fee_rate": 0.0
      }
    }
  }
}
```

### 字段说明

- `version`：规则版本号，当前为 1
- `currency`：币种，默认 CNY
- `defaults`：默认费率规则，当具体规则缺失时回退使用
- `rules`：按品种和方向的费率规则
  - `stock`：股票
  - `etf`：场内 ETF
  - `buy`：买入
  - `sell`：卖出

### 费率字段含义

- `commission_rate`：佣金费率
- `commission_min_fee`：单笔最低佣金
- `transfer_fee_rate`：过户费率
- `stamp_duty_rate`：印花税率（通常仅卖出收取）
- `other_fee_rate`：其他费率

## CLI 使用说明

### 命令列表

```bash
# 查看帮助
./account_cli.py --help

# 创建账户
./account_cli.py create --id <账户ID> --name <账户名称> --fee <费用规则JSON> --note <账户说明>

# 列出所有账户
./account_cli.py list

# 查看账户详情
./account_cli.py show <账户ID>

# 更新账户信息
./account_cli.py update <账户ID> [--name <新名称>] [--fee <新费用规则>] [--note <新说明>]

# 删除账户
./account_cli.py delete <账户ID>
```

### 使用示例

#### 创建账户

```bash
./account_cli.py create \
  --id zxzq \
  --name "中信证券" \
  --fee '{"version":1,"currency":"CNY","defaults":{"commission_rate":0.0002,"commission_min_fee":5.0,"transfer_fee_rate":0.0,"stamp_duty_rate":0.0,"other_fee_rate":0.0},"rules":{"stock":{"buy":{"commission_rate":0.0002,"commission_min_fee":5.0,"transfer_fee_rate":0.00001,"stamp_duty_rate":0.0,"other_fee_rate":0.0},"sell":{"commission_rate":0.0002,"commission_min_fee":5.0,"transfer_fee_rate":0.00001,"stamp_duty_rate":0.0005,"other_fee_rate":0.0}},"etf":{"buy":{"commission_rate":0.0002,"commission_min_fee":5.0,"transfer_fee_rate":0.0,"stamp_duty_rate":0.0,"other_fee_rate":0.0},"sell":{"commission_rate":0.0002,"commission_min_fee":5.0,"transfer_fee_rate":0.0,"stamp_duty_rate":0.0,"other_fee_rate":0.0}}}}' \
  --note "主要做T"
```

#### 列出所有账户

```bash
./account_cli.py list
```

输出示例：
```
zxzq: 中信证券 - 主要做T
gfzq: 广发证券 - 长线持仓
```

#### 查看账户详情

```bash
./account_cli.py show zxzq
```

输出示例：
```
ID: zxzq
名称: 中信证券
说明: 主要做T
费用规则: {"version":1,"currency":"CNY",...}
创建时间: 2026-06-02 10:30:00
更新时间: 2026-06-02 10:30:00
```

#### 更新账户信息

```bash
# 更新名称
./account_cli.py update zxzq --name "中信证券(新)"

# 更新说明
./account_cli.py update zxzq --note "调整后的说明"

# 更新费用规则
./account_cli.py update zxzq --fee '{"version":1,...}'
```

#### 删除账户

```bash
./account_cli.py delete zxzq
```

删除前会有确认提示：
```
确定要删除该账户吗？ [y/N]:
```

## 注意事项

1. **账户 ID 不可修改**：账户 ID 作为主键，创建后不可修改，如需变更请删除后重建
2. **费用规则校验**：创建和更新时会校验 JSON 格式，必须包含 `version` 和 `rules` 字段
3. **删除确认**：删除账户会有确认提示，防止误删
4. **数据存储**：账户数据存储在技能目录下的 `database/hermes_trade.db` 文件中
