# 内容类型

按内容的主要用途选择类型：

- 外部新闻、公告、行情数据和其他可验证输入：`事实`。
- 长期保留的阅读笔记、研究分析、交易心得和方法学习：`笔记`。
- 按日期保存的市场、券商或来源分析：`财经分析`。
- 面向未来交易日的动作、条件和预案：`交易计划`。
- 对已完成计划、实际成交和结果的复核：`交易复盘`。
- 扫描结果、计算结果、状态文件和分析中间产物：`交易过程资料`。
- 相对稳定的交易方法、参数、脚本、模板和流程：`交易体系内部文档`。
- 一段时间内的工作、研究、交易和待办汇总：`摘要`。
- 图片、表格、PDF 等辅助材料：`附件`。

## 易混淆类型

- 长期沉淀的方法或经验 → `笔记`；按交易日产生的市场判断或来源稿件 → `财经分析`。
- 方法本身 → `交易体系`；准备执行的方法 → `交易计划`。
- 已经发生的执行及其结果 → `交易复盘`。
- 程序或分析过程产生的中间结果 → `交易过程资料`。
- 外部策略的整理和学习 → `笔记/交易策略`；已纳入项目运行的策略文件 → `交易体系`。

识别为交易体系内部文档后，只确定体系名称并转交对应的交易体系技能，由该技能决定体系内部位置。
