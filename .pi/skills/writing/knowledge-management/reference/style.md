# 总体风格

- 优先表达结论和关键依据，保持内容简洁。
- 区分事实、观点、交易计划、已发生的成交和复盘结论。
- `summary` 必须能概括正文实际内容，不写空泛描述。
- 避免套话、重复背景和堆叠免责声明；不确定性直接说明来源和影响。
- 涉及投资判断时不忽视风险，写出主要风险、失效条件或观察指标。
- 涉及行情、收益、估值、概率和历史表现时，提供时间范围、数据依据和来源。
- 区分原始数据、计算结果和主观判断。
- 不编造价格、成交、持仓、收益、新闻或数据来源；无法确认的内容标注待确认。
- 使用清晰的小标题和列表组织内容，结构服务于理解。
- 相关内容优先补充已有文档，避免重复创建和无意义拆分。
