# 附件规则

## 定位

所有非文本文件，如图片、图表、PDF 等，都存放在 `knowledge/附件` 目录下。附件以便于存放和引用为主，不强制按主题归类。

## 使用方式  

在其他文档中，如果需要引用图片等附件，直接在文档中插入图片即可，仍然使用相对于knowledge/附件目录的路径。如：
```markdown
![图片描述](附件/2023-08-01/1234567890abcdef1234567890abcdef.png)
```

## 目录边界

附件目录用于存放非文本资源，本身不作为主要知识组织目录。重要信息应尽量记录在正文文档中，附件主要用于被 `笔记`、`事实`、`交易`、`摘要` 等目录下的正文文档引用和辅助说明。

## 目录组织

按日期建立一级目录，每个目录下存放该日期的所有附件，如 `2023-08-01` 目录下存放 `2023-08-01` 日期的所有附件。

## 上传建议

附件通常不作为云端知识库的重点上传内容，应优先节省知识库空间。确有必要上传时，应优先上传已经被正文文档引用、且对当前分析或交易有直接帮助的附件。
