# 热门板块回调低吸体系 - 综合研判 | 2026-09-16

**结论：热门行业 = 元器件、半导体；唯一动作 = 观察（不操作）；无试仓授权，评估点顺延 9/17 晚（执行日 9/18）。**

## 一、决策链（机械门槛逐格核对）

| 格 | 条件 | 9/16 事实 | 判定 |
|:---|:-----|:---------|:-----|
| ① | 热门行业存在（涨停 ≥5 且 ma5 > ma10） | **元器件**（12 / +0.5775 > +0.3337）、**半导体**（5 / +0.9370 > +0.2589）→ **2 个**（9/15 为 0） | ✅ |
| ② | 板内深度回调候选存在 | 负回调 3 只（彩虹股份 -15.56 / 嘉德利 -8.50 / 先导基电 -1.62）；复盘深度区留存 5 只 | ✅ |
| ③ | 大盘不破位（创业板指 > 0） | **3,311.47（+1.9568%）> 0** → 企稳档恢复；从严条款未触发 | ✅ |
| ④ | 延迟授权：**首日不追 + 连续第 2 日验证** | 元器件 / 半导体双确认均为**第 1 日** → **定义上不可能满足** | ❌ |
| — | 仓位分级 | ④ 缺格 → **观察（不操作）** | **零买入** |

**为何不采「提前授权」**：体系 `建仓.md` 对延迟授权（④）是**前置必要条件**，非可选项；「首日不追」正是为规避「单日脉冲后次日退潮」。若允许以 ①②③ 成立替代 ④，等于取消延迟授权条款本身——超出本任务边界（**不修改静态规则**），故本日按缺格处理。**当日零成交属规则内等待，不是遗漏。**

## 二、基线警示：3 个「重建首日次日退潮」样本（复盘口径，逐字引用）

- **8/28**：元器件涨停 **6 → 3**；
- **9/7 → 9/8**：元器件涨停 **16 → 3**（大面积冲榜次日近乎全灭）；
- **9/11 → 9/14**：元器件涨停 **8 → 2**，随后 9/15 ma5 下穿 ma10 **判定中断**。

三例共同指向：**首日强度不构成次日必然延续**。故 9/16 的涨停 **91** / 跌停 **4**（9/15 为 32 / 35、跌停反超涨停）只能记为**情绪修复观察日**，须第 2 日实测强化方可升级为趋势修复；**9/17 判定须以当日实测为准，不得沿用本日方向推演**。

## 三、9/17 评估窗口的口径裁定（预先固化，避免事后解释）

1. **判定时点**：9/17 收盘后（>=15:00 数据齐备）执行 `sector_heat.py`，**不以盘中数据判定**。
2. **双确认连续第 2 日成立条件**：元器件 / 半导体**各自**同时满足「当日涨停 ≥5（`.BJ` 后缀口径，剔 N/C/U 首日新股）」**且**「ma5 > ma10（截止 9/17 收盘）」。
3. **评估与执行时点**：**9/17 晚评估、9/18 开盘执行**（建仓.md：信号收盘后检出，次一交易日开盘价成交）。
4. **试仓上限**：**1/4 正常仓位（约 6.25% 资金，按 9/16 现金 ¥998,148.00 计约 ¥62,384）**——**本计划不授权**，仅为口径预留；若 9/17 第 ④ 格成立且板内深度候选仍有效，由 9/17 晚生成的计划**逐一落具体标的、数量与价格规则**。
5. **大盘不破位定义（从严）**：创业板指**收盘**失守 **3,247.92** 且次日**加速下跌** → 触发从严；本日未触发。
6. **「板内深度候选」定义**：位于双确认板块内（元器件 / 半导体）**且**回落深度 ≤-8%（复盘口径）**且**站上 MA5 **且**量 ≥1.2×20 日均量。
7. **失效条件（任一出现即作废等待）**：①任一板块涨停 <5 或 ma5 下穿 ma10（重建中断、从零起算）；②板内深度候选全部消失；③创业板指从严条款触发；④`risk_signal.py` 输出审慎标签。

## 四、采纳复盘改进建议 #4

9/16 复盘提出「深度区清单纳入监控表」——本日 plan 的「监控清单」已**逐条列示 5 只跨日留存深度标的**（戈碧迦 920438.BJ / 中巨芯 688549.SH / 惠科股份 001399.SZ / 宏明电子 301682.SZ / 嘉德利 603435.SH），并标注 official 候选集与复盘口径的差异，便于 9/17 逐条核验延续性。

## 五、风险提示

- 本轮一旦建仓，**三层风控（<MA10 清仓 / <MA5 减半 / 3 日观察）+ 硬止损 + 审慎标签将重新启用，试仓无风控豁免**；
- 元器件 12 只涨停**分散于 PCB / 覆铜板 / 被动元件 / 终端件多方向、量能仅 1.06×**，未形成单一主线合力，反弹持续性弱于 9/11 的 PCB 集中冲榜形态；
- 半导体量能 1.37× 为当日最显著，但**绝对值仍取决于次日能否守住（9/15 教训：涨停 8 → 2 单日崩塌）**；
- 北交所 '92' 前缀误计已连续 7 日复发，**本轮已按 `.BJ` 口径修正**；若脚本沿用缺陷口径，元器件将虚增为 18、半导体 15，**足以把单腿伪造成双确认**——继续推动修复。
