# 开源证券 2026-06-26 盘前分析

## 核心要点

### 1. 市场分化加剧 — 半导体材料一枝独秀
- 昨日真正涨幅方向是**半导体、通信的材料**，其他板块普跌（**4200+只**个股下跌）
- 材料涨价是核心催化逻辑
- **兴业材料**走出 **5连板**，断板后大概率见顶

### 2. MLCC 板块异军突起
- 风华高科、国瓷材料大涨，逻辑偏猛
- 但**半导体整体趋势不如 MLCC 猛**，放缓交易节奏

### 3. 科创50趋势健康
- 周二仅休整一天，偏离值接近前15天调整节奏
- 当前回调**仍判断为倒车接人**
- 新易盛创新高大阳线，势头未减

### 4. 中报业绩预告开始发酵
- **恒逸石化**业绩预告暴增 **20倍**，今日大概率涨停
- 虽然不是科技材料主流板块，但反映中报业绩预期
- 中报行情趋势看到 **7.15**

### 5. 外部压力
- 外围下跌（韩国 + 美股）
- 美元收紧趋势 → 美股科技可能走弱
- 互联网媒体会放大悲观情绪，但**不要信，仍是倒车接人**

### 6. 公募基金限购
- 类比茅台20年前暴涨阶段的公募限购
- 对短期情绪有压制

## 今日策略

| 场景 | 策略 |
|------|------|
| **大幅低开** | ✅ **分批低吸**，防止周末利空，储备子弹 |
| **正常开盘** | 保持谨慎，主流不走断头铡大阴线则低吸 |
| **高开** | 不追涨 |
