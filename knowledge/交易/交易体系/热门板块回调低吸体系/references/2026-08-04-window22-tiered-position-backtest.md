# 2026-08-04 窗口22天 + 三层仓位分级 · 回测依据

## 背景

用户提议两点放松：① 个股和板块认证窗口延长至 22 天；② 添加试仓逻辑。按"先分析不落盘"原则先回测验证，确认后才落盘。本次回测全程零脚本代码变更（params + 文档 + prompt 层面）。

## 数据与方法

- **长样本**：2025-06-03 ~ 2026-08-03，286 个交易日，全市场日线 1,560,345 行（parquet 21MB）
- 拉取方式：`pro.daily(trade_date=td)` 按日批量，`time.sleep(0.25)`，`to_parquet` 存储
- 验证脚本模式：板块四维（A涨停≥5 / B多头MA5>MA10 / C连板梯队 / D量比≥1.2）逐日状态 → 持续N天判定 → 个股买点（10/22日内有涨停 + 回调≤-8% + 站上MA10 + 放量≥1.2×20日均量）→ 后续5日等权收益
- 大盘三档：创业板指 399006.SZ 当日涨跌幅（企稳>0 / 非极端弱-2%~0 / 极端弱≤-2%）

## 关键结果

### ① 窗口 10→22 天（个股认证）

| 组合 | n | 胜率 | 均值 |
|:-----|:----:|:----:|:----:|
| 买点(10天窗口·旧) | 3,016 | 37% | -1.22% |
| 买点(22天窗口·新) | 9,128 | 39% | -0.97% |
| 22天新增买点(10天不触发) | 6,112 | 40% | -0.84% |

→ 22天窗口样本扩大 3 倍，新增部分质量更好（潜伏末期形态：涨停→充分回调→站回MA10）。

### ② 板块热度窗口对比（叠加在22天买点上）

| 过滤 | n | 均值 |
|:-----|:----:|:----:|
| 无板块过滤 | 9,128 | -0.97% |
| 板块当日涨停≥5（现状） | 1,484 | -0.55% |
| 板块22日累计涨停≥20 | 5,921 | -1.06% |
| 板块当日A 且 多头B（双确认） | 991 | -0.16% |

→ **板块确认必须看当日**，22日累计反而更差（把过气板块当热门）。

### ③ 三层仓位分级（试仓逻辑）

| 组合 | n | 胜率 | 均值 |
|:-----|:----:|:----:|:----:|
| 22天买点 无板块过滤 | 9,128 | 39% | -0.97% |
| + 板块当日双确认 | 991 | 41% | -0.16% |
| + 双确认 + 大盘企稳(cyb>0) | 672 | 43% | **+0.25%** |
| + 双确认 + 大盘非极端(cyb>-2%) | 902 | 40% | -0.09% |
| + 仅板块多头 + cyb>0 | 2,999 | 40% | -0.52% |

→ 试仓条件必须卡在"板块当日双确认 + 大盘非极端弱"，用 1/4 仓位承担接近零期望的试错。**只靠板块多头就试仓不行**（-0.52%）。

### ④ 前置探索（为什么不能简单放宽）

同一数据源还验证过（未落盘，但结论重要）：
- "持续满足部分条件"（连续2-4天A/B/任意两条件）全部负期望（-1.7%~-5.05%），持续越久越差——持续=情绪高潮接盘，不是资金确认
- 任意3条件持续4天 -5.05%（n=47）：条件越多持续越久越危险
- 三重共振（严格板块确认+个股买点+大盘企稳）是唯一稳定为正组合
