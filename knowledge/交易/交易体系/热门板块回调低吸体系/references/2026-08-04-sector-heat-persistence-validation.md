# 板块热度条件"持续属性"验证（2026-08-04，286 交易日长样本）

## 背景

用户提议优化板块确认逻辑："三重共振（板块+个股+大盘）太严，如果某板块**持续几天**满足两个条件甚至一个条件，也算可以了。"

第一轮验证只测了**单日**板块条件 + 个股买点，被用户抓包（"两个条件的前提是持续，你确定测了持续这个属性吗"）。补测后才得到完整结论。

## 数据与方法

- 样本：2025-06-03 ~ 2026-08-03，**286 个交易日**，156 万行全市场日线（parquet 存 /tmp，21MB）
- 板块四维条件（对应 sector_heat.py 的维度）：
  - A = 当日涨停数 ≥ 5
  - B = 多头排列（等权 MA5 > MA10）
  - C = 连板梯队延续（前一日涨停≥2 且当日涨停≥2）
  - D = 量比 ≥ 1.2（当日板块总量 / 前5日均量）
- 个股买点（体系原逻辑，不变）：10日内有涨停 + 回调 ≥8% + 收盘>MA10 + 放量≥1.2x
- 收益口径：个股买入后次日~第5日累计涨幅
- 样本总数：3177 个个股买点信号

## 核心结果（后续5日累计等权收益）

| 组合 | n | 胜率 | 均值 |
|:-----|:----:|:----:|:----:|
| 仅个股买点（无板块过滤） | 3177 | 37% | -1.23% |
| AB 单日（对照组） | 184 | 40% | -0.39% |
| AB 持续3天 | 30 | 37% | -0.81% |
| AB 持续4天 | 10 | 50% | -1.99% |
| AB 持续3天 + 大盘企稳 | 19 | 42% | +0.30% |
| 任意2条件 持续2天 | 644 | 33% | -2.16% |
| 任意2条件 持续3天 | 506 | 32% | -2.11% |
| 任意2条件 持续4天 | 363 | 34% | -1.68% |
| 任意2条件 持续3天 + 大盘企稳 | 244 | 39% | -0.95% |
| 任意2条件 持续4天 + 大盘企稳 | 190 | 39% | -0.76% |
| 任意3条件 持续3天 | 88 | 23% | -3.57% |
| 任意3条件 持续4天 | 47 | 23% | -5.05% |
| 全市场等权 5 日基准 | — | — | +0.44% |

## 结论（数据不支持放宽板块确认）

1. **"持续更久"不改善结果，反而变差**：AB 单日 -0.39% → 持续3天 -0.81%；任意3条件持续3天 -3.57% → 持续4天 -5.05%。**持续 = 板块已涨很久 ≈ 情绪高潮，不是"资金刚确认"。**
2. **"任意两个条件"持续全部负期望**（-1.7% ~ -2.2%），加大盘企稳也只回到 -0.8%，仍跑不赢基准。
3. **唯一稳定为正的是原版三重共振**（严格板块确认 + 个股回调买点 + 大盘企稳）：短样本 +1.94%（n=49），长样本 AB单日+企稳 +0.30%（n=19，符号一致）。
4. 每加一层过滤（个股→板块→大盘），均值提升 2~2.8 个百分点——过滤层层有效，不是"太严"。

## 短样本陷阱（教训）

- 20 天短样本（7/7-8/3）曾显示"多头持续2天"胜率 79%——那是 7 月下旬普涨行情的幸存者偏差。
- 拉长到 286 天后同样信号只有 36%。**验证体系改动必须用长样本（≥1年），短样本只配当线索。**

## 对体系的意义

- 当前板块确认门槛（涨停≥10+梯队+多头）死磕的"涨停数"维度，恰是数据里预测力最差的（单日 A 40% 胜率负期望）。
- 若未来想优化：方向是**分级建仓**（严格三重共振→正常仓；AB单日+企稳→1/4试探仓），不是放宽确认条件。
- 若再有人提议"放宽板块热度门槛"，先引用本文件数据。
