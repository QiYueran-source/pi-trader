# 更新日志 · 2026-08-10

## 变更背景

此前体系脚本将运行产物写入 `交易体系/热门板块回调低吸体系/output/`，导致静态规则目录混入每日结果，也无法按运行日期完整追溯。此次调整保留历史更新日志原样，仅从本日志开始采用日期化过程资料。

## 目录职责

- `交易体系/热门板块回调低吸体系/` 只保留规则、参数、脚本、模板、参考资料和更新日志。
- 当日 JSON 与 Markdown 过程结果写入 `交易/过程资料/<日期>/热门板块回调低吸体系/`。
- 过程目录不再增加 `output/` 子目录。
- 2026-08-07 及之后的可恢复产物按新目录归档；2026-08-07 之前的历史过程资料不补迁。

## 参数和路径

新增 `params/process.json`，统一声明：

- `back_n: 3`：历史过程资料回看窗口，按交易日计算。
- 过程资料根目录。
- 滚动分析输入文件。
- 状态快照文件名。

新增 `scripts/process_paths.py`，统一处理：

- `YYYYMMDD` 与 `YYYY-MM-DD` 日期规范化。
- 当天过程目录计算。
- 前 N 个交易日的日期解析。
- 历史状态快照查找。

CLI 仍只传运行日期，例如 `--date 20260810`，不传具体快照路径。

## 脚本调整

`stock_picker.py`、`sector_heat.py`、`buy_signal.py`、`sell_signal.py`、`render_candidates.py` 和 `render_sector_heat.py` 的默认读写路径已切换到日期化过程目录；参数文件仍从体系目录的 `params/` 读取。

状态快照采用“当天优先、向前最多 `back_n` 个交易日继承最近有效快照”的规则，避免历史回放读取未来数据。

## Cron 调整

18:25 回放、18:30 复盘、18:35 生成计划的路径约定已统一到：

```text
交易/过程资料/{日期}/热门板块回调低吸体系/
```

缺失当天过程文件时不回退读取其他日期的分析结果；跨日状态才允许按 `back_n` 查找历史快照。

## 模块架构收敛

在过程资料日期化之后，体系进一步按业务职责收敛参数、脚本和产物命名。新结构不兼容旧脚本名、旧参数文件名和旧 `output/` 路径。

### 参数目录

```text
params/
├── selection.json    # 候选筛选
├── sector_heat.json  # 板块热度
├── entry.json        # 建仓技术信号
├── risk.json         # 持仓风控状态机
└── runtime.json      # 过程资料路径与日期规则
```

删除旧 `pick.json`、`buy.json`、`sell.json` 和 `process.json`。风险状态回溯深度改由 `risk.json` 的 `prudent_tag.snapshot_lookback_trading_days` 明确管理，不再使用泛化的 `back_n`。

### 脚本目录

```text
scripts/
├── runtime_support.py      # 严格参数校验、日期路径与快照定位
├── select_candidates.py    # 全市场候选筛选
├── sector_heat.py          # 候选行业热度事实
├── entry_signal.py         # 放量突破建仓信号
├── risk_signal.py          # 开盘、标签和日线风险评估
└── render.py               # 日期化 JSON → Markdown 渲染
```

删除旧 `stock_picker.py`、`buy_signal.py`、`sell_signal.py`、专项渲染脚本和重复的配置/路径包装脚本。

### 风控、渲染与文档

- `risk_signal.py` 合并开盘信号、审慎标签、MA5、MA10 和固定止损；动作固定为 `hold`、`observe`、`reduce`、`liquidate`。
- 风险产物统一为 `risk_signal.json`，同时写入 `prudent_tags.json` 与 `state.json`；generate-plan 不再手动补算 MA10。
- `render.py --date <日期> --template <目标>` 统一渲染 `candidates`、`sector_heat`、`entry_signal` 和 `risk_signal`。
- 已同步更新 `system.yml`、体系介绍、每日 SOP、代码速查和选股/建仓/风控规则；踩坑记录保留旧事件事实，但增加当前架构说明。
