# 口径收口：删除 promax 兜底、大盘三档落参数、文档去副本 | 2026-10-18

## 一、动因

审查发现三类问题：开盘段的 promax 备源依赖一个**不存在**的技能目录（必然失败，却把兜底伪装成可用）；「大盘三档」边界值硬编码在实现里而文档同值、`params/` 无键；文档里的阈值副本与产物样例混杂。用户裁定按建议处理。

## 二、变更清单

| 对象 | 变更 |
|:--|:--|
| `params/risk.json` | `opening_signal` 去掉 `fallback_sources`，加 `note` 说明只取 official；`schema_version` 1→2 |
| `params/entry.json` | 新增 `benchmark_tiers`（`stabilize_above_pct=0`、`extreme_weak_at_or_below_pct=-2`、`note`）；`schema_version` 1→2 |
| 实现 | 删除 `TUSHARE_PROXY_SCRIPTS`、`fetch_proxy_bars` 与 `import sys`；`fetch_opening_signal` 只取官方 `stk_mins`（失败即 `unavailable`）；`build_sector_environment` 从 `params/entry.json#benchmark_tiers` 读三档边界；校验器同步（entry 增键校验、risk 去 `fallback_sources` 校验）；`get_manifest` 的 `fact_sources.minutes` 同步 |
| `风控.md` | 降级链改为「只有 official」；`promax` 实测段标注为历史证据（兜底已撤销）；信号表与第二层阈值改键名（`#opening_signal.rapid_drop_pct`、`#exit_rules.ma5.*`）；样例中的通道值改 `official` |
| `建仓.md` | 三档表改键名表述；新增「口径归属」声明：涨停家数门槛（≥5）、多头排列与仓位比例（25%／1/4）为 **Agent 判断口径、不参数化**；大盘三档边界指针指向 `params/entry.json#benchmark_tiers` |
| `选股.md` | 分板涨停表标注「交易所规则，实现按本表判定，不参数化」 |
| 三份文档 | 各加一条「样例说明」：JSON 块都是示例，实况见 `交易/过程资料/<日期>/热门板块回调低吸体系/` |
| `templates/` | `process-documentation-pattern.md`／`-examples.md` 移入 `笔记/体系搭建/`（改名为 `体系过程资料落盘设计模式.md`／`体系过程资料落盘实践参考.md`，去掉 `system-id` Frontmatter）；`review-template.md` 标注「非渲染模板，19:10 复盘结构参考」 |
| 19:10 prompt | 复盘结构行补「（结构参考，非渲染模板）」并同步注册 |
