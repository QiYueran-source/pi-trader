# 更新日志 · 2026-06-16

## 体系初始化

搭建热门板块回调低吸体系完整目录结构，包含：

- **params/** — 超参数文件（pick.json, buy.json, sell.json）
- **scripts/** — 执行脚本（stock_picker, buy_signal, sell_signal, render_candidates）
- **output/** — 脚本输出目录
- **更新日志/** — 本日志
- 体系文档：体系介绍.md、体系运作流程.md、建仓.md、选股.md、风控.md、system.yml

## 性能优化

### stock_picker.py — 重写

| 改前 | 改后 |
|------|------|
| 逐只调用 `pro.daily(ts_code=xxx)` × 350次 | 按交易日批量拉全市场日线 × ~20次 |
| MA10/涨停统计逐只调接口 | 全在内存计算 |
| `--industry` 再跑一遍全市场 | 直接过滤候选列表 |
| **~130s** | **~16s** |

### buy_signal.py — 加缓存

- 优先读 `stock_picker` 写入的日线缓存（`~inbox/daily_cache.json`）
- 缓存命中 → 零API调用，秒出
- 缓存路径在 `.inbox/` 目录下，流水线跑完由 Agent 自动删除

### 流水线

- 18:25 模拟执行 → 18:30 复盘 → 18:35 生成计划（缓存仅在此 job 内部存活）
- cronjob 调度链、自选股状态机、日期格式等已全部就绪
