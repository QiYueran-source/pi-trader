# 热门板块回调低吸体系运作流程

## 运行入口

体系任务只通过 MCP 获取外部事实：`tushare-data` 提供交易日与行情，`trade-management` 提供 MNZH 模拟账户的交易、持仓和现金。过程资料、计划与复盘路径以 `system.yml` 为准。

## 每日顺序

1. 确认交易日；非交易日静默。
2. 回放当日正式计划，按计划登记模拟成交并获取账户快照。
3. 对照计划、执行与市场事实生成正式复盘；无成交时仍写维持结论。
4. 基于复盘、MCP 事实和当前账户快照，按 `选股.md`、`建仓.md`、`风控.md` 生成下一交易日唯一计划。

## 状态处理

- 正常无交易：生成复盘和计划的最小结论。
- 输入缺失、日期不一致或数据不可用：写入链路异常并停止依赖步骤。
- 过程资料记录事实，计划记录唯一动作，复盘记录计划与执行偏差。

## 边界

不在运行任务中修改静态规则、参数或历史资料；不使用旧脚本、旧 CLI 或旧 `output/` 作为数据、账户或执行依据。
