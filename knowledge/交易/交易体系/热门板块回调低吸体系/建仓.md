# 建仓规则

## 定位

建仓模块对候选股进行**二次筛选**，检出当前符合放量突破条件的个股。只有通过建仓信号检验的股票才真正进入交易环节。

## 输入

从日期化过程资料读取，默认 `交易/过程资料/{日期}/热门板块回调低吸体系/full_market_candidate.json`，也可通过 `--input` 指定热门行业候选：

```bash
# 全市场候选
entry_signal.py --date 20260810

# 热门行业候选
entry_signal.py --date 20260810 --input "archive/交易/过程资料/2026-08-10/热门板块回调低吸体系/hottest_industry_candidate.json"
```

## 开仓信号

### 条件一：放量突破 MA5

收盘价站上 5 日均线，说明短期趋势转强。

### 条件二：放量确认

当日成交量 > `volume_multiplier` × `volume_average_period` 日均量。量能是突破的佐证——无量突破可能是假突破。

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `volume_multiplier` | 1.2 | 当日成交量需达到均量的倍数 |
| `volume_average_period` | 20 | 均量计算周期 |
| `breakout_ma_period` | 5 | 突破均线周期 |

两个条件**同时满足**才视为有效开仓信号，缺一不可。

## 仓位分级（2026-08-04 新增）

> 基于 286 交易日（2025-06~2026-08）长样本回测设计。回测结论：个股买点无条件期望 -1.23%；叠加"板块当日双确认 + 大盘企稳"后转正 +0.25%~+1.94%；叠加"板块当日双确认 + 大盘非极端弱"约 -0.09%（接近零）。详见 `更新日志/2026-08-04.md`。

**开仓信号出现后，按以下三层分级决定仓位。** 分级判断在 18:35 生成计划时由 AI 完成（参考 `体系运作流程.md` 大盘三档判断）：

| 层级 | 条件（全部满足才触发） | 仓位 |
|:-----|:-----|:-----|
| 🟢 **正式仓** | 开仓信号 + 板块当日双确认（涨停≥5 且 多头排列）+ **大盘企稳**（创业板指当日 >0） | 正常单票仓位（约 25% 资金上限） |
| 🟡 **试仓** | 开仓信号 + 板块当日双确认 + **大盘非极端弱**（创业板指当日 >-2%） | 正常单票仓位的 **1/4**（约 6.25% 资金） |
| ⚪ **观察** | 开仓信号 + 其他（无板块双确认 / 大盘极端弱 ≤-2%） | 只记录 watchlist，不操作 |

### 试仓升级规则

试仓持仓期间，若同时满足 **板块当日双确认 + 大盘企稳（创业板>0）** → 可加仓至正式仓。加仓同样以次日开盘价成交。

### 试仓风控

试仓持仓**无风控豁免**，与正式仓相同：三层风控（审慎标签 / MA5 减半 / MA10 清仓）一视同仁。这是试仓安全的核心——进错后 MA10 破位即走，不会套牢。

## 买入价格

实际买入以**信号日的下一个交易日开盘价**成交。信号在收盘后检出，次日开盘执行。

## 执行方式

**人工判断 + 手动下单。** `entry_signal.py` 只负责检出技术信号，不执行交易。

## 脚本用法

```bash
# 默认读当天 full_market_candidate.json
entry_signal.py --date 20260615

# 从热门行业候选读
entry_signal.py --date 20260615 --input "交易/过程资料/2026-06-15/热门板块回调低吸体系/hottest_industry_candidate.json"

# dry-run
entry_signal.py --date 20260615 --dry-run

# 指定输出文件名
entry_signal.py --date 20260615 --output my_entry_signal.json
```
