# 建仓规则

## 定位

建仓模块对候选股进行**二次筛选**，检出当前符合放量突破条件的个股。只有通过建仓信号检验的股票才真正进入交易环节。

## 输入

从同日过程资料读取候选，由 `calculate(operation="entry_signal")` 决定读哪一份：

- 不传 `industries`：读 `交易/过程资料/{date}/热门板块回调低吸体系/full_market_candidate.json`（全市场候选）；
- 传 `industries`：读同日 `hottest_industry_candidate.json`（热门行业候选）。

> **样例说明**：本文的 JSON 块都是**示例**（调用样例或产物结构示例，数值取自当日实际产物），不代表当前值；当日实况见 `交易/过程资料/<日期>/热门板块回调低吸体系/` 下的同名文件。

```json
{"system_id": "hot_sector_pullback_system", "operation": "entry_signal", "date": "2026-10-15"}
{"system_id": "hot_sector_pullback_system", "operation": "entry_signal", "date": "2026-10-15", "industries": ["元器件"]}
```

## 开仓信号

### 条件一：放量突破 MA5

收盘价站上 5 日均线，说明短期趋势转强。

### 条件二：放量确认

当日成交量 > `volume_multiplier` × `volume_average_period` 日均量。量能是突破的佐证——无量突破可能是假突破。

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `volume_multiplier` | 1.2 | 当日成交量需达到均量的倍数 |
| `volume_average_period` | 20 | 均量计算周期 |
| `breakout_ma_period` | 5 | 突破均线周期 |

两个条件**同时满足**才视为有效开仓信号，缺一不可。均线与均量都含当日。

## 仓位分级（2026-08-04 新增；2026-10-18 补入前置闸门与衔接规则）

> 基于 286 交易日（2025-06~2026-08）长样本回测设计。回测结论：个股买点无条件期望 -1.23%；叠加"板块当日双确认 + 大盘企稳"后转正 +0.25%~+1.94%；叠加"板块当日双确认 + 大盘非极端弱"约 -0.09%（接近零）。详见 `更新日志/2026-08-04.md`。
> 2026-10-18 补入前置闸门与衔接规则，依据见 `更新日志/2026-10-18_首日不追与仓位分级衔接裁定.md`（含 2026-06-01~09-26 的①连续日数分层回测）。

**前置闸门（缺则一律不授权）**：板块双确认（①）须**连续 ≥2 个交易日**成立——① 的全新第 1 日不构成建仓依据（**首日不追**）。该闸门对三层分级全部生效，**不因大盘档位放宽**。

**开仓信号出现后，按以下三层分级决定仓位。** 分级判断在 19:25 生成计划时由 Agent 完成（大盘三档取当日 `sector_environment.json` 的 `benchmark`）：

| 层级 | 条件（全部满足才触发） | 仓位 |
|:-----|:-----|:-----|
| 🟢 **正式仓** | 前置闸门（① 连续 ≥2 日）+ 开仓信号 + 板块当日双确认（涨停家数 ≥5 且 多头排列）+ **大盘企稳** | 正常单票仓位（约 25% 资金上限） |
| 🟡 **试仓** | 前置闸门 + 开仓信号 + 板块当日双确认 + **大盘非极端弱** | 正常单票仓位的 **1/4**（约 6.25% 资金） |
| ⚪ **观察** | 其余情形（① 仅第 1 日 / 无板块双确认 / 大盘极端弱） | 只记录 watchlist，不操作 |

**衔接规则（2026-10-18 裁定）**

- ① 已连续 ≥2 日但 **② 仍为极端弱档** → ⚪ 观察，不授权建仓；**不因 ① 连续日数增加而放宽**。
- ① 连续 ≥2 日且 **② 已企稳** → 直接落 🟢 正式仓，不必先试仓再升级（正式仓条件本就含 ② 企稳；试仓只为承担中间档接近零的期望）。
- ① 连续 ≥2 日且 **② 为中间档（非极端弱）** → 🟡 试仓 1/4；持仓期间 ② 转企稳再按下方升级规则补仓。**这就是本体系的分批建仓路径（第 2 日起分两步），不设首日分批。**

> **口径归属**：本表是 **Agent 判断口径，不参数化**——「板块当日双确认」的涨停家数门槛（≥5）、「多头排列」与三档仓位比例（25%／1/4）只以本文为准，不在 `params/` 设键。
> 其中**大盘三档的边界值**由实现读取参数：`企稳 = 创业板指当日 > params/entry.json#benchmark_tiers.stabilize_above_pct`，`极端弱 = ≤ extreme_weak_at_or_below_pct`，中间为「非极端弱」；三档结果见当日 `sector_environment.json` 的 `benchmark.tier`。

### 试仓升级规则

试仓持仓期间，若同时满足 **板块当日双确认 + 大盘企稳（创业板>0）** → 可加仓至正式仓。加仓同样以次日开盘价成交。

### 试仓风控

试仓持仓**无风控豁免**，与正式仓相同：三层风控（审慎标签 / MA5 减半 / MA10 清仓）一视同仁。这是试仓安全的核心——进错后 MA10 破位即走，不会套牢。

## 买入价格

实际买入以**信号日的下一个交易日开盘价**成交。信号在收盘后检出，次日开盘执行。

## 执行方式

**人工判断 + 手动下单。** `entry_signal` 只负责检出技术信号，不执行交易。

检出结果写入 `交易/过程资料/{date}/热门板块回调低吸体系/entry_signal.json`（落 `knowledge/`），格式：

```json
{
  "date": "2026-10-15",
  "source": "交易/过程资料/2026-10-15/热门板块回调低吸体系/hottest_industry_candidate.json",
  "artifact": "entry_signal",
  "system_id": "hot_sector_pullback_system",
  "generated_at": "2026-10-15T11:27:33.945Z",
  "note": "判定口径与输入候选数的注记",
  "params": {
    "volume_multiplier": 1.2,
    "volume_average_period": 20,
    "breakout_ma_period": 5
  },
  "stats": {
    "total_candidates": 9,
    "with_daily_data": 9,
    "signals": 7
  },
  "signals": [
    {
      "code": "002134.SZ",
      "name": "天津普林",
      "industry": "元器件",
      "board_count": 2,
      "board_dates": ["20260918", "20261015"],
      "signal_date": "20261015",
      "close": 24.34,
      "breakout_ma": 22.264,
      "breakout_above_pct": 9.32,
      "volume_ratio": 1.34,
      "pass": true
    }
  ]
}
```

`signals` 按 `volume_ratio` 降序排列；`with_daily_data` 为候选中能取到日线数据的只数；实现另输出 `pullback_pct`、`volume`、`volume_ma`（分别对应候选回调深度、当日成交量与 20 日均量）。

## 调用方式

```json
{"system_id": "hot_sector_pullback_system", "operation": "entry_signal", "date": "2026-10-15", "dry_run": true}
```

`dry_run=true` 只返回结果不落盘；上游候选产物缺失时调用报错，不用历史产物替代。
