# 选股规则

## 定位

选股模块是热门板块回调低吸体系的第一环，从全市场筛选**近期涨停启动后回调企稳**的股票，输出候选池供[[交易/交易体系/热门板块回调低吸体系/建仓.md|建仓模块]]使用。

## 核心理念

强势股在涨停启动后，往往经历一段回调洗盘。如果回调不破关键技术位，随后放量突破时就是二次介入的时机。

**选股只在涨停股中找，不碰不涨停的。** 涨停 = 资金关注度，是筛选的第一道门槛。

## 选股流程

### 1. 涨停统计

在窗口期内（默认 22 个交易日），统计全市场所有股票的涨停次数：

- 通过 `pro.daily(trade_date=td)` 按日期拉取全市场数据
- 按板块判断涨停阈值：主板 9.8%、创业板/科创板 19.5%、北交所 29.5%
  - **口径说明（2026-09-27 修正）**：板块/市场涨停腿统计**含北交所**（保持与公开市场数据一致）；北交所一律以 **`.BJ` 后缀**判定（现行号段 920xxx，**禁用 8/4 前缀匹配**），并排除**上市首日**（`list_date == 当日`，无涨跌幅限制）与 N/C 开头新股。判定实现见 `scripts/select_candidates.py` 和 `scripts/sector_heat.py`；涨停阈值与新股排除口径在本体系内统一维护，不在其他脚本重复实现。
  - **ST 无独立阈值（纠错）**：实测全市场 199 只 ST 的限幅 = 所属板块限幅（主板 10% / 双创 20% / 北交所 29.9%），**0 只 5%**——旧口径「ST 一律 5%」已证伪。是否把 ST 计入双确认涨停腿是**策略口径**（默认剔 ST 虚增），与限幅判定分开处理。
- 涨幅 ≥ 对应阈值即视为涨停

写入 `params/selection.json`：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `limit_up_window_days` | 22 | 统计最近 N 个交易日内的涨停 |
| `min_limit_up_count` | 1 | 至少涨停次数 |
| `max_limit_up_count` | 2 | 最多涨停次数，排除高位连板 |

### 2. 板数筛选

保留涨停 **1-2 板** 的股票：

- 0 板 → 不涨停，排除（无资金关注）
- 1-2 板 → 候选（启动初期，回调空间大）
- 3 板及以上 → 排除（处于高位，风险大）

同时补充股票名称和行业信息（`pro.stock_basic` 接口）。

### 3. 均线检查

检查当前价格是否站上 MA10（10日均线），确保回调不破位。

**两种通过方式：**

| 方式 | 条件 |
|------|------|
| **从未破位** | 始终在 MA10 上方运行 |
| **反弹站回** | 曾跌破 MA10，但在 `破位反弹窗口` 天内反弹站回，且站回后未再次跌破 |

**回升后不再回落校验：** 从站回 MA10 之日起，每日收盘价都必须 ≥ 当日 MA10。只要有任意一天再次跌破，即排除。这是为了防止假反弹。

写入 `params/selection.json`：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `pullback_ma_period` | 10 | 回调均线周期 |
| `rebound_window_days` | 5 | 跌破后最多 N 个交易日站回 |

### 4. 行业筛选

通过 `--industry` 参数指定关注行业，仅在候选池中保留匹配行业的股票。热门行业的判断基于 **板块热度分析**（`sector_heat.py` 的四个维度量化数据），不再依赖AI网络搜索。

判断流程：
1. 运行 `sector_heat.py --date {日期}` 计算候选行业热度事实
2. 运行 `render.py --date {日期} --template sector_heat` 渲染 Markdown 供 AI 阅读
3. AI 根据量化事实判断热门行业
4. **AI 判断完成后，落过程资料 `板块热度研判.md`**（路径：`交易/过程资料/{日期}/热门板块回调低吸体系/`），记录候选板块数据 + 选/不选的理由
5. 用 `select_candidates.py --industry` 筛选对应行业候选股，结果写入 `交易/过程资料/{日期}/热门板块回调低吸体系/hottest_industry_candidate.json`

```bash
# 板块热度分析
sector_heat.py --date 20260810
render.py --date 20260810 --template sector_heat

# 单行业筛选
select_candidates.py --date 20260810 --industry 半导体

# 多行业
select_candidates.py --date 20260810 --industry "半导体,通信"

# JSON 数组
select_candidates.py --date 20260810 --industry '["半导体","通信"]'
```

## 输出

选股结果写入 `交易/过程资料/{日期}/热门板块回调低吸体系/full_market_candidate.json`。行业筛选时通过 `--output hottest_industry_candidate.json` 写入同一日期目录，输出结构如下：


## 脚本用法

```bash
# 全量市场选股
select_candidates.py --date 20260615

# 行业筛选
select_candidates.py --date 20260615 --industry 半导体

# dry-run 不写文件
select_candidates.py --date 20260615 --dry-run

# 指定输出文件名
select_candidates.py --date 20260615 --output my_candidates.json
```
