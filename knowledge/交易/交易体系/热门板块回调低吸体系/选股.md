# 选股规则

## 定位

选股模块是热门板块回调低吸体系的第一环，从全市场筛选**近期涨停启动后回调企稳**的股票，输出候选池供[[交易/交易体系/热门板块回调低吸体系/建仓.md|建仓模块]]使用。

全市场日线与股票基础资料由体系 MCP 取数：日线按 `trade_date` 逐日拉取，名称、行业与上市日期取自基础资料。候选筛选、板块热度与板块环境都由 `hot-sector-pullback-system` 计算，口径实现见 `交易/交易体系/热门板块回调低吸体系/MCP介绍.md`。

## 核心理念

强势股在涨停启动后，往往经历一段回调洗盘。如果回调不破关键技术位，随后放量突破时就是二次介入的时机。

**选股只在涨停股中找，不碰不涨停的。** 涨停 = 资金关注度，是筛选的第一道门槛。

## 选股流程

### 1. 涨停统计

在窗口期内（`params/selection.json#limit_up_window_days`）统计全市场所有股票的涨停次数。涨停判定为**分板精确阈值**（交易所规则，实现按本表判定，不参数化）：

| 板块 | 阈值 |
|------|------|
| 北交所（`.BJ` 后缀） | 30% |
| 创业板 / 科创板（`30`／`68` 开头） | 20% |
| 主板 | 10% |
| ST（名称含 ST） | 5% |

- 涨幅 ≥ 对应阈值（含容差，见 `params/selection.json`）即视为涨停。
- 北交所一律以 **`.BJ` 后缀**判定（现行号段 920xxx，**禁用 8/4 前缀匹配**）；排除**上市首日**（`list_date == 当日`，无涨跌幅限制）与 N/C 开头新股。
- 板块热度与全市场板块环境中的涨停行业分布只统计 **clean（剔 ST）**；**ST 无独立市场限幅**——2026-09-27 全市场实测 199 只 ST 的限幅与所属板块一致（主板 10%／双创 20%／北交所 29.9%），**0 只为 5%**。实现仍按上表以 ST 5% 判定（与「剔 ST 统计」组合后不影响 clean 口径），该差异已由 2026-10-17 口径裁定确认维持，记于 `更新日志/2026-10-17_运行定义迁入 MCP.md`。
- **全市场板块环境的统计口径**（`sector_environment.json`）：涨跌家数、成交额与放量对比、涨停/跌停家数均沿用本节同一新股排除口径（剔 N/C 新股与上市首日）；涨停行业分布与样本只计 clean（剔 ST），跌停剔 ST。

写入 `params/selection.json`：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `limit_up_window_days` | 22 | 统计最近 N 个交易日内的涨停 |
| `min_limit_up_count` | 1 | 至少涨停次数 |
| `max_limit_up_count` | 2 | 最多涨停次数，排除高位连板 |

### 2. 板数筛选

保留涨停 **1-2 板** 的股票：

- 0 板 → 不涨停，排除（无资金关注）
- 1-2 板 → 候选（启动初期，回调空间大）
- 3 板及以上 → 排除（处于高位，风险大）

同时补充股票名称和行业信息（来自 tushare 基础资料）。

### 3. 均线检查

检查当前价格是否站上 MA10（10 日均线），确保回调不破位。**判定逐日重算 MA10 后逐日比较**，不只看最新一根：

**两种通过方式：**

| 方式 | 条件 |
|------|------|
| **从未破位** | 窗口内每日收盘均 ≥ 当日 MA10 |
| **反弹站回** | 曾跌破 MA10，但在 `破位反弹窗口` 天内站回，且站回后未再次跌破 |

**回升后不再回落校验：** 从站回 MA10 之日起，每日收盘价都必须 ≥ 当日 MA10。只要有任意一天再次跌破，即排除。这是为了防止假反弹。

回调深度记为 `pullback_pct =（当日收盘 − 窗口内涨停日最高价峰值）/ 峰值 × 100`。

写入 `params/selection.json`：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `pullback_ma_period` | 10 | 回调均线周期 |
| `rebound_window_days` | 5 | 跌破后最多 N 个交易日站回 |

### 4. 行业筛选

热门行业的判断基于**板块热度与全市场板块环境**两份量化事实，不依赖网络搜索：

1. `calculate(operation="sector_heat", date="{date}")` 计算候选行业热度（`sector_heat.json`）与全市场板块环境（`sector_environment.json`）；
2. `render(artifact="sector_heat", date="{date}")` 渲染 Markdown 供阅读（可选）；
3. Agent 根据量化事实判断热门行业；
4. 判断落过程资料 `板块热度研判.md`（`交易/过程资料/{date}/热门板块回调低吸体系/`，落 `knowledge/`），记录候选板块数据 + 选/不选的理由；
5. `calculate(operation="select_candidates", date="{date}", industries=["元器件"])` 按行业筛选候选股，写入 `hottest_industry_candidate.json`。

`sector_heat.json` 每个行业的字段：`short_ma_pct`／`long_ma_pct`（板块成分股当日平均涨幅的 5／10 日均值）、`trend`（`short > long` 记「多头排列」，否则「空头」）、`volume_ratio`（板块当日总成交量 ÷ 前 5 日均量）、`limit_up_count`／`limit_up_clean`。

## 输出

全市场筛选写入 `交易/过程资料/{date}/热门板块回调低吸体系/full_market_candidate.json`（落 `knowledge/`）；传入 `industries` 时同一操作写 `hottest_industry_candidate.json`。结构如下：

> **样例说明**：本文的 JSON 块都是**示例**（调用样例或产物结构示例，数值取自当日实际产物），不代表当前值；当日实况见 `交易/过程资料/<日期>/热门板块回调低吸体系/` 下的同名文件。

```json
{
  "date": "2026-10-15",
  "artifact": "full_market_candidate",
  "system_id": "hot_sector_pullback_system",
  "generated_at": "2026-10-15T11:27:33.945Z",
  "note": "窗口与判定口径的注记",
  "params": {
    "limit_up_window_days": 22,
    "min_limit_up_count": 1,
    "max_limit_up_count": 2,
    "pullback_ma_period": 10,
    "rebound_window_days": 5
  },
  "stats": {
    "total_candidates": 146,
    "candidate_sectors": 55
  },
  "candidates": [
    {
      "code": "000498.SZ",
      "name": "山东路桥",
      "industry": "建筑工程",
      "board_count": 1,
      "board_dates": ["20260924"],
      "current_close": 6.32,
      "pullback_ma": 6.152,
      "pullback_pct": 2.73
    }
  ]
}
```

`stats` 另含 `total_limit_up_stocks`（窗口内命中涨停的股票数）。按行业筛选时另带 `industry` 数组字段，记录本次选定的行业；`candidates` 按 `pullback_pct` 升序排列。

## 调用方式

```json
{"system_id": "hot_sector_pullback_system", "operation": "select_candidates", "date": "2026-10-15"}
{"system_id": "hot_sector_pullback_system", "operation": "select_candidates", "date": "2026-10-15", "industries": ["元器件"], "dry_run": true}
```

`dry_run=true` 只返回结果不落盘；不传 `industries` 即全市场筛选。
