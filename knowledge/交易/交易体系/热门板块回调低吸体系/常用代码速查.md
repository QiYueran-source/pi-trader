# 热门板块回调低吸体系 · 常用代码速查

## 使用原则

- 脚本支持 `YYYYMMDD` 和 `YYYY-MM-DD`，过程目录统一使用 `YYYY-MM-DD`。
- 全市场日线按交易日批量调用 `pro.daily(trade_date=td)`，不按股票逐个请求。
- 当前项目使用容器中的 `/opt/venv/bin/python`；推荐通过 `python` 或脚本 shebang 启动。
- 批量调用遵守 Tushare 限速，调用间隔不少于 `sleep(0.3)`。

## 脚本入口

| 脚本 | 功能 | 输出 |
|---|---|---|
| `prepare_shared_sector_context.py` | 可选复用同日红利科创 ETF 双网格环境事实 | `shared_sector_context.json` |
| `select_candidates.py` | 全市场候选筛选 | `full_market_candidate.json` |
| `sector_heat.py` | 候选行业专项热度 | `sector_heat.json` |
| `entry_signal.py` | 建仓技术信号 | `entry_signal.json` |
| `risk_signal.py` | 持仓风险评估 | `risk_signal.json`、`prudent_tags.json`、`state.json` |
| `render.py` | JSON 渲染为 Markdown | 对应 `.md` 文件 |

过程产物统一写入：

```text
knowledge/交易/过程资料/<YYYY-MM-DD>/热门板块回调低吸体系/
```

## 标准流水线

```bash
python scripts/prepare_shared_sector_context.py --date 20260810
python scripts/select_candidates.py --date 20260810
python scripts/sector_heat.py --date 20260810
python scripts/render.py --date 20260810 --template sector_heat
python scripts/select_candidates.py --date 20260810 --industry "半导体,通信" --output hottest_industry_candidate.json
python scripts/entry_signal.py --date 20260810 --input "knowledge/交易/过程资料/2026-08-10/热门板块回调低吸体系/hottest_industry_candidate.json"
python scripts/risk_signal.py --date 20260810 --positions /tmp/positions.json
```

脚本目录为：

```text
knowledge/交易/交易体系/热门板块回调低吸体系/scripts/
```

## 共享板块环境事实

来源文件必须是同日、结构有效的：

```text
knowledge/交易/过程资料/<日期>/红利科创ETF双网格体系/sector_facts.json
```

共享文件保留 `source_system_id`、来源路径和事实副本。来源缺失时只输出不可用结果，不替代本体系的 `sector_heat.py`。

## `risk_signal.py` 持仓输入

输入是 `{ts_code: buy_price}` 映射文件：

```json
{
  "301348.SZ": 40.0,
  "600206.SH": 35.0
}
```

不能传入嵌套持仓对象或内联 JSON 字符串。分钟数据降级目录通过 `TUSHARE_PROXY_SCRIPTS` 环境变量配置；未配置时使用项目内默认位置。

## 常用 Tushare 接口

```python
pro.daily(trade_date="20260810", fields="ts_code,open,close,high,vol,pct_chg")
pro.stock_basic(fields="ts_code,name,industry,list_date")
pro.trade_cal(exchange="SSE", start_date="20260701", end_date="20260810", fields="cal_date,is_open")
pro.stk_mins(ts_code="301348.SZ", freq="5min", start_date="2026-08-10 09:30:00", end_date="2026-08-10 10:00:00")
```

风控参考价优先使用日线 `open`；分钟线只用于开盘形态判断。代理返回分钟数据时必须校验 `trade_time` 日期与目标日期一致。

## 检查命令

```bash
python -m py_compile scripts/*.py
python scripts/select_candidates.py --help
python scripts/sector_heat.py --help
python scripts/entry_signal.py --help
python scripts/risk_signal.py --help
```

不需要真实行情时使用各脚本的 `--dry-run`，不要用测试数据替代正式过程产物。
