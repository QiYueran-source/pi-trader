# 热门板块回调低吸体系 · 数据与账户工具速查

体系运行只使用 MCP，不调用脚本、旧 CLI 或直接 Tushare 接口。

## 数据入口

| 事实 | MCP 工具 |
|---|---|
| 交易日 | `tushare-data.get_trade_calendar` |
| 全市场日线 | `tushare-data.get_market_daily` |
| 个股日线与基础资料 | `get_stock_daily`、`get_stock_basic` |
| 分钟线 | `get_stock_minutes` |
| 账户快照 | `trade-management.portfolio_snapshot` |
| 交易与盈亏 | `trade_list`、`trade_pnl` |

## 过程资料

过程资料写入 `knowledge/交易/过程资料/<YYYY-MM-DD>/热门板块回调低吸体系/`。每份事实记录数据日期、MCP 工具、请求参数、`source`、`warnings` 与账户快照时点。

## 使用边界

同一轮运行的事实必须来自同一交易日；分钟线仅用于规则所需的开盘形态判断。数据不可用、来源告警未消除或日期不一致时，记录链路异常，不用旧数据或估算结果替代。
