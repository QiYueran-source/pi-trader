# 热门板块回调低吸体系 · 常用代码速查

## 使用原则

1. 脚本 `--date` 支持 `YYYYMMDD` 与 `YYYY-MM-DD`，过程目录统一为 `YYYY-MM-DD`。
2. 全市场日线按交易日批量调用 `pro.daily(trade_date=td)`，不要按股票逐个请求。
3. 当前直接按需拉取 Tushare 数据，不设置体系级缓存。
4. 批量调用遵守 Tushare 限速，调用间隔不少于 `sleep(0.3)`。

## 脚本入口

| 脚本 | 功能 | 输出 |
|---|---|---|
| `prepare_shared_sector_context.py` | 可选复用同日网格板块环境事实 | `shared_sector_context.json` 或不可用结果 |
| `select_candidates.py` | 全市场候选筛选 | `full_market_candidate.json` 或指定候选文件 |
| `sector_heat.py` | 候选行业专项热度 | `sector_heat.json` |
| `entry_signal.py` | 建仓技术信号 | `entry_signal.json` |
| `risk_signal.py` | 持仓风险评估 | `risk_signal.json`、`prudent_tags.json`、`state.json` |
| `render.py` | 过程资料 JSON 渲染 | 对应 Markdown |

所有业务产物写入：

```text
交易/过程资料/{date}/热门板块回调低吸体系/
```

## 同日共享板块环境事实

```bash
prepare_shared_sector_context.py --date 20260810
```

脚本只接受同日、结构有效的：

```text
交易/过程资料/{date}/红利ETF网格/sector_facts.json
```

成功时复制为 `shared_sector_context.json`，保留 `source_system_id`、来源路径和完整事实副本；网格体系当日未运行时，脚本只报告不可用，不阻断低吸体系。

该共享文件是全市场行业背景，不替代 `sector_heat.py` 对候选行业的连板、均线和量比专项分析。

## 标准流水线

```bash
prepare_shared_sector_context.py --date 20260810
select_candidates.py --date 20260810
sector_heat.py --date 20260810
render.py --date 20260810 --template sector_heat
select_candidates.py --date 20260810 --industry "半导体,通信" --output hottest_industry_candidate.json
entry_signal.py --date 20260810 --input "交易/过程资料/2026-08-10/热门板块回调低吸体系/hottest_industry_candidate.json"
risk_signal.py --date 20260810 --positions /tmp/positions.json
```

## `risk_signal.py` 持仓输入

输入是 `{ts_code: buy_price}` 映射文件：

```json
{
  "301348.SZ": 40.0,
  "600206.SH": 35.0
}
```

不能传入嵌套持仓对象或内联 JSON 字符串。

## 常用 Tushare 接口

```python
# 全市场日线
pro.daily(trade_date="20260810", fields="ts_code,trade_date,close,high,vol,pct_chg")

# 股票名称与行业
pro.stock_basic(fields="ts_code,name,industry")

# 交易日历
pro.trade_cal(exchange="SSE", start_date="20260701", end_date="20260810", fields="cal_date,is_open")

# 开盘分钟线（持仓风控）—— 官方限频 1 次/小时，被拒走 promax 降级
pro.stk_mins(ts_code="301348.SZ", freq="5min", start_date="2026-08-10 09:30:00", end_date="2026-08-10 10:00:00")

# 降级通道（promax）：sys.path.insert(0, "/opt/data/skills/data/tushare-proxy/scripts"); from ts_proxy import get
#   get("stk_mins", ts_code=..., freq="5min", start_date=..., end_date=...)  # 必须校验 trade_time 日期 == 目标日

# 第一层参考价取「日线 open」（权威开盘价，不用分钟首根 open）
pro.daily(trade_date="20260810", fields="ts_code,open,close")
```

注意：`pro.daily()` 不返回股票名称或行业；`stock_basic` 单次查询有数量限制，候选筛选脚本已按批次处理。
