# 主观多头体系介绍

> ⚠️ **占位体系**：本目录当前**只有 `system.yml` 与本文两个文件**，没有规则库、参数、脚本和模板。建立它的目的是给「主观多头的交易计划」一个合规挂靠点（`system-id` ＋ 体系介绍链接），**不代表该体系已建成或规则已定型**。规则由用户逐步人工拍板后补充。约束见 [[交易/交易体系/RULES.md|交易体系规则]] 与 [[交易/RULES.md|交易规则]]。

## 定位

主观多头 = 用户在 **YHZQ（银河）** 与 **KYZQ（开源）** 两个实盘账户上、**人工主观决策**的资产组合。它不是机械规则体系：没有选股脚本、没有信号计算、没有状态机，买卖判断来自投顾盘前分析 ＋ 用户个人判断。

**口径变更（2026-10-10）**：此前记录为「KYZQ 同属 `subjective_long`，**不新建体系**」（2026-09-29 参数更新）、「账本口径，**非登记体系**」（2026-10-08 整体计划）。用户 2026-10-10 决定**新建本占位体系**，使交易计划、账本与复盘统一挂 `subjective_long`。历史文件不回溯修改。

## 交易计划格式约定

- **路径**：`交易/交易计划/{交易日}/主观多头.md`（与各体系计划同目录；命名沿用 `交易计划/RULES.md` 的 `<体系名称>.md`，不加 `_交易计划` 后缀）。
- **正文只写动作**，风格与 09:15 全体系计划推送一致，一行一个动作：

```markdown
- 159781.SZ 双创ETF ｜ 买入 ｜ 10:00 市价，回收资金等额
- 159819.SZ AI ETF ｜ 卖出 3,000 份 ｜ 10:00
｜失效：回收资金不足则买入腿缩减
```

- frontmatter 仍按 `交易计划/RULES.md` 与总规则要求齐全：`uuid / system-id / system-name / trade_type / date / account_id / tags / updated / links`，并至少链接一份 `体系介绍.md`。
- **生成时点**：盘前，且必须等投顾盘前分析到位之后（约 09:00–09:25）。因此本体系**没有「盘后生成次日计划」的 cron**——由 09:15 全体系计划通报负责**提醒**用户补，用户回话后由会话落盘。
