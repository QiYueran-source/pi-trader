# system.yml 改为体系声明（不再复制参数取值） | 2026-10-18

> 说明（2026-10-18 同日）：本文记录的「改为纯声明」随后被同日裁定取代——`system.yml` 已整体删除，见 `交易/交易体系/招商双债LOF择时体系/更新日志/2026-10-18_删除system.yml.md`。本文作为当日过程记录保留。

## 一、动因

`system.yml#state` 与 `params/runtime.json` 的 `strategy_state_file`／`state_lookup`／`state_anchor_date` 同值两份，`process_output.artifacts` 与 runtime 的三个文件名同值两份；而实现只读 `params/runtime.json`，`system.yml` 仅被做存在性校验。用户 2026-10-18 裁定：`system.yml` 不承担参数，只做体系声明。

## 二、变更

| 字段 | 变更 |
|:--|:--|
| `state` | 删去 `strategy_state_file`／`lookup`／`content_roots`／`anchor_date` 取值，改为一行说明「状态文件、查找方式、锚日与双头根目录均以 `params/runtime.json` 为准」 |
| `process_output` | 保留落盘根位置（含 `{date}` 与体系名称），删去 `artifacts` 文件清单，注明「文件名见 `params/runtime.json`」 |
| `overview` | 去掉标的代码与费率取值，改为「标的与费率见 `params/instrument.json`」 |
| `parameters`／`templates` | 保留 `root` 指针（本就需要指向目录） |
| `maturity`／`account-id`／`service`／`operations`／`rules`／`boundaries`／`utilities` | 保留（体系声明） |

文档同步：`体系介绍.md`「过程产物」、`MCP介绍.md`「过程产物」改为「文件名以 `params/runtime.json` 为准；落盘位置见 `system.yml#process_output.root`」；`MCP介绍.md` 目录树中 `system.yml` 的注释改为「体系声明……不复制参数取值」。

## 三、验证

- 服务启动校验（`system.yml` 存在）与全部工具行为不变；`validate_parameters`、`calculate`、`replay_check`、`render` 复测通过。
- 复扫：`system.yml` 中已无与 `params/` 同值的参数取值（`account-id` 作为体系声明保留，机器可读值仍在 `params/instrument.json#account`）。

## 四、遗留

- 其余三体系（双网格、轮动、热门板块）的 `system.yml` 仍有同类重复（尤其 `process_output.artifacts` 与 `state` 块），是否按同一口径逐一体检由用户裁定。
