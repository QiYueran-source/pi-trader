# 招商双债LOF择时体系

## 定位

本体系针对招商双债增强债券 LOF（`161716.SZ`），利用债券基金的低波动和均值回归特征，通过固定规则生成波段买卖计划。

```text
收盘行情
  ↓
机械信号计算
  ↓
理论策略状态 + 当日信号
  ↓
Agent gen_plan
  ↓
下一交易日唯一交易计划
  ↓
用户手动执行
```

体系当前只负责**生成计划**。实际下单、交易记账、持仓管理、成交价格、手续费和盈亏核算由用户结合 `hermes-trade` 完成，不属于本体系运行链路。本体系不查询其数据库，也不依赖实际持仓状态。

## 四规则闭环

| 规则 | 触发条件 | 次日动作 |
|---|---|---|
| 买入 | 空仓连续 `confirmation_days` 天收盘不创新低，且当前收盘高于谷值 | 买入 |
| 卖出 | 持仓连续 `confirmation_days` 天收盘不创新高，且当前收盘低于峰值 | 全部卖出 |
| 止损 | 收盘跌破买入前谷值 | 全部卖出 |
| 追回 | 卖出后收盘重新突破卖出时峰值 | 买入 |

止损优先于普通卖出判断。参数和计数语义以 `params/timing.json` 为准。

## 信号与执行动作

`signal_facts.json` 使用英文机器枚举；报告和交易计划将其翻译为中文。

- `signal` 记录收盘触发原因：`buy`、`sell`、`stop_loss_sell`、`chase_buy` 或 `null`；
- `next_trading_action` 记录次日执行动作：`buy`、`sell_all`、`hold` 或 `no_action`；
- `sell` 与 `stop_loss_sell` 的原因不同，但次日动作均为 `sell_all`；
- `hold` 表示理论持仓继续持有，`no_action` 表示理论空仓且不操作。

## 理论策略状态

过程资料中的 `strategy_state.json` 表示：

> 基于当日收盘已确认的信号，假设下一交易日交易计划已按要求执行后的理论策略状态。

它不是 YHZQ 的实际账户状态。若用户某日未按计划执行，需要人工告知并修正策略状态；系统不会自动发现执行偏差。

## 过程产物

```text
交易/过程资料/{date}/招商双债LOF择时体系/
├── strategy_state.json    # 理论状态：峰值、谷值、计数器、锚点
├── signal_facts.json      # 当日收盘信号与次日动作
└── signal_report.md       # Jinja 渲染报告
```

参数目录只保存静态配置，不保存行情、信号或策略状态。

## 当前边界

- 单标的验证：`161716.SZ`；
- 账户信息仅用于交易计划标识：`YHZQ`；
- 计划金额来自静态参数，实际成交由用户决定；
- 实际成交、成本、手续费和盈亏由 `hermes-trade` 处理，不回写本体系的理论状态；
- Agent 不重新发明择时规则，只读取结构化信号并生成计划；
- 当前不包含自动执行、成交回报、账户对账和自动复盘。

## 回测依据与局限

当前参数依据 2019-01 至 2026-08 的历史回测，`confirmation_days = 2` 为当前验证结果。回测结果不等于未来收益承诺；策略仅验证过单一标的，跨品种稳健性仍待验证。
