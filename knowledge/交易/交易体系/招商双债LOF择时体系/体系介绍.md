## 基本信息

- 标的：`161716.SZ` 招商双债增强债券（LOF）
- 类型：机械择时
- 成熟度：执行体系
- 关联账户：`YHZQ`
- 运行方式：收盘确认信号，下一交易日开盘人工执行
- 运行定义：`.pi/mcp-servers/trade-system/zslof_timing_trade/`（实现、契约、参数、模板的唯一来源；MCP 注册名 `zslof-timing-trade`）

本体系维护理论策略状态，不查询实际账户，不自动下单。实际成交、持仓、手续费和盈亏由用户另行管理。

## 核心逻辑

- 空仓时，连续确认不创新低并反弹，生成买入信号。
- 持仓时，连续确认不创新高并回落，生成卖出信号。
- 收盘跌破买入前谷值，生成止损卖出信号。
- 卖出后收盘突破卖出时峰值，生成追回买入信号。

信号优先级和计数语义见 `交易/交易体系/招商双债LOF择时体系/择时参数.md`，实际参数以 `params/timing.json` 为准。

## 运行链路

```text
收盘行情（tushare-data MCP）
→ 体系 MCP zslof-timing-trade：推进理论状态与信号（replay_check 可复算校验）
→ strategy_state.json + signal_facts.json + signal_report.md
→ 下一交易日交易计划（任务按 SOP 2.4 写）
```

JSON 是机器事实与状态来源，Markdown 是可读展示产物。运行定义与接口见 `交易/交易体系/招商双债LOF择时体系/MCP介绍.md`，执行细节见 `交易/交易体系/招商双债LOF择时体系/体系运作流程.md` 第 2 节。
