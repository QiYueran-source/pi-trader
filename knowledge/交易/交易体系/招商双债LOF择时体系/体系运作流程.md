# 招商双债LOF择时体系运作流程

## 运行入口

任务只通过 `tushare-data` MCP 确认交易日和读取行情。参数、过程资料和正式计划路径以 `system.yml` 与 `择时参数.md` 为准。

## 收盘顺序

1. 确认交易日；非交易日不生成产物。
2. 获取规则所需的收盘数据，按 `择时参数.md` 计算机械信号与理论状态。
3. 写入日期化过程资料，生成下一交易日唯一正式交易计划；无信号时仍生成不操作计划。

## 边界

- 本体系只生成信号和计划，不查询账户、不下单。
- 数据或参数无效时记录链路异常，不生成计划。
- 计划金额只按 `择时参数.md` 的规范渲染，且取自当日有效参数。
