# 红利科创ETF双网格体系风控规则

## 定位

风控模块只采集风险事实和阈值命中情况，不直接切换防守档、不直接暂停交易、不直接下单。最终动作由 Agent 结合调节器规则、投顾与市场事实给出建议，经**人工审批**后生效（见 `风控调节器.md`）。

当前静态阈值以 `params/risk.json` 为准，风险事实采集范围为 `dividend` 与 `growth` 双标的。风险事实口径以本文为准，调节与审批规则见 `风控调节器.md`。

## 风险事实

风险事实由 1810 任务调用 `scripts/collect_risk_facts.py`（或按同一口径用 MCP 复算）读取当日行情、价格边界与实际持仓，生成：

```text
交易/过程资料/{date}/红利科创ETF双网格体系/risk_facts.json
```

其中包含：

- 收盘价、日涨跌幅、量比和平均振幅；
- 连续下跌交易日数及累计跌幅；
- 最近网格校准价格与上下边界；
- 实际持仓份额、市值与资金占比；
- 价格边界、仓位熔断、连续下跌、放量下跌和异常上涨的布尔命中结果。

## 风险边界

| 分类 | 规则来源 | 含义 |
|---|---|---|
| 资金约束 | `params/regulator.json#capital_guard` | 资金使用率分档、单腿权重上限与停买/恢复 |
| 价格边界 | `price_boundary` | 相对最近有效网格校准价格的上下偏离 |
| 市场异常 | `market_anomalies` | 连跌、放量下跌、异常上涨的事实阈值 |
| 波动窗口 | `volatility` | 平均振幅和量比的统计窗口 |

价格边界基准（v4）取自 `params/risk.json#price_boundary.by_instrument`（含各标的参考价与上下边界），不能用当天收盘价作为自身基准；不再依赖网格校准产物。

## Agent 使用规则

```text
risk_facts.json + sector_facts.json + 文本研究
  ↓
Agent 汇报事实、硬闸占用与信号，给出建议防守档（不生效）
  ↓
人工审批后生成交易计划（留痕 human_review.json）
```

- 阈值命中不等于自动卖出或切换防守档；
- 未命中不等于风险不存在；
- 证据冲突时，Agent 不给出建议防守档并记录原因；
- 实际持仓缺失时，不得给出建议防守档，也不得把建议档写成已生效参数。

## 禁止事项

- 不得将运行检查结果回写入 `params/risk.json`；
- 不得用旧 `output/` 中的价格或仓位替代当日事实；
- 不得把风险事实脚本改造成防守档判定脚本；
- 不得把阈值命中直接伪装为人工账户已执行的交易。
