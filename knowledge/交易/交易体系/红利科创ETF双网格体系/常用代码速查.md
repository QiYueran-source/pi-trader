# 红利科创ETF双网格体系运行接口速查

## 运行入口

体系计算与渲染统一通过 MCP 服务 `div-etf-grid-trade` 完成（注册见 `.pi/mcp.json`）。运行定义目录：

```text
.pi/mcp-servers/trade-system/div_etf_grid_trade/
├── mcp_server.py       # 实现
├── system.yml          # 运行契约
├── params/             # 参数唯一来源
└── templates/          # 模板唯一来源
```

过程产物写入：

```text
交易/过程资料/{date}/红利科创ETF双网格体系/
```

## 工具与入参

实现名 `div-etf-grid-trade`，工具命名空间 `mcp__div_etf_grid_trade__*`；`date` 支持 `YYYY-MM-DD` 或 `YYYYMMDD`，产物目录按 `YYYY-MM-DD` 命名。

| 工具 | 入参 | 返回 / 产物 |
|---|---|---|
| `list_systems` | — | 本服务实现的体系清单 |
| `get_manifest` | `system_id` | 运行定义路径（`system_root`/`parameter_root`/`template_root`）、支持的操作、产物落盘位置 |
| `validate_parameters` | `system_id` | `valid`、`files`、`parameter_version`、`parameter_hash`、`schema_versions` |
| `calculate` | `system_id`、`operation`（`risk_facts`／`regulator_facts`／`sector_facts`）、`date`、`positions`（前三者中除 `sector_facts` 外必填）、`human_review`（可选）、`skip_emotion`（可选）、`dry_run`（可选） | 事实 JSON；`dry_run=false` 时写入 `{operation}.json` |
| `render` | `system_id`、`artifact`、`date`、`document`（对应 JSON 全文） | 同名 `.md`，返回落盘路径 |

说明：

- `system_id` 必填且必须为 `div_etf_grid_trade`；一个体系一个 MCP 服务，别的体系由各自的服务提供。
- `calculate` 默认写入过程资料；`dry_run=true` 只计算不落盘。
- 每次调用都会重新读取并校验 `params/`（6 个文件）；失败时返回 `{"ok": false, "error": "..."}`，不产生产物。
- 非交易日或当日无行情时按无数据返回错误，不使用其它日期数据替代。
- 渲染使用运行定义 `templates/` 下的模板，依赖 `/opt/venv` 中的 `jinja2`。
- 情绪涨跌停采用分板口径（主板 10%、创业板/科创板 20%、北交所 30%），与 `sector_facts` 一致。

## 输入结构

`positions`（`calculate` 入参）必须包含真实持仓与现金：

```json
{
  "positions": {
    "dividend": {"shares": 0, "market_value_amount": 0},
    "growth": {"shares": 0, "market_value_amount": 0}
  },
  "cash": 0
}
```

- `cash` 必填；缺失或非数值会被拒绝。
- `market_value_amount` 可省略，缺省时按 `shares × 当日收盘价` 计算。
- 脚本与 MCP 都不访问券商账户；调用端必须先用 `trade-management` MCP 生成真实持仓事实。

`human_review`（防守档审批留痕，可选入参）字段见运行定义 `params/regulator.json#approval`。

## 依赖口径

- 体系 MCP 由 `/opt/venv/bin/python` 启动（`.pi/mcp.json` 已配置），依赖含 `mcp`、`tushare`、`jinja2`。
- Tushare token 读取项目 MCP 的 `.pi/mcp-servers/tushare/.env`，不写入仓库其它文件。
- `/opt/venv` 属 root 且不在挂载点上（随容器可写层）：容器重建后若报 `ModuleNotFoundError`，由 root 执行 `uv pip install --python /opt/venv/bin/python jinja2` 补回。`uv` 的缓存 `/opt/uv/cache` 已对 node 用户开放。

## Tushare 接口

### 交易日历

```python
pro.trade_cal(
    exchange="SSE",
    start_date="20260810",
    end_date="20260811",
    fields="cal_date,is_open",
)
```

### ETF 日线

```python
pro.fund_daily(
    ts_code="515180.SH",
    start_date="20260601",
    end_date="20260810",
    fields="trade_date,close,high,low,vol,amount",
)
```

返回默认可能倒序，计算前必须按 `trade_date` 升序排序。

### 全市场行业事实

```python
pro.daily(trade_date="20260810", fields="ts_code,pct_chg")
pro.stock_basic(exchange="", list_status="L", fields="ts_code,name,industry")
```
