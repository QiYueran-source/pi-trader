# 红利科创ETF双网格体系运作流程

## 运行入口

体系任务只通过 MCP 访问数据与账户：`tushare-data` 提供交易日和行情，`trade-management.portfolio_snapshot` 提供 YHZQ 仓位与现金。过程资料、状态和计划的路径以 `system.yml` 为准。

## 盘后顺序（v4）

1. 确认交易日；非交易日不生成产物。
2. 读取参数、MCP 行情及账户快照，生成持仓与风险事实（双标的）。
3. 按 `风控调节器.md` 输出参数事实：常态档距/份数、资金与单腿硬闸占用、停买标志、信号与建议防守档 → 写入 `regulator_facts.json`。
4. 生成下一交易日唯一正式计划（**参数版**：档距/份数/买卖开关/防守档/硬闸提示；**不输出逐档价格**）；防守档切换仅在人工审批后生成。
5. 持仓或关键输入无效时记录链路异常并停止后续步骤。

## 边界

- 过程资料记录事实与参数；正式计划只记录下一交易日参数与待审批项。
- 真实持仓是唯一仓位事实，不使用估算仓位或旧状态替代。
- 静态规则、参数和更新日志不在定时任务中修改。
- **不产出状态迁移、状态快照与切换指令**（状态机自 v4 退役）；不生成清仓/减仓/止损动作。

## 当前规则入口

- 网格与参数：`网格参数.md`、`params/regulator.json`
- 风险事实：`风控.md`
- 调节与防守审批：`风控调节器.md`
- 输出契约：`system.yml`
