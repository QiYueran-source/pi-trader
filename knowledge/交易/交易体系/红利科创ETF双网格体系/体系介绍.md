# 红利科创ETF双网格体系

## 阅读顺序

1. 先读本文，了解体系定位、规则入口和文件索引。
2. 执行体系时读取 `交易/交易体系/红利科创ETF双网格体系/体系运作流程.md`。
3. 需要参数与硬闸、风险事实、调节与审批规则时，读取对应专题文档。
4. 需要调用体系 MCP 或查看接口入参时，读取 `交易/交易体系/红利科创ETF双网格体系/MCP介绍.md`。

## 基本信息

- 固定标的：红利 ETF `515180.SH`、双创 50 ETF `159781.SZ`
- 体系类型：储蓄型双网格 + 人工审批防守（v4）
- 当前成熟度：候选体系
- 关联账户：`YHZQ`
- 机器标识：`div_etf_grid_trade`
- 运行定义：`.pi/mcp-servers/trade-system/div_etf_grid_trade/`（实现、契约、参数、模板的唯一来源；MCP 注册名 `div-etf-grid-trade`）
- 执行边界：体系 MCP 不直接下单；条件单与防守档参数由用户在券商端人工执行

## 风控调节与人工审批（v4）

机械层只输出参数与建议：常态档距与份数、资金与单腿硬闸（停买不清仓）、保底仓（触达下限停卖该腿）、信号评估与建议防守档；**升档与降档均需人工审批**，审批后生成交易计划再改券商参数；档位价格与锚由券商软件维护。

缩放规则：防守倍数对买卖两侧同时生效（档距与份数）；资金倍数只作用于买入档距；份数按 100 份向下取整；哪些量吃哪些倍数由 `params/regulator.json#scaling` 声明。

规则见 [[交易/交易体系/红利科创ETF双网格体系/风控.md|风控与调节规则]]，机器可读参数见运行定义 `params/regulator.json`。

```text
→ 参数版交易计划
→ 人工审批与执行（券商软件）
```
