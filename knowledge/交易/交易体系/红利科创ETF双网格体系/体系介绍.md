- 执行边界：体系不直接下单；条件单由用户在券商端人工维护

## 风控调节（无状态机）

体系**不使用 `normal / bull / bear` 状态切换**，也不存在清仓动作。风控调节器按**距锚跌幅 `d`** 分层放慢买入：

- `L0`–`L3` 对应 `k_step` 1.0/1.3/1.6/2.0、`k_size` 1.0/0.8/0.6/0.5；
- 硬约束：单腿 ≤40%、双腿合计 ≤85%、现金 ≥15%，触犯即**停买**（不清仓、不止损、不反 T）；
- 滞回：升降档需连续 3 个交易日确认，每腿每周 ≤1 次档位变更。

规则见 [[交易/交易体系/红利科创ETF双网格体系/风控调节器.md|风控调节器]]，机器可读参数见 `params/regulator.json`。

## 运行链路

```text
静态参数（网格 / 风控 / 调节器）
→ 行情、持仓、风险与板块事实
→ 计算 d 与档位 L0–L3（叠加人工基准步长覆盖）
→ 校验硬约束（单腿 / 合计 / 现金）
→ 次日计划（档位 + 份额）
→ 人工维护条件单
```
