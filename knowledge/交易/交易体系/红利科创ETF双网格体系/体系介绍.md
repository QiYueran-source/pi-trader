# 红利科创ETF双网格体系

## 阅读顺序

1. 先读本文，了解体系定位、状态和文件索引。
2. 执行体系时读取 `体系运作流程.md`。
3. 需要理解网格公式、风险阈值或状态迁移时，读取对应专题文档。
4. 需要运行脚本时，读取 `常用代码速查.md` 和脚本自身参数说明。

## 基本信息

- 固定标的：红利 ETF `515180.SH`、科创 50 ETF `159781.SZ`
- 体系类型：双网格与状态切换
- 当前成熟度：候选体系
- 关联账户：`YHZQ`
- 机器标识：`div_etf_grid_trade`
- 执行边界：脚本不直接下单，条件单和状态切换由用户在券商端人工执行

## 风控调节与人工审批（v4）

体系**不使用三态状态机**，也不存在清仓动作。机械层只输出参数与建议：固定档距与份数、资金使用率与单腿硬闸（停买不清仓）、信号评估与建议防守档；**升档与降档均需人工审批**，审批后生成交易计划再改券商参数。档位价格与锚由券商软件维护。

规则见 [[交易/交易体系/红利科创ETF双网格体系/风控调节器.md|风控调节器]]，机器可读参数见 `params/regulator.json`。

## 运行链路

```text
静态参数
→ 行情、持仓和风险事实
→ Agent 状态提案
→ 状态迁移校验
→ 切换执行指令
→ 交易计划
→ 人工执行
```

## 过程产物

当前运行产物写入：

```text
交易/过程资料/<YYYY-MM-DD>/红利科创ETF双网格体系/
```

主要产物包括：

- `calibration_check.json`：是否需要校准；
- `grid_parameters.json`：网格计算结果；
- `positions.json`：运行前的实际持仓事实；
- `risk_facts.json`：风险事实；
- `sector_facts.json`：板块事实；
- `transition_proposal.json`：Agent 状态提案；
- `state_before.json`、`state_after.json`：迁移前后状态和审计快照；
- `switch_instruction.json`：人工切换执行指令。

过程产物是运行事实或执行建议，不代表已经成交。实际成交、持仓和账户变化由交易管理流程记录。
