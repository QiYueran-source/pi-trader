# v4 储蓄网格与人工审批防守 | 2026-10-16

## 一、变更动因

1. 2026-10-15 的 `normal → bear` 迁移由人工裁定暂缓执行、清仓指令作废；用户明确体系不应存在清仓类硬动作。
2. 复盘发现"单边行情无缓冲"，且现行回撤校准公式在红利上恒撞 1% 下限（2026-10-16 校准：10 日最大回撤 5.94% × 0.15 = 0.89%），单日跌幅即可穿透 3.5 个档距。
3. 用户决定：**去掉状态机，用风控策略替代；机械层只出参数与建议，是否增强防御由人工审批**。

## 二、v4 机制（要点）

| 项 | 内容 |
|:---|:---|
| 定位 | 价格驱动的长期定投储蓄；无清仓、无减仓、无止损；允许 T（含日内） |
| 常态档距 | 固定值（读配置）：红利 买 **2.0%** / 卖 **3.0%**；双创 买 **4.6%** / 卖 **4.6%** |
| 常态份数 | 固定值（读配置）：红利 买 1,000 / 卖 800；双创 买 1,000 / 卖 1,000 |
| 硬闸 | 资金使用率（基数＝体系口径总资产）≥50% → 档距 ×1.3；≥70% → ×1.6；**≥85% 停买**；回落 ≥80% 恢复；单腿权重上限 **45%** |
| 叠加 | `实际档距 = min(常态档距 × 防守倍数 × 资金倍数, cap)`（红利 cap 6%、双创 cap 10%） |
| 信号 | 一阶冲击 → 二阶确认（未收复 50% / 创 20 日新低）+ 纯阴跌 + 情绪（量化分板口径 + 文本性质）；**只汇报，不切换** |
| 防守档 | A0 常态 / A1 1.3×1.0 / A2 1.6×0.75 / A3 2.0×0.5；**升档与降档均需人工审批**，审批后生成交易计划再改参数 |
| 执行分工 | 券商软件算档位价格、维护锚、一次预挂一档；系统**只算参数**；无持仓时每周重设基准价；**参数变更不需重设基准价** |
| 上涨侧 | 卖出腿常态启用，靠买卖不对称与防守档惜售；**份额底线暂不启用**（`reserve_shares.enabled=false`） |
| 复核 | 所有参数可配；修改须写更新日志 |
