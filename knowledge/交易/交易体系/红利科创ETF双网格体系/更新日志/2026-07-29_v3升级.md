# v3 双标的双态混合体系升级

## 升级日期

2026-07-29

## 核心变化

| 项目 | v2 | v3 |
|:---|:---|:---|
| **标的** | 单标的（515180 红利ETF） | **双标的**：+ 159781 双创50ETF |
| **卖步长公式** | 22日最大涨幅 × 系数 | **1/(1-买步长)-1** 推导 |
| **上涨回调卖出** | ❌ 无 | ✅ 触发后追踪最高价，回落买步长×0.2 后卖出 |
| **红利不对称** | ❌ 对称 1000/1000 | ✅ 买1000/卖800，每轮存200份 |
| **状态机行为** | bull=清仓等，bear=只买不卖 | **bull=全仓双创，bear=全仓红利** |
| **资金池** | 8,000 单独 | **11,000 统一共享** |
| **输出分离** | params/ 混用 | params/ 只留配置，output/ 放运行数据 |

## 参数文件变更

- `params/grid.json` → 双标的配置（网格一/网格二）
- `params/base.json` → 新增 `selection_dual` 双创信息
- `params/state.json` → 已迁移至 `output/state.json`
- `output/` → 新目录，存放所有脚本输出（calc_params/risk_check/switch）

## 脚本变更

| 脚本 | 变更 |
|:---|:---|
| `grid_calc_params.py` | 双标的循环计算 + 新卖步长公式 + 深圳ETF支持 + 上涨回调比例 |
| `state_machine_cli.py` | 切换时自动记录仓位快照 + 更新状态描述 |
| `risk_monitor.py` | 读取 output/state.json + 额外写入 dated 存档 |
| `render_template.py` | 双标的扁平参数注入 + 新增 compute_dual.* 字段 |
| `grid_switch.py` | 🆕 新脚本，输出全仓切换指令 |

## 模板变更

- `grid_params.txt` → 双网格并排展示，含上涨回调比例
- `state_machine.txt` → 展示双网格各自状态
- `risk_check.txt` → 标注仅红利做风控
