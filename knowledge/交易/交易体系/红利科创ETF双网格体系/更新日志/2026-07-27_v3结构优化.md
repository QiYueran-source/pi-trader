# 体系运作流程 v3 结构优化

## 变更内容

精简优化体系运作流程的文档结构，消除冗余流程。

### 修改文件

`体系运作流程.md` — 8节→7节：

| 变更 | 说明 |
|:---|:---|
| 删除"二、状态机管理（开盘前/盘中）" | 状态机不再作为早晨单独流程，完全归入每日风控 |
| 原"三、每日收盘后" → 新"二、每日收盘后" | 统合风控（风控+状态机+日计划），作为每日风控的唯一节点 |
| 09:25 早晨动作简化 | 从"按当前步长和状态设置条件单" → "按当前参数设置条件单"，去掉状态机依赖 |
| 标题更新 | v2 → v3，"按需调参" → "按周调参"，去掉"开盘前判断"引用 |
| 热门板块运行时机 | 去掉"或开盘前（状态机判断之前）"，统一为收盘后 |

### 未变更

- 状态机管理.md（独立文档）— 无修改，仍为三态定义和判断逻辑的参考文档
- 风控.md — 无修改，风控只警告不决策的原则不变
- Cronjob 排程 — 不变，18:00 仍每天跑但由内部脚本判断是否触发

### 目的

消除早晨状态机判断和收盘后状态机判断的冗余，让每日流程更清晰：只在收盘后做 风控+状态机 的统合判断，早晨只按当前参数设置条件单。
