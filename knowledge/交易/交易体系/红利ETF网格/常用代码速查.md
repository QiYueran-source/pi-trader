# 红利ETF网格体系常用代码速查

## 运行入口

所有脚本显式接收 `--date`，支持 `YYYY-MM-DD` 或 `YYYYMMDD`。过程产物写入：

```text
knowledge/交易/过程资料/{date}/红利ETF网格/
```

```bash
cd /hermes-trader
PYTHON=/opt/hermes/.venv/bin/python3
BASE=knowledge/交易/交易体系/红利ETF网格/scripts
```

| 目的 | 命令 |
|---|---|
| 校验是否调参 | `$PYTHON $BASE/should_calibrate.py --date {date}` |
| 计算网格参数 | `$PYTHON $BASE/calculate_grid.py --date {date}` |
| 采集风险事实 | `$PYTHON $BASE/collect_risk_facts.py --date {date} --positions {positions.json}` |
| 采集板块事实 | `$PYTHON $BASE/collect_sector_facts.py --date {date}` |
| 固化状态迁移 | `$PYTHON $BASE/apply_state_transition.py --date {date} --proposal {proposal.json} --positions {positions.json}` |
| 生成切换指令 | `$PYTHON $BASE/build_switch_instruction.py --date {date}` |
| 渲染过程资料 | `$PYTHON $BASE/render.py --template {target} --date {date}` |

## Tushare 接口

### 交易日历

```python
pro.trade_cal(
    exchange="SSE",
    start_date="20260810",
    end_date="20260811",
    fields="cal_date,is_open",
)
```

### ETF 日线

```python
pro.fund_daily(
    ts_code="515180.SH",
    start_date="20260601",
    end_date="20260810",
    fields="trade_date,close,high,low,vol,amount",
)
```

返回默认可能倒序，计算前必须按 `trade_date` 升序排序。

### 全市场行业事实

```python
pro.daily(trade_date="20260810", fields="ts_code,pct_chg")
pro.stock_basic(exchange="", list_status="L", fields="ts_code,name,industry")
```

## 状态提案输入

Agent 写入的 `transition_proposal.json` 至少包含：

```json
{
  "date": "YYYY-MM-DD",
  "system_id": "div_etf_grid_trade",
  "from_state": "normal",
  "to_state": "normal",
  "decision": "keep",
  "confidence": "medium",
  "evidence_summary": ["过程资料与文本研究的结论摘要"],
  "conflict_resolution": "存在冲突，保持状态",
  "decided_by": "agent"
}
```

持仓输入至少包含：

```json
{
  "positions": {
    "dividend": {"shares": 0, "market_value_amount": 0},
    "growth": {"shares": 0, "market_value_amount": 0}
  }
}
```

状态与切换脚本不直接访问券商账户；调用端必须先生成真实持仓事实。
