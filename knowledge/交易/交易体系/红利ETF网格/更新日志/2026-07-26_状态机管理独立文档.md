# 状态机管理独立文档

## 变更内容

将状态机的完整说明从 `体系运作流程.md` 中拆分出来，独立为 `状态机管理.md`。

### 新增文件

`状态机管理.md` — 状态机完整文档，包含：

| 章节 | 内容 |
|:---|:---|
| 概述 | 三层架构、状态机的定位 |
| 三态定义 | normal/bull/bear 各自的买入/卖出/网格行为 |
| 合法转换 | 四个合法转换路径及操作 |
| v1 判断逻辑 | 投顾盘前分析 + 热门板块数据 + 事实，AI综合判断 |
| 工具 | state_machine_cli.py 使用说明 |
| 状态切换后操作 | 每种转换后的具体操作步骤 |
| 版本记录 & 迭代方向 | 当前v1，规划v2/v3/v4 |

### 修改文件

| 文件 | 变更 |
|:---|:---|
| `体系运作流程.md` | 状态机章节大幅精简，改为引用 `状态机管理.md` |
| `体系介绍.md` | frontmatter links 增加 `状态机管理.md` 引用 |

### 目的

独立文档后，状态机判断逻辑可以独立迭代和优化，不影响体系运作流程的整体SOP。
