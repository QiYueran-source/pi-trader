# 基于Agent的ETF轮动体系

## 体系定位

本体系在固定六只ETF和货币ETF之间进行日频轮动，由Agent完成环境评估、候选比较、调仓判断和风控审查，当前使用MNZH模拟账户，处于观察阶段。

核心不是追逐单日最强，而是在证据充分时形成唯一动作，并让计划、执行和复盘保持一致。

## 固定候选池

- `510300.SH`：沪深300ETF
- `588000.SH`：科创50ETF
- `511260.SH`：10年国债ETF
- `518880.SH`：黄金ETF
- `513500.SH`：标普500ETF
- `511990.SH`：货币ETF，作为现金替代

候选池不因短期热点临时扩展。增减标的需要经过复盘论证并写入更新日志。

## 决策链路

```text
交易日与账户状态
  → 环境评估
  → 候选比较
  → 当前持仓复核
  → 调仓判断
  → 风控审查
  → 交易计划
  → 计划推送
  → 模拟执行
  → 交易复盘
```

详细业务顺序见 [`体系运作流程.md`](体系运作流程.md)，具体执行时间由体系 cronjob 配置决定。

## 相关技能和 MCP

- `trade-system`：体系运行、规则读取和流程衔接；
- `tushare`：市场数据工具路由；
- `tushare-data` MCP：ETF、指数、宏观和交易日历数据；
- `trade-management`：MNZH 模拟账户、成交、持仓、现金和盈亏；
- `knowledge-management`：路径、Frontmatter 和正文整理；
- `summary`：完整工作结束后的简报落盘；
- `cronjob_management`：体系定时任务管理。

## 交易边界

- 体系只生成模拟交易计划，不执行真实交易。
- 过程资料记录事实和判断依据，交易计划记录唯一可执行动作，复盘记录计划与执行偏差。
- 当前持仓默认优先保留，只有显著且有持续证据的替代优势才切换。
- 证据不足、数据缺失或风险失真时，降低动作强度或转入现金。
