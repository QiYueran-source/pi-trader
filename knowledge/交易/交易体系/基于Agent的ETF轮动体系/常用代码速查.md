# 基于Agent的ETF轮动体系 - 常用代码速查

## 定位

本文件用于沉淀“基于Agent的ETF轮动体系”高频会用到的 Tushare 代码、接口、字段和最小可运行示例，服务于规则库中的评估框架、调仓逻辑和风控逻辑。

本文件不是完整 API 手册，只保留当前体系已经验证需要、且已实测可跑通的常用接口。

## 使用原则

### 1. 主评估优先使用日线与宏观数据

- 日线数据用于候选比较、区间表现、波动与回撤观察。
- 宏观数据用于增长预期、流动性、利率、通胀与海外扰动判断。

### 2. 分钟线用于辅助观察，不替代日频判断

分钟线主要用于：

- 观察盘中强弱是否持续。
- 判断是否存在冲高回落、尾盘转弱等异常结构。
- 做风控复核与盘中节奏补充。

不得仅凭分钟线异动推翻日频结论。

### 3. 默认从环境变量中读取 `TUSHARE_TOKEN`

推荐写法：

```python
import os
import tushare as ts

pro = ts.pro_api(os.environ["TUSHARE_TOKEN"])
```

也可以显式使用：

```python
import os
import tushare as ts

token = os.environ.get("TUSHARE_TOKEN")
pro = ts.pro_api(token)
```

### 4. 如果通过子进程运行 Python，必须显式注入 `TUSHARE_TOKEN`

若用 `subprocess.run()`、`python -c` 或其他子进程方式调用 Tushare，**不要假设子进程一定继承当前环境变量**。必须显式注入：

```python
import os
import subprocess

env = {
    **os.environ,
    "TUSHARE_TOKEN": os.environ.get("TUSHARE_TOKEN", ""),
}

subprocess.run(
    ["/opt/hermes/.venv/bin/python3", "script.py"],
    env=env,
    check=True,
)
```

对于本体系，优先直接在主进程里调用 Tushare；若必须用子进程，必须显式传 `env`。

## 1. 交易日历：`trade_cal`

### 用途

用于判断今天是否为交易日，以及获取最近交易日。适用于盘前检查、计划生成与复盘流程。

### 适用环节

- 工作流程
- 评估框架前置检查
- 计划生成 / 复盘日期校验

### 最小可运行代码

```python
import os
import tushare as ts

pro = ts.pro_api(os.environ["TUSHARE_TOKEN"])

df = pro.trade_cal(
    exchange="SSE",
    start_date="20260601",
    end_date="20260610",
)
print(df.head())
```

### 常用字段

- `cal_date`：自然日
- `is_open`：是否开市，`1` 为交易日
- `pretrade_date`：前一个交易日

### 注意事项

- 当前体系默认以上交所交易日历作为 A 股交易日判断基准。
- 返回结果可直接用于判断“今天能不能生成正式交易计划”。

## 2. ETF 基础信息：`fund_basic`

### 用途

用于核实 ETF 基础资料，包括名称、管理人、托管人、费率、上市状态、基准等。适用于维护 ETF 池与后续规则校验。

### 适用环节

- `ETF池.md`
- 更新 ETF 档案时的事实核验
- 周期性池子维护

### 最小可运行代码

```python
import os
import tushare as ts

pro = ts.pro_api(os.environ["TUSHARE_TOKEN"])

df = pro.fund_basic(market="E")
print(df[["ts_code", "name", "management", "custodian", "m_fee", "c_fee", "status"]].head())
```

### 常用字段

- `ts_code`：基金代码
- `name`：名称
- `management`：管理人
- `custodian`：托管人
- `m_fee`：管理费
- `c_fee`：托管费
- `list_date`：上市日期
- `delist_date`：退市日期
- `benchmark`：业绩比较基准
- `status`：状态
- `market`：市场

### 注意事项

- 当前实测可用字段是 `m_fee` / `c_fee`，不要误写成其他字段名。
- 若要精准筛 ETF，可结合 `ts_code` 与 `name` 进一步过滤。

## 3. ETF 日线：`fund_daily`

### 用途

用于拉取 ETF 日线行情，是当前体系最核心的数据接口之一。用于观察区间表现、成交活跃度、波动与回撤。

### 适用环节

- `评估框架.md`
- `调仓逻辑.md`
- `风控逻辑.md`

### 最小可运行代码

```python
import os
import tushare as ts

pro = ts.pro_api(os.environ["TUSHARE_TOKEN"])

df = pro.fund_daily(
    ts_code="510300.SH",
    start_date="20260520",
    end_date="20260609",
)
print(df.head())
```

### 常用字段

- `trade_date`：交易日
- `pre_close`：前收盘
- `open`：开盘价
- `high`：最高价
- `low`：最低价
- `close`：收盘价
- `change`：涨跌额
- `pct_chg`：涨跌幅
- `vol`：成交量
- `amount`：成交额

### 注意事项

- 返回结果默认按交易日倒序。
- ETF 使用 `fund_daily`，不要误用股票日线接口。

## 4. ETF 分钟线：`stk_mins`

### 用途

用于观察 ETF 分钟级走势，辅助判断盘中强弱结构、持续性与异常波动。

### 适用环节

- 评估框架中的辅助确认
- 风控逻辑中的盘中复核
- 盘中强弱结构观察

### 最小可运行代码

```python
import os
import tushare as ts

pro = ts.pro_api(os.environ["TUSHARE_TOKEN"])

df = pro.stk_mins(
    ts_code="510300.SH",
    start_date="2026-06-09 09:30:00",
    end_date="2026-06-09 15:00:00",
    freq="1min",
)
print(df.head())
```

### 常用字段

- `trade_time`：分钟时间戳
- `open`：该分钟开盘价
- `high`：该分钟最高价
- `low`：该分钟最低价
- `close`：该分钟收盘价
- `vol`：成交量
- `amount`：成交额

### 注意事项

- 当前已实测：ETF 代码可直接通过 `stk_mins` 获取分钟线。
- 本接口主要用于辅助观察，不应替代日线和宏观结论。

## 11. 常用衍生计算模板

### 11.1 区间涨跌幅

```python
import os
import tushare as ts

pro = ts.pro_api(os.environ["TUSHARE_TOKEN"])
df = pro.fund_daily(ts_code="510300.SH", start_date="20260520", end_date="20260609")
df = df.sort_values("trade_date")
ret = df.iloc[-1]["close"] / df.iloc[0]["close"] - 1
print(round(ret * 100, 2), "%")
```

### 11.2 平均振幅

```python
import os
import tushare as ts

pro = ts.pro_api(os.environ["TUSHARE_TOKEN"])
df = pro.fund_daily(ts_code="510300.SH", start_date="20260520", end_date="20260609")
amplitude = ((df["high"] - df["low"]) / df["pre_close"]).mean()
print(round(amplitude * 100, 2), "%")
```

### 11.3 最大回撤

```python
import os
import tushare as ts

pro = ts.pro_api(os.environ["TUSHARE_TOKEN"])
df = pro.fund_daily(ts_code="510300.SH", start_date="20260520", end_date="20260609")
df = df.sort_values("trade_date")
prices = df["close"].astype(float)
rolling_max = prices.cummax()
drawdown = prices / rolling_max - 1
print(round(drawdown.min() * 100, 2), "%")
```

## 12. 多 ETF 横向对比模板

### 用途

把固定池候选放在一起做最近阶段对比，辅助评估框架排序。

### 最小可运行代码

```python
import os
import tushare as ts
import pandas as pd

pro = ts.pro_api(os.environ["TUSHARE_TOKEN"])

codes = [
    "510300.SH",
    "588000.SH",
    "511260.SH",
    "518880.SH",
    "513500.SH",
    "511990.SH",
]

rows = []
for code in codes:
    df = pro.fund_daily(ts_code=code, start_date="20260520", end_date="20260609")
    df = df.sort_values("trade_date")
    ret = df.iloc[-1]["close"] / df.iloc[0]["close"] - 1
    amp = ((df["high"] - df["low"]) / df["pre_close"]).mean()
    amt = df["amount"].mean()
    rows.append({
        "ts_code": code,
        "区间涨跌幅": round(ret * 100, 2),
        "平均振幅": round(amp * 100, 2),
        "平均成交额": round(float(amt), 2),
    })

result = pd.DataFrame(rows).sort_values("区间涨跌幅", ascending=False)
print(result)
```

### 注意事项

- 横向对比只能作为辅助，最终仍需回到评估框架解释“为什么强”。
- 不要仅凭区间涨跌幅排序直接生成交易结论。

## 13. 分钟线辅助观察模板

### 用途

用于观察盘中强弱是否持续、是否出现冲高回落、尾盘异动等结构。

### 最小可运行代码

```python
import os
import tushare as ts

pro = ts.pro_api(os.environ["TUSHARE_TOKEN"])
df = pro.stk_mins(
    ts_code="510300.SH",
    start_date="2026-06-09 09:30:00",
    end_date="2026-06-09 15:00:00",
    freq="1min",
)

df = df.sort_values("trade_time")
first = df.iloc[0]["open"]
last = df.iloc[-1]["close"]
high = df["high"].max()
low = df["low"].min()

print("开盘到收盘涨跌幅:", round((last / first - 1) * 100, 2), "%")
print("日内最高:", high)
print("日内最低:", low)
```

### 适合观察的问题

- 早盘强势是否延续到尾盘。
- 是全天稳步走强，还是冲高回落。
- 防御资产是否全天稳定偏强。

## 14. 轮动分析最小脚手架

```python
import os
import tushare as ts
import pandas as pd

pro = ts.pro_api(os.environ["TUSHARE_TOKEN"])

etf_pool = {
    "510300.SH": "沪深300ETF",
    "588000.SH": "科创50ETF",
    "511260.SH": "10年国债ETF",
    "518880.SH": "黄金ETF",
    "513500.SH": "标普500ETF",
    "511990.SH": "货币ETF",
}

summary = []
for code, name in etf_pool.items():
    df = pro.fund_daily(ts_code=code, start_date="20260520", end_date="20260609")
    df = df.sort_values("trade_date")
    ret_5 = df.tail(5).iloc[-1]["close"] / df.tail(5).iloc[0]["close"] - 1 if len(df) >= 5 else None
    ret_all = df.iloc[-1]["close"] / df.iloc[0]["close"] - 1
    amp = ((df["high"] - df["low"]) / df["pre_close"]).mean()
    summary.append({
        "名称": name,
        "代码": code,
        "区间涨跌幅%": round(ret_all * 100, 2),
        "近5日涨跌幅%": round(ret_5 * 100, 2) if ret_5 is not None else None,
        "平均振幅%": round(amp * 100, 2),
    })

summary_df = pd.DataFrame(summary).sort_values("区间涨跌幅%", ascending=False)
print(summary_df)
```

### 用法说明

- 先用这段代码拉出候选池的基础对比表。
- 再结合评估框架解释：当前环境、相对优势、风险暴露与证据清晰度。
- 最后再进入调仓逻辑与风控逻辑。

## 坑位与约定

### Tushare 拉 ETF 行情
