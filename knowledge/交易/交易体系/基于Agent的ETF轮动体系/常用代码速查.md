# 基于Agent的ETF轮动体系 · 数据工具速查

## 数据入口

Agent 通过 `tushare-data` MCP 获取市场数据，不直接读取 Token，不直接调用 `tushare` Python 客户端。

| 数据 | 工具 | 主要用途 |
|---|---|---|
| 交易日历 | `get_trade_calendar` | 判断交易日和下一交易日 |
| ETF 日线 | `get_fund_daily` | 区间收益、波动、回撤、成交量 |
| ETF 分钟线 | `get_fund_minutes` | 按计划时点回放成交 |
| ETF 基础资料 | `get_fund_basic` | 费率、上市状态、基金信息 |
| A 股指数 | `get_index_daily` | 沪深300、科创50等市场环境 |
| 海外指数 | `get_index_global` | 标普500等海外环境 |
| CPI | `get_cpi` | 通胀环境 |
| PMI | `get_pmi` | 增长和景气环境 |
| Shibor | `get_shibor` | 流动性与利率环境 |
| 美国国债收益率 | `get_us_treasury_curve` | 海外利率和风险偏好 |

所有结果检查 `ok`、`row_count`、`source` 和 `warnings`。空结果需要区分非交易日、权限不足、参数错误和真实无数据。

## 常用调用参数

ETF 日线：

```text
get_fund_daily(
  ts_code="510300.SH",
  start_date="2026-09-01",
  end_date="2026-10-09"
)
```

ETF 分钟线：

```text
get_fund_minutes(
  ts_code="510300.SH",
  freq="1min",
  start_date="2026-10-09 10:00:00",
  end_date="2026-10-09 10:01:00"
)
```

宏观月度数据使用 `YYYYMM` 或 `YYYY-MM`，日频数据使用 `YYYYMMDD` 或 `YYYY-MM-DD`。ETF 必须使用 `get_fund_daily`，不能使用股票日线工具。

## 数据来源

- 常规数据优先来自官方 Tushare。
- 分钟线官方失败时由 MCP 自动切换 promax 代理。
- 过程资料记录实际 `source` 和警告。
- 代理只用于读取数据，不用于交易提交。

## 交易管理入口

模拟持仓、成交、现金和盈亏通过 `trade-management` MCP 查询或登记。交易计划只定义动作，MCP 负责账户数据和模拟成交记录。
