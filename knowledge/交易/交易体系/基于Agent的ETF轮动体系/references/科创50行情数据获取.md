# 科创50 行情数据获取（复盘/回放用）

用途：1815 复盘 / 1810 回放时，`市场收评.md` 缺 588000 精确收盘/量能数据时，用 tushare 补齐。
量能是判断「缩量止跌日」第一环的硬指标，不能只靠收评的指数涨跌幅替代。

## 前置

```bash
cd /hermes-trader && source /hermes-trader/.mnt/.env   # 载入 TUSHARE_TOKEN
```

- token 在 `/hermes-trader/.mnt/.env`（与 `.mnt/.hermes/.env` 均有，python 从 `os.environ` 读取即可）
- 用 `/opt/hermes/.venv/bin/python3` 执行，不要用系统 python

## 命令模板

```python
import tushare as ts, os
pro = ts.pro_api(os.environ.get('TUSHARE_TOKEN',''))

# ETF 日线：588000.SH —— 必须用 fund_daily！pro.daily() 对 ETF 静默返回空表不报错
df = pro.fund_daily(ts_code='588000.SH', start_date='20260728', end_date='20260804')
print(df[['trade_date','open','high','low','close','pct_chg','vol','amount']].to_string())

# 科创50 指数：000688.SH（index_daily），作参照
df2 = pro.index_daily(ts_code='000688.SH', start_date='20260728', end_date='20260804')
print(df2[['trade_date','open','high','low','close','pct_chg','vol','amount']].to_string())
```

## 字段与单位

| 字段 | 含义 | 注意 |
|------|------|------|
| `close` | 收盘价 | 588000 现价约 1.6-1.8 元档；511990 货币ETF ≈100.00-100.002 |
| `pct_chg` | 涨跌幅 % | 指数与 ETF 略有差异（如 000688 +4.09% vs 588000 +4.28%），结论以 ETF（持仓标的）为准 |
| `vol` | **手**（1手=100份） | 588000 近月量能区间 4000-9000万手；读数 `62410029.39` ≈ 6241 万手，直接与「缩量止跌 <4000万手」观察阈值比较 |
| `amount` | **千元** | 1亿 = 100,000千元 |

## 信号链判断要点（复盘复用）

- **缩量止跌日（第一环）**：量显著萎缩至 4000万手以下 + 跌幅收窄/十字星 + 当日不创新低。**大涨日（哪怕 +4%）不算止跌日**——形态与量能两个条件都要看。
- **单日反弹（涨幅 >3% 但无第一环前置）= 不入场**，属诱多候选（7/21、7/31、8/4 三次均按此处理，前两次被证伪）。
- 拉数区间建议取近 5-6 个交易日（如 `20260728`→当日），足够对比量能趋势与前低位置。
