# 基于Agent的ETF轮动体系 - 风控逻辑

## 定位

本文件定义本体系的**风险控制规则**。在[[交易/交易体系/基于Agent的ETF轮动体系/评估框架.md|评估框架]]完成候选排序、[[交易/交易体系/基于Agent的ETF轮动体系/调仓逻辑.md|调仓逻辑]]给出动作建议后，Agent 必须使用本文件判断该结论是否需要维持、降级、复核或退出。

本文件的核心不是替代选标，也不是机械追求最小回撤，而是防止 Agent 在证据不足、环境失真、事件扰动或价格异常时做出过于激进的动作。

## 风控目标

本文件用于解决以下问题：

1. 即使评估方向看似正确，证据是否足够支撑动作。
2. 当前持仓的成立前提是否已失效。
3. 当价格与逻辑背离时，应如何复核或退出。
4. 当重大事件或极端波动出现时，是否需要暂停进攻型轮动。

## 核心原则

### 1. 认知风控优先于价格风控

本体系是 Agent 驱动的轮动体系，首要风险不是价格本身，而是**判断错误却不自知**。因此风控首先看结论是否可靠，其次才看盈亏与波动。

### 2. 风控是第二道闸门，不是附属备注

只要风控逻辑认为环境不适合执行原动作，Agent 就必须对调仓结论降级。不能把风控写成“已知风险提示”，却仍按原计划执行。

### 3. 情景失效比价格回撤更早触发

若持仓原有前提已经被破坏，即便价格回撤尚不明显，也应提前复核甚至退出。不能等到大幅亏损后才承认逻辑失效。

### 4. 不确定时先收缩动作，再追求收益

当环境模糊、证据冲突、重大事件临近时，风控应优先要求延续旧仓、降低切换冲动，或直接转入现金，而不是继续放大风险暴露。

## 风控分类

### 一、置信度风控

用于处理“结论看起来成立，但证据并不够强”的情况。

#### 需要触发置信度风控的情形

- 支撑结论的证据数量不足。
- 不同证据方向冲突明显。
- 结论过度依赖单一消息、单一催化或单日走势。
- 数据尚未充分反映重大事件影响。
- 前二候选差距很小，但 Agent 却试图做强切换。

#### 风控动作

- 优先维持当前持仓。
- 若当前持仓也不稳，则优先转现金。
- 不允许在低置信度下进行激进切换。

### 二、情景失效风控

用于判断当前持仓的核心前提是否已被破坏。

#### 典型失效情景

- 持有国债的前提是增长走弱与利率下行，但政策刺激与风险偏好修复同步增强。
- 持有黄金的前提是避险与通胀交易，但避险迅速退潮、实际利率回升形成压制。
- 持有科创50的前提是成长主线占优，但市场重新回到防御风格或大盘权重风格。
- 持有标普500的前提是海外风险资产占优，但海外政策扰动、汇率或美股风险明显恶化。

#### 风控动作

- 一旦发现核心前提失效，应立即降低持仓确定性评级。
- 若存在更明确替代资产，可允许切换。
- 若没有明确替代资产，则优先转现金而不是硬留原仓。

### 三、价格与回撤风控

用于处理市场价格快速背离、波动异常放大的情形。

#### 核心认识

本体系不把机械止损当作唯一标准，但也不能完全忽视价格。价格与逻辑持续背离，通常意味着市场没有认可当前叙事，必须触发复核。

#### 需要触发价格与回撤风控的情形

- 持仓出现超预期快速回撤。
- 连续多日走势不利，且未见逻辑修复。
- 持仓出现异常大波动，超出其常态风险特征。
- 已有明显盈利，但市场环境开始转弱，利润保护需求上升。

#### 风控动作

- 首先触发**强制复核**，重新检查原持仓逻辑是否仍成立。
- 若价格不利但逻辑仍强，可维持观察，不机械止损。
- 若价格不利且逻辑同步削弱，应执行退出或降级。
- 若盈利较大但逻辑未被破坏，不强制止盈；若盈利扩张后逻辑开始转弱，应优先保护利润。

### 四、事件风险风控

用于处理可能使短期价格和叙事都出现失真的重大事件。

#### 重点事件类型

- 美联储议息、非农、通胀等关键海外宏观数据。
- 国内重大政策会议、金融政策窗口、监管表态。
- 地缘冲突升级。
- 海外权益或大宗商品出现极端波动。
- 可能对黄金、国债、标普500形成单日强冲击的突发事件。

#### 风控动作

- 提高新开仓与切换门槛。
- 优先维持旧仓，避免事件前后追涨杀跌。
- 若事件本身已成为主导不确定性来源，则现金优先级上升。

## 风控状态分级

本体系每日风控状态只分三档，便于执行。

### 1. 正常

适用情形：

- 证据较清晰。
- 环境主线明确。
- 主要事件风险可控。
- 调仓结论与风控判断一致。

动作要求：

- 可按评估框架与调仓逻辑正常执行。

### 2. 审慎

适用情形：

- 证据存在分歧。
- 当前环境尚未完全确认。
- 重大事件临近但未落地。
- 新候选与旧持仓差距不够大。

动作要求：

- 提高切换门槛。
- 优先继续持有当前仓位。
- 若当前仓位也不稳定，则优先转现金。

### 3. 防御

适用情形：

- 核心变量高度失真。
- 市场剧烈波动，方向判断失效。
- 当前持仓逻辑已被破坏，替代资产又缺乏清晰支撑。
- 重大突发事件已显著抬升系统性风险。

动作要求：

- 暂停激进切换。
- 优先现金或低波防御资产。
- 任何新进攻性判断都必须降级处理。

## 风控执行顺序

### 第一步：先审查调仓结论的置信度

若调仓建议本身证据不足，则不进入积极执行阶段，应优先保守化。

### 第二步：再审查当前持仓是否情景失效

若旧仓逻辑失效，则不能仅因惯性继续持有。

### 第三步：最后审查价格、回撤与事件冲击

若价格或事件风险已显著破坏赔率结构，则应对动作结论做降级处理。

## 允许的风控干预动作

风控逻辑可以对调仓结论做以下处理：

1. **维持原建议**：风险可控，按原计划执行。
2. **降级为继续持有**：新候选不够稳，回到观察状态。
3. **降级为转现金**：结论不稳，优先保留流动性。
4. **要求强制复核**：暂不下最终动作，先重新审查核心前提。
5. **要求退出当前持仓**：原逻辑已失效且风险不可接受。

## 输出要求

每次风控结论必须明确写出：

### 1. 当前风控状态

- 正常 / 审慎 / 防御

### 2. 触发原因

- 置信度不足
- 情景失效
- 价格与回撤异常
- 事件风险上升
- 以上多项叠加

### 3. 风控动作

- 维持原建议
- 降级为继续持有
- 降级为转现金
- 强制复核
- 退出当前持仓

### 4. 核心解释

必须说明：

- 风控为什么介入。
- 原评估或调仓结论哪里不够稳。
- 最终动作为什么更符合当前赔率与风险约束。

## 禁止事项

- 禁止只把风控写成提示语，而不改变实际动作。
- 禁止把短期小波动机械等同于逻辑失效。
- 禁止在明显低置信度或高事件风险环境下做激进切换。
- 禁止因为已有浮盈就无条件止盈，也禁止因为暂时浮亏就无条件止损。
- 禁止跳过风控审查直接执行调仓建议。
