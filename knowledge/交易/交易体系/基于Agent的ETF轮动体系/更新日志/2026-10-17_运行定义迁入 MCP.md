# 运行定义迁入 MCP | 2026-10-17

## 一、动因

`trade-system/reference/mcp.md` 要求「一个体系一个服务」，知识库体系目录只放文档：参数、模板与实现归运行定义，`system.yml` 不留在知识库。本体系此前保留 `system.yml` 与 `references/`（复盘模板、科创50取数说明），且 SOP 为「阶段一～七」结构、任务 prompt 内联权威来源。

用户 2026-10-17 选定 **a1 + b1**：只建**最小只读服务**（不做事实计算与判定），`system.yml` 与模板进运行定义。

## 二、口径

| 项 | 决定 |
|:--|:--|
| 服务范围 | 只提供 `list_systems`／`get_manifest`／`validate_parameters`／`render`；**不取数、不算事实、不判定、不写计划** |
| 判定口径 | 环境、候选、调仓与风控仍由 Agent 按 `规则库/` 执行；规则库保持唯一事实源 |
| 参数范围 | `params/runtime.json` 只放路径与文件名等契约项，**不含任何阈值** |
| 复盘渲染 | `render(artifact="review", date, document)` 按 `templates/review.md.j2` 落盘；`dry_run=true` 只返回全文 |
| 过程资料路径 | 统一到 `交易/过程资料/<日期>/基于Agent的ETF轮动体系/`（新产物起；2026-10-16 及以前保持原路径） |
