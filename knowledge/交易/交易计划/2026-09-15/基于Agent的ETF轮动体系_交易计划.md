## 核心理由

1. **派发信号重启 → 清仓残余仓位（本计划核心裁决）**：9/14 量 **43.61万手 ≥40万手** ✓、收盘 **+0.004%（涨幅趋零）** ✓、**未创新高**（最高 135.902 < 9/10 最高 135.938）✓ → **放量滞涨**成立，9/10 的「派发解除」状态终结。剩余 200 份由「常规持有监控」回到「派发评估」区间 → 按 9/14 复盘「决策参考」#1 作出**非维持**的确定性裁决。**取「全清」而非「减半」的理由**：① 剩余仓位仅约 2.4%（¥27,172），减半的操作意义递减、执行与记账成本不划算；② 风控审慎 + 事件前收缩（议息 9/16-17）——不确定时先收缩；③ 本轮为「同一形态的第二轮循环」（9/7-9/8 派发后已减仓 50%，信号重启说明首轮减仓未止住派发），保留残余仓位与风控结论不一致；④ 清仓后回到「现金等价 ≈100% 等待」的干净状态，符合调仓逻辑第四步。
2. **风险暴露抬升触发强制复核 → 退出而非维持（调仓逻辑第二步情形 3）**：持仓环境前提（增长走弱 + 利率下行 + 避险）**未被证伪**，但「风险暴露急剧上升」成立（放量滞涨 + 事件窗口）→ 不得维持为「常规继续持有」，风控「价格与回撤风控」要求执行退出/降级。
3. **无更优替代 → 去向现金而非切换标的（调仓逻辑第三、四步）**：黄金 9/14 收 8.875（-0.76%，量 -26.4% 缩量）→ 切换双前置「重新放量上行」明确未满足；权益（科创50 -1.62%、沪深300 -0.67%）均**缩量下跌**，无「放量反弹连续确认」→ 无显著更优项 → 清仓资金去向 = **现金**（非黄金、非权益）。
4. **事件风险约束（风控四）**：美联储议息（**9/16-17**）临近（9/15 为其前一交易日），美债收益率上行 + 美元走强 + 通胀预期升温；「提高新开仓与切换门槛、优先收缩暴露」→ 支持事件前完成退出，不重启回补。
5. **清仓双线仍安全（但不等同于维持理由）**：9/14 收 135.858 距观察线 **+0.190%**、较成本 -0.024%（-0.5% ≈135.21 远未触及）→ 双线**未触发**；但双线是**防守底线**而非持有依据，量价背离 + 事件窗口下，底线安全不构成保留残余仓位的理由（风控「情景失效比价格回撤更早触发」「不确定时先收缩动作」）。
6. **反向分支保留（放量上行则撤销）**：若 9/15 10:00 时点出现放量上行、价站稳 135.886 上方（收复 9/10 收盘/高点区），则派发判定被推翻、形态转为健康量价齐升 → 撤销清仓裁决。**判定点前移至 10:00 执行时点**，避免「解除永远晚于执行」。
