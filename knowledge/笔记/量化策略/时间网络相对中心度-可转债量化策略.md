# 时间网络相对中心度——可转债量化策略

> 来源：微信公众号[原文链接](https://mp.weixin.qq.com/s/c_X8L4szkglMf5EkgMAO1A)
> 因子原型：股票网络研报，作者复现后迁移至可转债市场

---

## 因子逻辑：捕捉"异类"

通过计算转债收益率在截面上的偏离程度，构建时间维网络关系衡量"中心度"，捕捉与多数转债表现不同的标的。

- 尝试变体：正股收益率 / 残差收益率计算
- **结论**：均不如直接用转债自身收益率效果好

## 因子计算方法

| 步骤 | 操作 |
|------|------|
| ① | 所有转债 t 时刻收益率做截面 Z-score 标准化 |
| ② | 取过去 20 个交易日标准化收益率均值 |
| ③ | 基于此计算时间维网络相对中心度 |

## 策略实现

| 要素 | 设定 |
|------|------|
| 调仓 | 日频：收盘算因子 → 次日开盘调整 |
| 选股 | 因子值最大前 10% |
| 加权 | 等权 / 按因子值 / 按价格，三种测试 |
| 绩效 | 不计费时 scale_weights 净值最好；综合夏普+换手率，等权 Fitness 最佳（>5，系列最高，此前均 <4） |

## 因子评价

- **IC**：2022/2023 出色（均值 >0.15），2020/2024 偏弱 —— 阶段性强
- **分层回测**：一般。IC 为正但长期因子值最小一组领先（收益结构非线性/环境依赖迹象）

## 个人思考

- 本质是横截面"偏离度/异类"因子，与横截面动量类同源
- 日频调仓换手高，Fitness 未计费率，实盘需重估
- 前 10% 持仓或偏小规模/高波动券，注意流动性
- 2020/2024 失效 + 分层反转 → 环境依赖明显，不宜直接照搬
- 与其他因子可作组合候选（如[[笔记/量化策略/2026-07-10/量化拯救散户-卖出倾向因子.md|卖出倾向因子]]）
