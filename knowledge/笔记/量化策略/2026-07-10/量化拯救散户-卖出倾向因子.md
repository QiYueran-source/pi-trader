# 卖出倾向因子——基于V型处置效应的选股策略

> 来源：公众号「量化拯救散户」[原文链接](https://mp.weixin.qq.com/s/oxOvAnYebdRpNDAKp_7Rig)
> 复现自：广发证券《行为金融因子研究之四：基于V型处置效应的选股策略研究》

## 因子逻辑：V型处置效应

行为经济学中的 **V型处置效应** 解释投资者卖出行为的两种理论：

1. **有限注意力理论**：投资者买入后，价格波动不足以吸引注意时不会交易；只有当盈利/亏损幅度大到引起关注时，才会倾向卖出
2. **投资理念更新理论**：投资者认为自己掌握非公开信息买入。股价上涨 → 信息已price in → 卖出实现收益；股价下跌 → 重新评估信息有效性 → 亏损到一定程度也卖出

→ 结果：**盈亏两端交易倾向高，中间区域交易倾向低**，呈"V型"。

## 因子计算方法

> 参数：过去21个交易日窗口

**输入数据**：VWAP（成交量加权均价）、换手率（TR）

**计算步骤**：

| 步骤 | 操作 |
|------|------|
| ① | 取过去21日VWAP，过去20日换手率 |
| ② | 计算T日VWAP相对T-21~T-1的涨跌幅 |
| ③ | 分离 gain（涨幅）和 loss（跌幅） |
| ④ | 换手率倒序排列后累乘 → 时间越近权重越高 |
| ⑤ | 归一化权重 |
| ⑥ | gain 和 loss 分别加权求和 |
| ⑦ | 因子值 = **gain - n × loss**（n ∈ {1, 1.25, 1.5, 2, 3}） |

**权重设计亮点**：换手率时间衰减权重——近期换手率权重高，远期权重低，体现投资者记忆衰减特性。

**代码逻辑**：

```python
def cal_factor(self, idx):
    vwap = self.vwap.iloc[idx-21:idx]
    day = vwap.iloc[[-1]].index.tolist()[0]
    tr = self.tr.iloc[idx-21:idx-1]
    vwap_diff = vwap.iloc[[-1]].values / vwap.iloc[:-1] - 1
    gain = vwap_diff * np.where(vwap_diff > 0, 1.0, 0.0)
    loss = vwap_diff * np.where(vwap_diff < 0, 1.0, 0.0)
    weight = (1 - tr.sort_index(ascending=False)).cumprod()
    weight.sort_index(inplace=True)
    weight = tr / (1 - tr) * weight.values
    weight = weight / weight.sum().values.reshape(1, -1)
    gain = (gain * weight).sum()
    loss = (loss * weight).sum()
    res = [gain - loss, gain - 1.25 * loss, gain - 1.5 * loss, gain - 2 * loss, gain - 3 * loss]
    res = pd.concat(res, axis=1)
    res.columns = ['multiple_100', 'multiple_125', 'multiple_150', 'multiple_200', 'multiple_300']
    res['datetime'] = day
    return res
```

## 因子评价结果

### IC表现（一般）
- IC绝对值大多在 **0.03 附近**
- 最高年份未超过 **0.06**
- 整体信号强度偏弱

### 分层回测
- 不同倍数因子呈**"中间好两头差"**特征
- 做过均值距离化尝试（减截面均值取绝对值）→ IC反而降低
- **倍数=3的因子分层回测区分度最好**

### 结论
独立使用效果有限，更适合作为**多因子组合中的辅助因子**。

## 个人思考

这个因子的价值在于**有行为金融学理论支撑**，而非纯数据挖掘。换手率时间衰减权重的设计有一定巧思。但IC偏低是硬伤，单独使用的超额收益有限。可考虑：
- 与[[笔记/量化策略/]]中的其他因子组合使用
- 加入行业/市值中性化后看是否有改善
- 在特定市场环境（如震荡市）下可能有择时价值
