# 红利科创ETF双网格体系-v3 设计记录

> 本文件是 v3 时期（2026-07-29 ~ 2026-10-15）的设计记录，不是现行规则。三态状态机与「只做红利风控」等约束自 v4（2026-10-16）退役，现行规则见 `交易/交易体系/红利科创ETF双网格体系/风控.md`；体系现状见 `交易/交易体系/红利科创ETF双网格体系/体系介绍.md`。

## 设计讨论时间线

| 步骤 | 决策 | 被否决方案 | 理由 |
|:---|:---|:---|:---|
| 双轨方式 | 分开独立运行双网格 | 单网格轮动 / 联动双网格 | 分开简化，储蓄体系定位 |
| 双创标的 | 159781 双创50ETF | 588000 科创50ETF | 双创覆盖科创板+创业板，更分散 |
| 资金池 | 11,000元统一共享 | 拆分8,000+3,000 | 跷跷板55%对冲，86%时间不双买 |
| 不对称设计 | 红利买1000/卖800 | 对称买1000/卖1000 | 储蓄定位，每轮存200份 |
| 卖步长公式 | 1/(1-买步长)-1 | 查最大涨幅×系数 | 省一个数据源，几何对称 |
| 上涨回调比例 | 买步长×0.2 | 固定值/均振幅 | 统一参数体系，间距自适应 |
| 科创步长系数 | 0.2 | 0.18/0.25/0.3 | 使双创步长≈红利步长，频率同步 |
| 状态切换 | 一次性全仓清→全仓建 | 分批等回调 | 投顾已谨慎才出信号，信就信到底 |
| 切换恢复 | 统一全仓清，不留底仓 | bull全清 bear留底仓 | 对称干净，不担心踏空 |
| 波段内操作 | 你手动管理 | AI管 | 简化体系复杂度，你根据投顾建议操作 |
| 输出分离 | `params/` 纯配置 + 日期化过程资料 | 混在一起 | 配置不改就不动，过程产物按日期保存 |
| 恢复基线 | 快照中的切换前仓位 | 固定数值 | 网格份额随触发变化，快照比固定值准确 |

## 关键约束

1. **YHZQ（银河证券）条件单能力** — 支持价格触发买卖，回落卖出功能影响上涨回调设计
2. **总资金仅11,000元** — 决定不能拆资金，决定了双创只能400份浅尝
3. **投顾主导的状态机判断** — 投顾谨慎，切换频率低，所以一次性全仓建/清合理
4. **只做红利风控** — 双创是放大器，不做独立监控
