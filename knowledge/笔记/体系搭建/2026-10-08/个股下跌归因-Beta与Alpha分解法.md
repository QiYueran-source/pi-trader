# 个股下跌归因：Beta 与 Alpha 分解法

> 来源：2026-10-08 盘中持仓复盘。新洁能（605111）当日 −7.07%，问题「是逻辑破坏，还是市场正常反应」——用本方法拆出「板块退潮」与「个股问题」各占多少。
>
> 定位：属于 [[笔记/体系搭建/2026-06-17/如何搭建自己的交易系统.md|交易系统三要素]] 中「**分析规则：市场在干什么**」的一个细分工具，用于**持仓诊断**，不用于选股，也不替代体系复盘。

## 一、要解决什么问题

个股单日大跌时，最危险的不是跌，而是**误判性质**：

- 当成「市场正常反应」继续持有 → 若是逻辑破坏，会一路扛到深亏；
- 当成「逻辑破坏」砍在最低点 → 若是板块退潮，砍完就反弹。

个股跌幅本身**不含任何信息**（既可能是 β，也可能是 α）。所以必须把它**分解成两层**：

| 层 | 含义 | 看不见它的后果 |
|:--|:--|:--|
| **β（板块/市场）** | 整个板块都在跌，个股只是被拖着走 | 把板块退潮误判成个股出事 |
| **α（个股超额）** | 个股比同类跌得更多的那部分 | 把个股出事误判成"大家都跌" |

## 二、四步分解

### 第 1 步：定大盘 β（分母端）

指数涨跌幅，重点是**与个股驱动相关的那个板指**（成长股看创业板/科创50，权重看上证）。

### 第 2 步：定行业 β —— 用「**同题材子集**」，不用宽行业

这是最关键、最容易做错的一步。宽行业（如「半导体」199 只）把几十个不同驱动逻辑的公司混在一起，均值会失真。

**要用「同一个买入理由/同一个催化」的那批票**（同题材、同驱动、同产业链位置）。经验：**≥5 只**才有均值意义。

### 第 3 步：算 α

```
α = 个股涨跌幅 − 同题材子集均值
```

### 第 4 步：给 α 找原因（α 本身也不是结论）

| α 的成因 | 识别方法 |
|:--|:--|
| **前期涨幅回吐**（拥挤退潮） | 把子集按**前期涨幅**排序，与**当日跌幅**排序对照——**同向**（涨得多的跌得多）即成立 |
| **个股事件** | 搜索当日新闻/公告：减持、立案、业绩预告、订单、客户切换 |
| **基本面变化** | 业绩/价格/订单等**真实经营变量**是否变化（不是股价变化） |
| **资金/技术因素** | 龙虎榜、量能异动、解禁、指数调样 |

## 三、判读表

| 情形 | 判读 |
|:--|:--|
| β 主导 + α 小 + 无事件 | **市场正常反应**（板块退潮） |
| β 主导 + α 大 + 有事件/基本面变化 | **个股逻辑破坏** |
| β 小 + α 大 + 无事件 | **存疑**，继续查（资金/预期/未公开利空） |
| β 大 + α 小 + 有事件 | 事件为真但被板块掩盖，**按事件处理** |

## 四、必须分开的两件事：技术结构 ≠ 产业逻辑

- **技术结构破坏**：跌破 MA5/MA10/MA20、空头排列、深度超阈值 —— 这是**价格**层面的事实。
- **产业逻辑破坏**：涨价/需求/订单/份额等**经营变量**发生逆转 —— 这是**产业**层面的事实。

两者可以不同步：**技术结构已破、产业逻辑完好**是常见组合（板块退潮 + 前期跌幅），此时"砍"与"留"的依据完全不同——**不要用均线破位去论证产业逻辑坏了**。

## 五、口径纪律

1. **子集必须同题材**，且样本 ≥5 只；宽行业均值只能作背景。
2. **涨跌幅自行复算**，不用接口舍入值（贴线时会翻转判定）。
3. 剔 ST、剔 N/C 次新（无涨跌幅限制会污染统计）。
4. **一日信号不切**：单日 α 只作背景，不改动作；要形成结论一般需 2–3 日或配合事件。
5. α 是**相对**量：板块整体跌 5% 时，个股跌 4% 也是 α 为正——不能只看绝对跌幅。

## 六、实战案例：2026-10-08 新洁能（605111）

| 层 | 数据 | 结论 |
|:--|:--|:--|
| 大盘 β | 上证 −0.79% / 深成 −2.07% / 创业板 −3.15% / 科创50 −4.82% | 结构性杀跌，非系统性 |
| 行业 β | 半导体 −4.77%（199 只，全市场领跌第一） | 板块性 |
| **同题材子集** | 功率半导体 10 只均值 **−4.21%**（东微半导 −5.97、宏微科技 −5.45、华微电子 −5.45、扬杰科技 −4.10、士兰微 −3.61、捷捷微电 −3.04、斯达半导 −2.91、银河微电 −2.41、上海贝岭 −2.11） | 子行业整体重挫 |
| **个股 α** | 新洁能 −7.07% → **α = −2.86pp** | 有超额，但幅度小 |
| α 归因 | 新洁能 9/16–9/18 三日 **+17.2%**（子集涨幅第一，涨价主题龙头），9/23 见高 62.38 → 今收 50.18 = **−19.6%**；跌幅最大的东微、宏微同属涨价主题 | **涨幅回吐 / 拥挤退潮** |
| 事件检索 | 当日无公司层面利空（无减持/立案/业绩预告/订单丢失） | 无事件 |
| 产业逻辑 | 2026 功率半导体处 AI 驱动涨价周期（2 月新洁能 MOSFET 涨价 10% 起；英飞凌/TI/ST/安森美多轮调价；台系拟 10 月现货提价 10–15%）；中报（8/25）营收 +25.57%、净利 −0.75%（增收不增利，属已知状态） | **未破坏，且仍在强化** |

**判读**：β 主导 + α 小且可由涨幅回吐解释 + 无事件 → **市场正常反应（板块退潮）**；但**技术结构已破坏**（破全部均线、距 20 日盘中高 −22.3%），两件事分开记。

> 反面提醒：本案例的"未破坏"结论只对**当日**成立。若后续出现「涨价函被下游拒绝 / 代工价格转跌 / AI 电源订单下修 / 大股东减持」，则升级为逻辑破坏——**失效信号要事先写下来**，否则事后会为了持仓而自我说服。

## 七、待固化的部分

本方法目前只是笔记，**未进入任何体系 SOP**。若要固化，需明确：子集如何自动圈定（题材标签来源）、α 的告警阈值（如 |α| > 5pp）、连续几日确认、以及与「主观多头止盈止损档位」的衔接（该档位目前尚未拍板）。
