# A股收评（2026-07-10）——放量调整、高低切换、创业板失守60日线

## 核心数据

| 指标 | 数值 |
|------|:----:|
| 上证指数 | **-1.00%** |
| 深证成指 | **-2.29%** |
| 创业板指 | **-4.00%+**（收报3,842.73）失守60日线 |
| 上涨家数 | ~3,700只 |
| 下跌家数 | ~1,200只 |

> 早盘回顾的"半日2.17万亿"→最终全天3.39万亿，说明下午放量下跌，抛压集中释放。

## 盘面特征：指数弱、个股强

尽管三大指数全线收跌，全市场仍有3,700+只个股上涨。呈现出明显的**"指数弱、个股强"**格局，市场存在结构性机会。

### 热点板块（涨）

| 板块 | 表现 |
|------|------|
| **创新药/医药** | ⭐ 最亮眼——2026H1对外授权交易金额已达2025年全年73%，益诺思、常山药业、美诺华等多股涨停 |
| **人形机器人** | 2026年被看作量产验证关键窗口，日盈电子、晋拓股份等涨停 |
| **白酒** | 反弹——高盛认为行业去库存最艰难阶段已过，复苏极早期，皇台酒业、金种子酒涨超5% |
| **AI应用端** | 盘中异动拉升，欢瑞世纪7天4板 |

### 调整板块（跌）

| 板块 | 表现 |
|------|------|
| **半导体与算力硬件** | ⛔ 前期热门赛道集体回调——兆易创新跌近8%，中际旭创、澜起科技、北方华创等权重跌幅明显 |
| **储能概念** | 海博思创跌超12% |

| **电子特气** | 中船特气跌超19% |

## 市场要闻

- 🚀 **航天重大突破**：长征十号乙运载火箭实现一子级可控回收（海上网系回收），全球首次
- 🏦 **金融监管**：监管层要求基金销售公司自查新规落地，重点核查费率调降及合规销售，推动长周期考核

## 后市分析

**技术面**：创业板指重回弱势，关注**3,755点附近支撑**。若跌破则中期转空，调整时间拉长。

**资金面**：资金从高位科技股获利了结，流向低估值防御板块（医药、消费）。

**策略建议**：
- 市场虽弱但有个股机会，不宜过度悲观
- 科技股需等待风险释放+中报业绩验证后再找修复机会
- 短期关注低位补涨机会，结合中报业绩预告布局
- 以**轮动行情**视角看待，不必执着单一主线

## 一句话总结

> 7月10日A股放量调整，创业板领跌，资金从半导体等高位科技股撤出，流向创新药、机器人及白酒等低位或利好驱动板块，市场进入剧烈分化与轮动期。
