# 参数放松验证（2026-08-04，286 交易日长样本）

背景：用户提议对热门板块回调低吸体系做两点放松——①个股/板块认证窗口 10→22 天；②新增试仓逻辑。要求"先分析不落盘"。本文档是验证结论，供未来正式落盘时引用。

## 数据集

- 2025-06-03 ~ 2026-08-03，286 个交易日，全市场日线 156 万行（parquet）
- 个股买点定义：窗口内有涨停 + 回调≥-8%（距窗口高点）+ 收盘>MA10 + 放量≥1.2×20日均量
- 基准：全市场等权日均 +0.087%，5日基准 +0.44%

## 结论①：个股认证窗口 10→22 天 — ✅ 支持

| 组合 | n | 胜率 | 均值 |
|:-----|:----:|:----:|:----:|
| 10天窗口买点（现状） | 3,016 | 37% | -1.22% |
| 22天窗口买点 | 9,128 | 39% | -0.97% |
| 22天新增（10天不触发） | 6,112 | 40% | -0.84% |

- 22天窗口不只是多抓机会，**新增部分质量反而更高**（-0.84% vs -1.22%）
- 逻辑：10天窗口抓"涨停后立刻回调"多为回调初期接飞刀；22天能等到"涨停→充分回调→站回MA10"的**潜伏末期**形态（对应视频体系"回调末期买点"）
- 样本 3 倍、命中率更高 → 纯收益

## 结论②：板块热度窗口不可拉长 — ❌ 保持当日

| 过滤（叠加在22天买点上） | n | 均值 |
|:-----|:----:|:----:|
| 板块当日涨停≥5（现状） | 1,484 | -0.55% |
| 板块22日累计涨停≥20 | 5,921 | -1.06% |
| 板块22日累计涨停≥30 | 4,727 | -1.03% |

- 板块热度看"当日"，不能看长周期累计——22天累计会把过气板块当热门
- 窗口拉长只对**个股认证**有效，板块确认维持当日

## 结论③：试仓逻辑 — ✅ 成立但条件必须精确

| 试仓组合 | n | 胜率 | 均值 |
|:-----|:----:|:----:|:----:|
| 22天买点+板块当日A+多头+cyb>-2% | 902 | 40% | -0.09% |
| 22天买点+板块当日A+多头+cyb>0 | 672 | 43% | **+0.25%** ✅ |
| 22天买点+仅板块多头+cyb>0 | 2,999 | 40% | -0.52% |

- 试仓必须卡在"板块当日双确认（涨停+多头）+ 大盘非极端弱"
- "只要板块多头就试仓"不行（-0.52% 仍是负）

## 建议的三层架构（未落盘）

```
正式仓：22天买点 + 板块当日A+多头 + 大盘企稳(cyb>0)  → 全仓
试仓：  22天买点 + 板块当日A+多头 + 大盘非极端(cyb>-2%) → 1/4仓试探
观察：  22天买点 + 其他（无板块确认）                  → 只记录不操作
```

试仓 = 正式仓只少一层"大盘企稳"，换来 902 个样本参与机会，期望从 +0.25% 掉到 -0.09%（接近零），用 1/4 仓位承担，试仓天然出口 = MA10 风控。

## 配套实证（同一数据集）

- **持续属性补测**：AB(涨停+多头)持续3天 -0.81% 比单日 -0.39% 更差；任意两条件持续3-4天全负（详见 hot-sector-heat 技能"实证校准"节）
- **三重共振边际贡献**：仅个股买点 -2.57% → +板块双确认 +0.19% → +大盘企稳 +1.94%

## 坑位

- 短样本陷阱：20 天样本曾显示"AB持续2天 +1.52%"，286 天不复现（7月下旬普涨行情的幸存者偏差）
- 用户提议条件必须逐字验证：第一轮只测了单日板块条件+个股买点，用户抓包"两个条件的前提是持续，你确定测了持续这个属性吗"，补测后才完整
