# 神奇公式（Magic Formula）A股全市场5年回测

> 基于乔尔·格林布拉特《股市稳赚》中的"神奇公式"框架，在A股全市场（5526只）做5年季度调仓回测。结果：总收益 **-22.09%**，同期沪深300 +10.21%，超额 **-32.29%**。原始版 Magic Formula 在此区间表现弱于基准。

## 一、回测设计

### 核心逻辑

复制格林布拉特的双因子排名法：

1. **ROC（资本回报率）**：使用 tushare `fina_indicator` 中的 `roic` 字段，衡量公司赚钱能力
2. **EY（盈利收益率）**：`EBIT / 总市值(total_mv)`，衡量股票相对盈利能力是否便宜

每期对全市场股票分别按 ROC 降序、EY 降序排名，两个排名加总后取综合排名最低的 **30 只**，等权持有至下一调仓日。

### 参数

| 项目 | 值 |
|------|----|
| 回测区间 | 2021-09-30 ~ 2026-06-30 |
| 调仓频率 | 每季度末 |
| 选股数量 | 30只 |
| 持仓方式 | 等权 |
| 排除行业 | 银行、保险、证券、房地产、多元金融 |
| 市值门槛 | 总市值 >= 10亿元 |
| 财务条件 | ROC > 0 且 EBIT > 0 |
| 数据源 | Tushare Pro |
| 股票池 | 全市场A股 5526 只（除北交所） |

### 季度财报对齐

| 调仓日 | 参考财报 | 原因 |
|--------|---------|------|
| 3月底 | 上年三季报(0930) | 年报截至4月底才出完 |
| 6月底 | 一季报(0331) | 年报+一季报已在4月底前出完 |
| 9月底 | 中报(0630) | 中报截至8月底已出完 |
| 12月底 | 三季报(0930) | 三季报截至10月底已出完 |

## 三、分析

### 为什么跑输？

1. **A股价值因子失效期（2022~2024H1）**：这段区间A股成长/小盘风格主导，高ROIC+低估值的"好公司便宜价"逻辑不赚钱。连续6期负收益（2022Q2~2024Q2），累计亏损约-45%，即使后续反弹也难回本。

2. **无行业中性化**：纯排名法可能把同一行业的多只股票集中选入（如顺周期行情下煤炭/有色扎堆），一旦行业逆转，集中亏损风险大。

3. **等权持仓波动大**：30只等权组合中如果包含大量中小盘股，单期波动远超沪深300。最大单期亏损 -14.12%，最后一期 -16.98%。

4. **季度调仓偏慢**：A股轮动节奏快（1~2个月），3个月持有期可能在趋势反转时无法及时反应。

### 何时有效？

2024年9月起，连续6期正收益（除2026Q2最后一期暴跌外），说明 **在价值风格回归时Magic Formula弹性极强**。牛市/价值风格下，高ROIC公司往往最先受益。

### 后续方向

- **市场环境过滤器**：叠加风格判断（如仅在大盘价值风格占优时启用）
- **行业中性化**：先按行业分层，各行业内部排名后再汇总
- **趋势过滤**：买入前确认个股在均线上方或动量为正
- **调仓频率优化**：尝试6个月或12个月持有期

## 四、回测代码

数据获取和回测代码见 `/opt/data/magic_backtest/`，核心逻辑如下：

### 数据获取脚本

```python
#!/opt/hermes/.venv/bin/python3
"""
Magic Formula 回测 - 数据获取
拉取：stock_basic, trade_cal, fina_indicator, daily_basic, 全市场日线
"""

import os, time, json, socket
import pandas as pd
import numpy as np
from concurrent.futures import ThreadPoolExecutor, as_completed
from pathlib import Path

DATA_DIR = Path("/opt/data/magic_backtest/data")
DATA_DIR.mkdir(parents=True, exist_ok=True)

socket.setdefaulttimeout(30)

import tushare as ts
token = os.environ.get("TUSHARE_TOKEN", "")
if not token:
    import subprocess
    r = subprocess.run(["hermes", "config", "get", "TUSHARE_TOKEN"],
                       capture_output=True, text=True)
    token = r.stdout.strip()
ts.set_token(token)
pro = ts.pro_api()

# 1. 全市场股票列表
stock_basic = pro.stock_basic(
    fields="ts_code,symbol,name,area,industry,market,list_date,delist_date,is_hs"
)
stock_basic.to_parquet(DATA_DIR / "stock_basic.parquet")

# 筛选活跃A股（上市、未退市、非北交所）
active = stock_basic[
    (stock_basic["list_date"].notna()) &
    ((stock_basic["delist_date"].isna()) | (stock_basic["delist_date"] == ""))
]
active = active[~active["market"].isin(["BJ"])]
all_codes = active["ts_code"].tolist()

# 2. 交易日历
trade_cal = pro.trade_cal(
    start_date="20200101", end_date="20260630",
    fields="cal_date,is_open,pretrade_date"
)
trade_cal = trade_cal[trade_cal["is_open"] == 1].reset_index(drop=True)
trade_cal.to_parquet(DATA_DIR / "trade_cal.parquet")
trade_dates = sorted(trade_cal["cal_date"].tolist())

# 确定季度末交易日（调仓日）
reb_dates = []
for year in range(2021, 2027):
    for month in [3, 6, 9, 12]:
        m_dates = [d for d in trade_dates if d.startswith(f"{year}{month:02d}")]
        if m_dates:
            reb_dates.append(m_dates[-1])
reb_dates = [q for q in reb_dates if "20210701" <= q <= "20260630"]

# 3. 财务指标（逐只拉取，10线程并发）
def fetch_one(code):
    try:
        df = pro.fina_indicator(
            ts_code=code, start_date="20200101", end_date="20260630",
            fields="ts_code,end_date,roic,ebit,invest_capital,"
                   "networking_capital,roe,eps,profit_dedt"
        )
        time.sleep(0.12)
        return code, df if (df is not None and len(df) > 0) else None
    except Exception as e:
        time.sleep(1)
        return code, None

all_fina = []
for b in range(0, len(all_codes), 200):
    batch = all_codes[b:b+200]
    results = []
    with ThreadPoolExecutor(max_workers=10) as exec:
        fs = {exec.submit(fetch_one, c): c for c in batch}
        for f in as_completed(fs):
            _, r = f.result()
            if r is not None:
                results.append(r)
    if results:
        all_fina.append(pd.concat(results, ignore_index=True))
    print(f"  批次 {b//200+1}: {len(results)}/{len(batch)}")

if all_fina:
    fina_all = pd.concat(all_fina, ignore_index=True)
    fina_all.to_parquet(DATA_DIR / "fina_indicator_all.parquet")

# 4. 调仓日估值数据
all_db = []
for tdate in reb_dates:
    df = pro.daily_basic(trade_date=tdate,
        fields="ts_code,trade_date,total_mv,circ_mv,pe_ttm,pb")
    if df is not None and len(df) > 0:
        all_db.append(df)
    time.sleep(0.15)
pd.concat(all_db, ignore_index=True).to_parquet(
    DATA_DIR / "daily_basic_reb.parquet"
)

# 5. 全市场日线行情（按月拉取）
daily_dir = DATA_DIR / "daily"
daily_dir.mkdir(exist_ok=True)

months = sorted(set(d[:6] for d in trade_dates
                     if "20210101" <= d <= "20260630"))
for ym in months:
    m_dates = [d for d in trade_dates if d.startswith(ym)]
    if not m_dates:
        continue
    all_m = []
    for tdate in m_dates:
        df = pro.daily(trade_date=tdate,
            fields="ts_code,trade_date,open,high,low,close,"
                   "pre_close,change,pct_chg,vol,amount")
        if df is not None and len(df) > 0:
            all_m.append(df)
        time.sleep(0.15)
    if all_m:
        pd.concat(all_m, ignore_index=True).to_parquet(
            daily_dir / f"daily_{ym}.parquet"
        )
```

### 回测执行脚本

```python
#!/opt/hermes/.venv/bin/python3
"""
Magic Formula 全市场5年回测 - 执行
"""

import os, json
from pathlib import Path
import pandas as pd
import numpy as np

DATA_DIR = Path("/opt/data/magic_backtest/data")
OUTPUT_DIR = Path("/opt/data/magic_backtest/output")
OUTPUT_DIR.mkdir(parents=True, exist_ok=True)

# 加载数据
stock_basic = pd.read_parquet(DATA_DIR / "stock_basic.parquet")
active = stock_basic[
    (stock_basic["list_date"].notna()) &
    ((stock_basic["delist_date"].isna()) | (stock_basic["delist_date"] == ""))
]
active = active[~active["market"].isin(["BJ"])]

trade_cal = pd.read_parquet(DATA_DIR / "trade_cal.parquet")
trade_dates = sorted(trade_cal["cal_date"].tolist())

fina_all = pd.read_parquet(DATA_DIR / "fina_indicator_all.parquet")
fina_all["end_date"] = fina_all["end_date"].astype(str)

db_reb = pd.read_parquet(DATA_DIR / "daily_basic_reb.parquet")
db_reb["trade_date"] = db_reb["trade_date"].astype(str)

daily_dir = DATA_DIR / "daily"

# 调仓日
reb_dates = []
for year in range(2021, 2027):
    for month in [3, 6, 9, 12]:
        m_dates = [d for d in trade_dates if d.startswith(f"{year}{month:02d}")]
        if m_dates:
            reb_dates.append(m_dates[-1])
reb_dates = [q for q in reb_dates if "20210701" <= q <= "20260630"]

# 财报对齐
def get_quarter_for_reb(reb_date):
    y, m = int(reb_date[:4]), int(reb_date[4:6])
    if m <= 3:   return f"{y-1}0930"
    elif m <= 6:  return f"{y}0331"
    elif m <= 9:  return f"{y}0630"
    else:         return f"{y}0930"

FINANCE_INDUSTRIES = [
    "银行", "保险", "证券", "多元金融", "房地产",
    "银行 II", "保险 II", "证券 II", "房地产 II",
]

results = []

for reb_date in reb_dates:
    quarter = get_quarter_for_reb(reb_date)

    # 取该季度财报，去重
    q_fina = fina_all[fina_all["end_date"].astype(str).str.startswith(quarter[:6])].copy()
    q_fina = q_fina.sort_values("end_date").drop_duplicates(subset="ts_code", keep="last")
    if q_fina.empty:
        continue

    # 合并估值数据
    db_day = db_reb[db_reb["trade_date"] == reb_date]
    if db_day.empty:
        continue
    merged = q_fina.merge(db_day, on="ts_code", how="inner")
    merged = merged.merge(active[["ts_code", "name", "industry"]],
                          on="ts_code", how="left")

    # 清洗
    merged = merged[~merged["industry"].isin(FINANCE_INDUSTRIES)]
    merged["roic"] = pd.to_numeric(merged["roic"], errors="coerce")
    merged["ebit"] = pd.to_numeric(merged["ebit"], errors="coerce")
    mask = (
        merged["roic"].notna() & (merged["roic"] > 0) &
        merged["ebit"].notna() & (merged["ebit"] > 0) &
        merged["total_mv"].notna() & (merged["total_mv"] >= 100000)  # 万元
    )
    merged = merged[mask]
    if len(merged) < 30:
        continue

    # 双因子排名
    merged["ey"] = merged["ebit"] / merged["total_mv"]
    merged["roc_rank"] = merged["roic"].rank(ascending=False)
    merged["ey_rank"] = merged["ey"].rank(ascending=False)
    merged["total_rank"] = merged["roc_rank"] + merged["ey_rank"]

    selected = merged.sort_values("total_rank").head(30)

    results.append({
        "rebalance_date": reb_date, "quarter": quarter,
        "codes": selected["ts_code"].tolist(),
        "avg_roic": float(selected["roic"].mean()),
        "avg_ey": float(selected["ey"].mean()),
    })

    # 计算持有期收益
    idx = reb_dates.index(reb_date)
    next_reb = reb_dates[idx + 1] if idx + 1 < len(reb_dates) else "20260630"

    hold_data = load_daily_range(reb_date, next_reb, daily_dir)
    hold_pivot = hold_data[hold_data["ts_code"].isin(selected["ts_code"].tolist())]
    hold_pivot = hold_pivot.pivot_table(
        index="trade_date", columns="ts_code", values="pct_chg", aggfunc="first"
    )
    hold_pivot["portfolio_ret"] = hold_pivot.mean(axis=1)
    hold_pivot["cum_ret"] = (1 + hold_pivot["portfolio_ret"] / 100).cumprod()

    print(f"{reb_date} -> {next_reb}: {hold_pivot['cum_ret'].iloc[-1]-1:+.2%}")


def load_daily_range(start_date, end_date, daily_dir):
    """加载日期范围内日线数据"""
    months = set()
    y, m = int(start_date[:4]), int(start_date[4:6])
    while f"{y}{m:02d}" <= end_date[:6]:
        months.add(f"{y}{m:02d}")
        m += 1
        if m > 12: m, y = 1, y+1
    dfs = []
    for ym in sorted(months):
        f = daily_dir / f"daily_{ym}.parquet"
        if f.exists():
            dfs.append(pd.read_parquet(f))
    if dfs:
        df = pd.concat(dfs, ignore_index=True)
        df["trade_date"] = df["trade_date"].astype(str)
        return df[(df["trade_date"] >= start_date) & (df["trade_date"] <= end_date)]
    return pd.DataFrame()
```
