## 运行契约

- 交易日判断用体系 MCP `agent-etf-rotation-system` 的 `is_trading_day`（本服务自带，不依赖其它 MCP）；非交易日发送一行状态（`【1825 轮动回放】非交易日 ｜ 跳过`）后结束。

- 体系 MCP `agent-etf-rotation-system` 只提供契约校验；本体系无机械计算，不调用历史脚本。
- 简报写入 `摘要/.abstract/{今天日期}_agent-etf-rotation-replay-execute.txt`（落 `knowledge/`）。

## 边界

只按计划回放并登记模拟成交：不重新判断动作、不改写计划、不改规则库与运行定义、不执行真实交易；计划或必要数据无效时写明链路异常且不执行成交。

## 投递与输出

- **投递**：读 `cronjob/delivery.json` 的 `feishuChatId`，用 `send_to_feishu` **显式传该 chat_id** 发送结果（运行时会话空闲时没有活跃聊天状态，不显式传会失败）。文件缺失或发送失败时，把内容留在回复中并说明原因。
- **输出格式**：首行一行式状态，格式 `【任务简称】结论/动作 ｜ 关键数字`；正文只列必要要点（不超过 5 行），异常与待办各占一行。
- **无动作也回执**：非交易日、无候选、无过期文件等情形同样发送一行状态，便于确认任务确实执行。
