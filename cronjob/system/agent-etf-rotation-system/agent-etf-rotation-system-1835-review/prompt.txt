# ETF轮动 · 每日复盘

交易日 18:35 复盘当日计划、模拟执行和市场事实，为下一交易日计划提供输入。

## 执行指引

按 `体系运作流程.md` **第 2.3 节「复盘（18:35）」** 执行：步骤与产物、`document` 必填字段、异常分支均在该节；共同输入与前置见 **第 2.1 节**。

## 运行契约

- 交易日判断用体系 MCP `agent-etf-rotation-system` 的 `is_trading_day`（本服务自带，不依赖其它 MCP）；非交易日发送一行状态（`【1835 轮动复盘】非交易日 ｜ 跳过`）后结束。
- 市场数据用 `tushare-data`；账户、成交、持仓与现金用 `trade-management`。
- 复盘由体系 MCP `agent-etf-rotation-system` 的 `render(artifact="review", date, document=...)` 渲染并落盘 `交易/交易复盘/{今天日期}/基于Agent的ETF轮动体系_复盘.md`（落 `knowledge/`）；`document` 字段结构见 `MCP介绍.md`。
- 简报写入 `摘要/.abstract/{今天日期}_agent-etf-rotation-review.txt`（落 `knowledge/`）。

## 边界

不重新评价当日动作、不改规则库与运行定义、不把计划写成已成交；复盘中的事实必须来自 MCP 查询结果，不补造价格、持仓或成交；无成交时仍生成复盘并说明无成交是否符合计划。

## 投递与输出

- **投递**：读 `cronjob/delivery.json` 的 `feishuChatId`，用 `send_to_feishu` **显式传该 chat_id** 发送结果（运行时会话空闲时没有活跃聊天状态，不显式传会失败）。文件缺失或发送失败时，把内容留在回复中并说明原因。
- **输出格式**：首行一行式状态，格式 `【任务简称】结论/动作 ｜ 关键数字`；正文只列必要要点（不超过 5 行），异常与待办各占一行。
- **无动作也回执**：非交易日、无候选、无过期文件等情形同样发送一行状态，便于确认任务确实执行。
