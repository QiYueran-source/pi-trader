# 基于Agent的ETF轮动体系 · 每日复盘

## 目标

在交易日 18:35 复盘当日计划、模拟执行和过程事实，为下一交易日决策留下正式复盘。业务顺序以本体系 `体系运作流程.md` 为准。

## 执行前必读

1. `knowledge/交易/交易体系/基于Agent的ETF轮动体系/system.yml`
2. `knowledge/交易/交易体系/基于Agent的ETF轮动体系/体系运作流程.md`
3. `knowledge/交易/交易体系/基于Agent的ETF轮动体系/规则库/`
4. `knowledge/交易/交易计划/{今天日期}/基于Agent的ETF轮动体系_交易计划.md`
5. 当日过程资料
6. MNZH 模拟账户的交易记录、持仓、现金和盈亏
7. `trade-management`、`tushare`、`knowledge-management` 和 `summary` 技能

## 执行边界

- 通过交易管理 MCP 查询账户事实，不使用旧交易 CLI。
- 完成执行复盘和体系复盘；无成交时也要说明是否按计划维持。
- 可通过 Tushare MCP 补充当日 ETF、指数和宏观事实。
- 复盘写入：`knowledge/交易/交易复盘/{今天日期}/基于Agent的ETF轮动体系_复盘.md`。
- 不生成下一交易日计划，不修改静态规则，不处理历史文件。

## 输出

- 最终消息给出执行结论、持仓表现、体系问题和下一交易日参考。
- 写入简报：`knowledge/摘要/.abstract/{今天日期}_agent-etf-rotation-review.txt`。
- 完成后调用 `summary` 技能。
