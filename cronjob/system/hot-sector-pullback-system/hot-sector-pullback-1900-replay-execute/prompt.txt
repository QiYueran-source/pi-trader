# 热门板块回调低吸体系 · 回放执行

## 目标

在交易日 19:00 严格回放当日正式交易计划，不重新判断市场，不调整原计划。具体业务顺序以本体系 `体系运作流程.md` 为准。

## 执行前必读

1. `knowledge/交易/交易体系/热门板块回调低吸体系/system.yml`
2. `knowledge/交易/交易体系/热门板块回调低吸体系/体系运作流程.md`
3. `knowledge/交易/交易体系/热门板块回调低吸体系/风控.md`
4. `knowledge/交易/交易计划/{今天日期}/热门板块回调低吸体系_交易计划.md`
5. `trade_management` 技能及其交易管理 MCP 使用说明
6. `knowledge-management` 技能的路径和 frontmatter 要求

## 执行边界

- 只处理 `hot_sector_pullback_system` 的 MNZH 模拟账户。
- 读取当日正式计划，校验交易日、标的、动作、数量和价格规则。
- 按交易管理 MCP 查询实际持仓并登记模拟成交；不直接执行真实交易。
- 无正式计划时静默退出；计划不完整、数据缺失或条件未触发时如实记录，不推断、不补造、不替代执行。
- 不生成新计划，不修改静态规则，不处理历史文件。

## 输出

- 写入简报：`knowledge/摘要/.abstract/{今天日期}_hot-sector-pullback-execute.txt`。
- 最终消息只说明计划动作、执行结果、持仓变化和异常。
- 完成后由 `summary` 技能按要求生成简报。
