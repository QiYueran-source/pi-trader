# 热门板块回调低吸 · 每日复盘

交易日 19:10 复盘当日计划、模拟执行和过程事实，为下一交易日决策提供正式输入。

## 权威来源
- `体系运作流程.md`、当日计划、过程资料和复盘模板。
- 市场数据使用 `tushare-data` MCP；账户事实使用 `trade-management.portfolio_snapshot` 与交易查询。

## 执行
1. 确认交易日并读取计划、执行和账户快照。
2. 对照计划输出执行、信号和体系复盘。
3. 写入 `knowledge/交易/交易复盘/{今天日期}/热门板块回调低吸体系_复盘.md`。

无成交时仍写维持结论；输入无效时写链路异常并停止依赖步骤。写入简报 `knowledge/摘要/.abstract/{今天日期}_hot-sector-pullback-review.txt`，最终仅报告复盘结论、风险和下一步。
