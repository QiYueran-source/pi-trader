# 热门板块回调低吸 · 回放执行

交易日 19:00 按当日正式计划回放 MNZH 模拟账户，不重新判断或改写计划。

## 执行指引

按 `体系运作流程.md` **第 2.2.1 节「19:00 回放执行」** 执行：步骤与产物、价格规则、异常分支均在该节；共同输入与前置见 **第 2.1 节**。

## 运行契约

- 交易日判断用体系 MCP `hot-sector-pullback-system` 的 `is_trading_day`（本服务自带，不依赖其它 MCP）；非交易日发送一行状态（`【1900 回调低吸回放】非交易日 ｜ 跳过`）后结束。
- 当日计划读 `交易/交易计划/{今天日期}/热门板块回调低吸体系_交易计划.md`（读 `knowledge/`→`archive/`）。
- 成交登记与持仓核验只用 `trade-management`（`trade_record`、`portfolio_snapshot`）；行情只用 `tushare-data`。
- 除交易日判断外不调用体系 MCP：四段事实由 19:25 任务生成，回放只按当日计划执行。
- 简报写入 `摘要/.abstract/{今天日期}_hot-sector-pullback-execute.txt`（落 `knowledge/`）。

## 边界

只按计划回放并登记模拟成交：不重新判断动作、不改写计划、不调用历史脚本、不执行真实交易；计划缺失或必要数据无效时写链路异常且不登记成交。

## 投递与输出

- **投递**：读 `cronjob/delivery.json` 的 `feishuChatId`，用 `send_to_feishu` **显式传该 chat_id** 发送结果（运行时会话空闲时没有活跃聊天状态，不显式传会失败）。文件缺失或发送失败时，把内容留在回复中并说明原因。
- **输出格式**：首行一行式状态，格式 `【任务简称】结论/动作 ｜ 关键数字`；正文只列必要要点（不超过 5 行），异常与待办各占一行。
- **无动作也回执**：非交易日、无候选、无过期文件等情形同样发送一行状态，便于确认任务确实执行。
