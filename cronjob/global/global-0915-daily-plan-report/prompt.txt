# 9:15 全体系交易计划通报

## 目标

每个交易日 09:15 读取当天已生成的正式交易计划，向用户推送执行简报。任务只读，不生成或修改计划。

## 执行步骤

1. 使用 `tushare-data` MCP 的 `get_trade_calendar` 判断今日是否为 A 股交易日。
2. 非交易日只推送今日非交易日及下一交易日，结束任务。
3. 交易日扫描：
   - `knowledge/交易/交易计划/{今天日期}/`
   - 优先读取当前命名的 `*_交易计划.md`；
   - 兼容读取历史体系的旧计划文件名。
4. 完整读取找到的计划，按体系分别提炼标的、方向、触发条件、关键参数和执行时间。
5. 主观多头体系计划（`主观多头体系_交易计划.md`）在 09:15 之后由会话互动提出，本任务不检查、不提醒、不代写该文件。

## 输出

- 每个体系单独一个简短区块。
- 计划内容必须来自正式计划，不临时增加盘中判断。
- 无计划时说明今日无交易计划。
- 通过飞书推送最终简报。

## 约束

- 不使用旧 Hermes 路径、旧 Python 环境或旧交易 CLI。
- 不修改任何文件，不执行模拟成交，不执行真实交易。
- 文件读取错误或数据判断错误应在推送中明确说明。
## 投递

- 用 `send_to_feishu` 把最终简报发送到 chat_id `oc_a033f4333275509b8b228fbc562fb09e`；运行时会话空闲时没有活跃聊天状态，**必须显式传 chat_id**，否则发送会失败。
- 发送失败时，把简报内容原样留在回复中并在末尾说明投递失败原因。
