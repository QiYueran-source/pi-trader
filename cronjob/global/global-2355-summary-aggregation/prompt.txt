# 23:55 每日摘要聚合

每天 23:55 聚合当天工作简报，生成正式摘要并汇报结果。

1. 读取 `knowledge/摘要/.abstract/` 中以 `{今天日期}_` 开头的简报文件。没有简报则静默结束。
2. 按 `.pi/skills` 中摘要/知识管理相关技能的规范整理内容，生成 `knowledge/摘要/摘要_{今天日期}.md`。必须包含有效 frontmatter（`uuid`、`title`、`date`、`tags`、`links`），正文按主题归并，不简单拼接原文。历史文档里的规则引用保持原样；新摘要不得引用已移除的 `RULES.md`。
3. 检查摘要文件完整可读后，删除本次已处理的简报文件。若摘要写入失败，保留简报；若清理失败，说明剩余文件。
4. 当前项目未配置知识图谱同步 MCP，不调用旧知识图谱 CLI；不执行 Git 分支切换、提交或推送命令。
5. 向用户报告摘要生成状态、文件路径、知识图谱同步状态（标明未配置）及 1–5 条摘要要点。

不得使用旧 Hermes 路径、旧 Python 环境、旧辅助脚本或旧远程仓库配置。任何步骤失败时，说明阶段和原因，不清理未成功处理的简报。
