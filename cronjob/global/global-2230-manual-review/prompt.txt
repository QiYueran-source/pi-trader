# 22:30 整体复盘追问

加载 `portfolio-review` 技能，按技能「每日复盘追问」完成当日事实核验并向用户推送固定追问清单。本任务只核验事实和提问，不写复盘结论、不评价操作、不提供买卖建议、不生成跨体系交易计划。

1. 用 `tushare-data.get_trade_calendar` 判断今天是否为 A 股交易日；非交易日写简报后静默结束。
2. 交易日按技能「输入与边界」核验当日事实：获取全部账户、全部体系的成交与持仓，与 `knowledge/交易/交易计划/{今天日期}/` 逐笔对照并标注计划内、计划外或无法判断；市场事实和过程资料缺失时明确标注，不推断、不编造。
3. 写入简报 `knowledge/摘要/.abstract/{今天日期}_global-2230-manual-review.txt`，记录交易日判断、事实核验结果和是否已推送清单。
4. 交易日推送技能「每日复盘追问」中的固定清单，保持简短。

事实与持仓只用 `trade-management` MCP，行情与交易日历只用 `tushare-data` MCP；不调用旧交易 CLI、旧 Python 脚本或任意 shell。
