# 22:30 主观复盘追问

向用户发送固定的当日复盘清单，自动填入可核验事实。只提问和呈现事实，不写复盘结论、不评价操作、不提供买卖建议、不生成交易计划。

## 步骤

1. 调用 `tushare-data.get_trade_calendar` 判断今天是否为 A 股交易日。非交易日写简报 `knowledge/摘要/.abstract/{今天日期}_global-2230-manual-review.txt` 后静默结束。
2. 交易日时调用 `trade-management.trade_list` 获取交易记录，按 `occurred_at` 筛选今天的记录；不要遗漏当天记录。与 `knowledge/交易/交易计划/{今天日期}/` 对照，逐笔标注计划内或计划外。没有成交时明确写“今日无成交”。
3. 从本地文档摘录市场事实：优先 `knowledge/事实/{今天日期}/市场收评.md`，没有时使用 `市场午评.md`；查阅当日 `knowledge/交易/过程资料/{今天日期}/` 中已有的市场脚本产物。若某项事实缺失，明确标记缺失，不推断或编造。
4. 对当日成交涉及的每个账户、证券和体系，调用 `trade-management.trade_pnl`，读取剩余数量与平均成本。交易记录包含多个体系时按对应 `system_id` 分别查询。
5. 写入简报，记录交易日判断、当日成交事实及是否已推送清单。
6. 交易日时推送以下固定三段，保持简短：

```text
【今日复盘清单 · {今天日期}（周X）】

一、看市场（水温）
   指数：{上证/深成指/创业板指涨跌幅；缺失则标明}
   量能：{全天成交额、较上一交易日增减；涨跌家数；缺失则标明}
   板块：{涨停最集中方向} ｜ 领跌：{方向；缺失则标明}

二、看自己（交割单）
   今日成交：
   - {逐笔：方向 标的 数量 @价格（时间） 计划内/计划外}
   持仓：{当日成交涉及标的的剩余数量与成本}
   → 请回两句：
     ① 这些操作是「模式内试错」，还是「偏离规则」？
     ② 当时是因为看到信号下单，还是不甘心 / 怕踏空？

三、写计划（定明天）
   → 请回一句：如果明天继续跌，你的防守底线（止损位）在哪？

（回这三段就行。我会：① 落盘《主观多头体系复盘》 ② 生成次日《主观多头体系_交易计划》）
```

所有交易事实使用 `trade-management` MCP；市场行情和交易日历使用 `tushare-data` MCP。不得调用旧交易 CLI、旧 Python 脚本或执行任意 shell。
