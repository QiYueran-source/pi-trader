# 22:30 整体复盘追问

使用 `portfolio-review` 技能完成跨账户、跨交易体系的整体持仓复盘准备。本任务只核验事实并向用户提问，不写复盘结论、不评价操作、不提供买卖建议、不生成跨体系交易计划。

## 执行

1. 调用 `tushare-data.get_trade_calendar` 判断今天是否为 A 股交易日。非交易日写简报 `knowledge/摘要/.abstract/{今天日期}_global-2230-manual-review.txt` 后静默结束。
2. 交易日调用 `trade-management` MCP 获取今天全部账户、全部体系的成交，并与 `knowledge/交易/交易计划/{今天日期}/` 对照，逐笔标注计划内、计划外或无法判断。没有成交时明确写“今日无成交”。
3. 读取当日市场事实和过程资料；对当日成交涉及的账户、证券和体系调用 `trade-management.trade_pnl` 获取持仓与成本。缺失事实明确标记，不推断或编造。
4. 写入简报，记录交易日判断、事实核验结果和是否已推送清单。
5. 推送以下固定问题，保持简短：

```text
【今日整体复盘清单 · {今天日期}（周X）】

一、看市场（水温）
   指数：{上证/深成指/创业板指涨跌幅；缺失则标明}
   量能：{全天成交额、较上一交易日增减；涨跌家数；缺失则标明}
   板块：{涨停最集中方向} ｜ 领跌：{方向；缺失则标明}

二、看自己（整体持仓与交割单）
   今日成交：
   - {逐笔：账户 / 体系 / 方向 / 标的 / 数量 @价格（时间）/ 计划判定}
   持仓：{相关账户和体系的剩余数量与成本}
   → 请回两句：
     ① 这些操作是「模式内试错」，还是「偏离规则」？
     ② 当时是因为看到信号下单，还是不甘心 / 怕踏空？

三、定明天（只记录意图）
   → 请回一句：如果明天继续跌，你的整体防守底线是什么？

（回复后调用 `portfolio-review` 技能，落盘《整体复盘》，并列出需要由对应体系分别处理的行动与待办。）
```

所有交易事实使用 `trade-management` MCP；市场行情和交易日历使用 `tushare-data` MCP。不得调用旧交易 CLI、旧 Python 脚本或执行任意 shell。
