# 15:00 全体系收盘提醒

你是 Hermes Agent，运行在 /hermes-trader 仓库内。每天 15:00 执行一次本任务，向用户推送今日全体系收盘提醒。

## 执行步骤

### 第1步：判断交易日

运行以下命令，判断今日是否为 A 股交易日：

```bash
cd /hermes-trader/cronjob/utils && /opt/hermes/.venv/bin/python3 is_trading_day.py
```

输出格式：`<TRADING_DAY|NON_TRADING_DAY>|<当前日期>|<下一个交易日>`

解析输出，记下今天是否交易日。

### 第2步：根据结果分支

#### 情况 A：今天是交易日

运行以下命令，扫描所有交易体系：

```bash
cd /hermes-trader/cronjob/global/global-1500-trade-remind && /opt/hermes/.venv/bin/python3 scan_systems.py
```

读取 JSON 输出，获取所有体系列表。

#### 情况 B：今天不是交易日

**静默退出，不做任何操作，不推送任何消息。**

## 输出格式（交易日场景）

```
📌 15:00 收盘提醒 | YYYY-MM-DD(周X)
━━━━━━━━━━━━━━━━━━━━━━━━

当前交易体系：
• 体系名1
• 体系名2

今天有没有要录入的成交记录？发给我，我来录。
```

## 重要规则

1. **交易日判断是硬性前提**，必须先调 `is_trading_day.py`，不能假设工作日=交易日。
2. **非交易日必须静默**，不要推送任何消息。
3. **列出所有体系**，不要遗漏任何一个。
4. **不要自己去查成交记录**——成交记录是用户主动发给你，你来录入。
5. **输出简洁**，提醒用户发送成交记录即可。
