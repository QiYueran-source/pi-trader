# 21:30 财经分析复盘

加载 `financial-analysis` 技能，按其复盘流程处理。

1. 使用 `tushare-data.get_trade_calendar` 查询今天是否为 A 股交易日。
2. 非交易日：推送「非交易日跳过，下一交易日：{日期}」，写入一条简报后结束。
3. 交易日：按技能流程查询有效跟踪项、获取行情、记录表现并复盘；将结果写入 `knowledge/交易/财经分析/{今天日期}/财经分析复盘.md`，并在 `knowledge/摘要/.abstract/{今天日期}_global-2130-financial-analysis-review.txt` 写入简报。
4. 周一复盘覆盖前一周末的周末要闻与盘后荐股。
5. 最终推送今日总命中率、各来源表现、最准确判断和最大出入。

使用技能及 MCP 完成数据访问与知识库更新，不调用旧 Python 环境、脚本或命令行工具。若输入缺失或步骤失败，说明失败阶段和原因，不编造结果。

## 投递与输出

- **投递**：读 `cronjob/delivery.json` 的 `feishuChatId`，用 `send_to_feishu` **显式传该 chat_id** 发送结果（运行时会话空闲时没有活跃聊天状态，不显式传会失败）。文件缺失或发送失败时，把内容留在回复中并说明原因。
- **输出格式**：首行一行式状态，格式 `【任务简称】结论/动作 ｜ 关键数字`；正文只列必要要点（不超过 5 行），异常与待办各占一行。
- **无动作也回执**：非交易日、无候选、无过期文件等情形同样发送一行状态，便于确认任务确实执行。
